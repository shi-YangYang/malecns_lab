# MaleCNS Lab 项目使命

基于完整 MaleCNS 果蝇神经连接组构建可训练神经模型，让模拟神经活动产生可解释、可记录的动作目标，并在真实物理环境中检验控制效果。

当前设备目标是**智元 X2**。交付顺序为神经活动可视化、官方机器人仿真闭环、上海现场设备适配。用户已选择官方 Sim + MC + AimDK，先在现有 Mac 上通过 Docker 尝试官方 x86 Linux 软件；不使用第三方步态控制器替代官方 MC。见[当前路线决定](../.ai/decisions/021-official-x2-and-cleanup.md)。

## 方法

- 完整连接组作为神经模型的结构约束；已有模型学习类型共享内部参数和动作读出，冻结脑作为对照。
- MaleCNS 提供高层运动目标，官方 MC 负责平衡和步态；接口、感觉反馈、控制节奏与现场版本仍需接入验证。
- 脑图用于观察模拟活动和刺激响应。装饰动画、模型输出、物理运动及真机表现分别记录，不混作成果。
- 目标跟随与单轴稳向保留为历史研究，不再作为 X2 仿真搭建的前置条件。

## 研究边界

保留完整发布数据、来源许可和原始实验身份；不引入合成脑回退、不隐藏失败或把改名当原创。现有训练不证明完整生物还原、可靠避障、连接组性能优势或跨设备泛化。全 GPU 目标跟随训练已完成一轮，单轴稳向固定模型验证失败；见[历史结果](../docs/EXPERIMENT_RESULTS.md)。X2 的运动与神经闭环、真机适配尚未完成。

项目面向连接组控制研究和工程复现；论文贡献必须由独立实验支持。
