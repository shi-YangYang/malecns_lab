# 路线与证据

此文件记录已知研究阶段，不代替具体 Spec，也不承诺时间表。阶段状态以现有实现和实验记录为依据。

| 阶段 | 当前状态 | 下一步所需证据 |
|---|---|---|
| 设备与人工读出基线 | 已有地面连接、视频、神经输出观察及分阶段短时 Tello 实飞工具；既有实飞采用人工读出和监督逻辑 | 保留每次运行配置、日志和肉眼观察，不能据此认定新读出有效 |
| 共享动作与离线学习基础 | 已实现 `BodyVelocity`、岭回归读出、无人机与差速底盘数学适配、采集及评估工具 | 接口和软件检查只说明实现可用，不代替真实任务评估 |
| 神经信号观察 | V2 完整图已完成六类标准视觉刺激诊断，保存输入、33 个输出细胞和全脑摘要；见 [实测记录](../docs/MODEL_V2_USAGE.md#7-已完成的完整图诊断) | 尚无真实录像；单纹理、单种子、短时响应不能证明正确动作或生物方向编码 |
| 第二版模型 | 完整参考图、感觉/神经诊断、掩码学习和登记对照工具 P0–P3 已独立验收通过；图为 166,700 节点、25,582,938 条内部连接，见 [Spec 007](../specs/spec-007-model-v2/spec.md) | 真实动作训练及 M4 研究待数据；阈值 3 等简化待受控实验，不是默认主图。本机每 50 ms 仿真窗约耗时 0.3 s，当前为离线运行 |
| 可训练 SNN 与目标跟随 | 用户已确认让网络内部学习 `vx/vz/wz`，当前仅 Mac；[Spec 008](../specs/spec-008-trainable-snn/spec.md) 处于 Planning | 先澄清 LIF 数值语义并测完整图内部参数更新成本，再定义目标、闭环环境与任务容差；尚未实现或训练 |
| 首批真实数据与读出评估 | 当前待验证阶段；采用 Tello 地面录像与人工期望动作标注 | 完整场景留出；报告方向、动作覆盖及神经读出相对视觉、均值、零动作基线的表现 |
| 新读出实体闭环 | 尚未接入实飞 | 在独立 Spec 中定义接入、设备约束、停止条件、延迟和失败记录，再由实体实验验证 |
| 移动底盘迁移与研究结论 | 已确认希望兼容的方向，实体型号与任务未定 | 明确共享部分和适配部分；报告迁移数据、微调及从零训练对照 |

用户确认的“先完成诊断与工具”阶段已完成。2026-10-17 的新目标把网络内部学习提升为主线；冻结脑读出保留为对照，采集真实录像不再是数值／训练可行性工作的唯一前置条件。受控重连、权重和通路干预工具见 [EXPERIMENT_V2](../docs/EXPERIMENT_V2.md)；完整 W 图已实际接通神经仿真，但没有动作对照效果证据。当前比较报告是描述性的，正式研究统计方案另需登记；研究图不作为设备可用的替代脑。
