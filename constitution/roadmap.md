# 路线与证据

当前主线是 **MaleCNS → 官方 AimDK/MC → 智元 X2**。用户已授权先清理仓库并本地提交，然后尝试 Mac Docker；本次清理不安装仿真或启动训练。

| 阶段 | 当前状态 | 下一项实际验证 |
|---|---|---|
| 完整数据与模型 | 完整神经元参考图、LIF、受约束内部学习与 GPU 工具已实现 | 原始数据与模型边界见 [MODEL_V2](../docs/MODEL_V2.md) |
| 神经活动可视化 | 三维胞体图谱、记录回放、可调刺激完整脑任务已实现 | 保持来源与模拟时间含义明确 |
| 官方 X2 环境 | 尚未搭建 | 独立 linux/amd64 容器的架构转译、官方 Sim/MC/AimDK 启动与通信 |
| X2 仿真闭环 | 尚未实现 | 先用官方指令验收站立/前进/转弯/停止，再接 MaleCNS 及反馈 |
| 上海现场适配 | 尚未实施 | 对齐现场型号、固件、MC/AimDK，验证相机/身体状态、命令、停止和接管 |
| 控制与研究效果 | 尚未证明 | 固定策略留出评估、冻结脑与拓扑对照及真实设备结果 |

既有目标跟随和单轴稳向属于历史实验。单轴两分支各 80 窗训练已结束，固定模型控制未达标；失败记录和原始数据保留，不追加训练，也不把稳向门槛当成 X2 环境的前置。详见[历史结果](../docs/EXPERIMENT_RESULTS.md)。
