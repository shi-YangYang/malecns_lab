# Decision 010 — 显式早期视觉背景工作状态候选

## Context

用户授权完整 MaleCNS 内部学习路线。P2b 的输入注释与 P0 方程显示：从完全静息出发，仅驱动 histamine 的 R1–R6 不能产生第一批非输入脉冲。该结论是[静态推论](../../specs/spec-008-trainable-snn/signal-observability.md)，不是完整图新实测。用户正在释放内存，尚未通知完成；本批只处理不依赖大图的数值实现。

## Decision

- 新增显式可选的 lamina tonic 模型变体；P0 与 P1 继续使用原来的严格无背景模型。完整图、原始连接、递质符号和外部输入集合保持不变。
- 仅按已校验图的原始类型精确选择 L1、L2、L3、L4、L5，每类型一个有界平衡电位偏移 `16 * sigmoid(rho)` mV，初始 rho=0，即8mV。这是待验证的工程假设，不是果蝇生理参数测量；不向下降神经元加入动作偏置。
- 背景项以解析系数 `(1-exp(-dt/tau_m))*offset` 加入 active 积分；保留这些细胞的不应期、复位和延迟语义。不能通过扩充 input_mask 实现背景。
- 变体独立记录模式、类型顺序、成员身份、参数公式和代码来源。原内部增益 checkpoint 暂时明确拒绝带额外参数或新动力学身份的模型，不能静默丢弃 rho；新策略的完整持久化另批实施。
- 后续完整图观测比较严格零背景、固定背景、可学习背景；冻结/训练内部增益的比较须使用同一背景条件。空白也可能产生自发活动，不能把它当作视觉通路贯通。

## Reason / Alternatives

这个最小扩展允许检验当前静息工作点是否妨碍视觉传播，并避免同时更换整个神经元动力学。直接全网改为分级电位模型会引入更大的假设与验证范围，暂不采用。无背景版本保留为独立对照，有限 rho 不能代表严格零。

## Consequences

数值通过只确认扩展按公式运行，不确认完整图传播、学习或控制。默认参数下无突触细胞首次跨阈值约需41.6ms，故未来可观测性协议必须登记充分预热与观察窗；P1原20ms内部更新协议不变。模型源码变化使代码身份变化，不能宣称旧 checkpoint 自动兼容。
