# Decision 017 — 本地 WebGL 神经活动展示

日期：2026-10-21。

用户采纳“脑活动可视化 → 机器人仿真闭环 → 现场设备”顺序，要求先完成可视化并咨询平台选型。选择本地网页、Three.js/WebGL 与 Python 只读导出，以现有完整 MaleCNS 诊断记录交付第一版。桌面安装壳、云服务与机器人适配延后，避免把它们作为展示的前置依赖。

前端新增于 `apps/atlas/`，Python 展示数据导出属于 `src/malecns_lab/visualization/`，不改训练与诊断核心。界面绑定真实来源的胞体位置及群组活动；缺坐标、累计统计、刺激重建、播放倍率与模型身份分别标注。三维果蝇仅是示意，无动作数据时不制造神经驱动的肢体动画。

源码与依赖锁文件可纳入版本控制；导出研究数据、node_modules、构建输出留在本地。验证按新子系统 S2 范围，执行定向导出检查、实际导出、前端构建与可用的浏览器交互验证，不运行训练或实机。

详见 [Spec 010](../../specs/spec-010-neural-atlas/spec.md) 与 [使用说明](../../docs/NEURAL_ATLAS.md)。
