# Decision 011 — 内存清理保留 Noria 服务

## Context

2026-10-19 用户要求检查能否训练，并允许清理无用内容。只读进程检查发现 Docker 正运行 Noria 的 control、runtime、Redis 和 PostgreSQL 四个容器。询问能否暂时停止服务后，用户明确回复：**“不可以，Noria 还在使用”**。

## Decision

后续为 CNSBridge 释放内存时，保留 Noria 容器及其 Docker Desktop / 虚拟机，不停止、暂停、删除或调整其资源。用户先前对“无用内容”的清理授权不包含这些在用服务。若用户今后明确改变此要求，以新指令为准。

## Reason

Noria 属于用户正在使用的另一项目；停止服务不是可自动执行的无用进程清理。

## Alternatives

继续只读评估其他明确闲置进程、等待可用资源变化，或按独立规格评估减少训练临时分配。任何方案仍须保留完整图与研究证据，不将删除磁盘文件当作释放所需运行内存。

## Consequences

本次没有停止 Noria 或 Docker，没有删除容器、镜像和数据。完整图内部更新仍未完成；当前资源阻塞不会因清理授权自动解除。该决定仅记录资源操作边界，不改变模型或实验协议。
