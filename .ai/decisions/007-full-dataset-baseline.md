# Decision 007 — 完整数据基线先于模型简化

## Context

用户明确要求基于完整官方数据集开展第二版模型研究。阈值 3 可以成为实验结论，但不能在没有实测时以旧代码默认值替代证据。本要求覆盖 Spec 007 初版沿用旧节点集合、以阈值 3 为主图的选择。

## Decision

1. 官方 v1.0 flat-connectome 发布数据完整保留为母本，登记发布阈值和每份文件用途；重复表示与派生子集不重复加入网络。
2. P0 依据官方身份定义逐 body ID 核实神经元全集。未知注释不能作为自动删除理由；原始片段图、确认神经元图、待定与非神经元记录分别对账，不能靠数量相同代替集合核验。
3. 完整神经元参考图保留全集间所有官方已发布非零连接、原始自连接及孤立节点，不额外剪弱边。旧 166,700 节点和 10,520,377 边仅是 V1 过滤图事实，不是 V2 固定规模。
4. 阈值 3、子图和去掉自连接均为独立简化候选。先取得完整基线结果，再预登记容差与预算，在同输入/动力学/标签等受控条件下比较响应、任务误差、耗时和内存；训练/验证选择后由独立测试确认。
5. 没有实测记录不称“实验得出”。完整模型资源不足就记录不足，不暗中剪图。后续派生版本不得覆盖完整参考图及其结果。

## Reason

数据来自真实连接组与模型完整使用发布数据是不同主张。需要先建立可追溯、未额外剪边的参考，才能评价删减是否损害信号与任务表现。不能把旧规则与代码一致当作规则已经实验证实。

## Consequences

本决定最初仅修改设计和规则；后续用户已授权按此实施。G/R/W 对照基于同一完整参考图，原始自连接在主重连/权重置换中固定，避免把删自环混进拓扑实验。原设计其余已确认内容不变；本决定优先于旧设计的阈值选择。

## P0 身份证据补充（2026-10-16）

[作者 bioRxiv v2 Methods / Annotations / Superclass](https://pmc.ncbi.nlm.nih.gov/articles/PMC12636603/) 明确："Bodies in the dataset are defined as neurons if they have a superclass." 这是已查阅的 2025-10-30 预印本方法，不冒充尚未取得全文的最终 Cell 论文。把此定义应用于完整 v1.0 注释，得到 166,700 个唯一神经元 body ID；旧 NPZ 恰好 ID 集合相同只是辅助核对，不能代替来源证明。

保留 2,194 个缺 type、94 个 tbc、2,094 个非 Traced 记录；不按这些普通注释或节点度数筛选。集合外 44,877 条注释分别登记，其中 11,864 条 Glia 明确归为非神经元，516 条 Traced/无 superclass 单列边界差异，仍保存在原始片段图。作者 v0.9 计数 notebook 的排除 tbc、只数连接端点与阈值分析不作为本参考图过滤条件。

逐 ID 清单、分类表、复现脚本、原始论文 XML 和来源/哈希保存在 `data/audits/malecns_v2_identity/`。升序 `official_neuron_ids_v1.csv` SHA256 为 `977260c45b258ebb72359475533e8c74bd65c95d9a9f6651f8f64efc5518a7be`。后续构图须用实际边扫描结果报告规模，不能用预期数字填充。此身份定义不保证形态、所有突触或全部生物细胞已被完美重建。
