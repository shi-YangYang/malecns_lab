# Decision 021 — 官方 X2 路线与仓库清理

日期：2026-10-21。来源：用户明确纠正设备为 X2，排除第三方控制器，并授权先整理、删除无用文件和冗余 Markdown 后本地 commit。

## 决定

- 使用智元官方 Sim + MC + AimDK，优先在现有 Apple Silicon Mac 的独立 linux/amd64 Docker 环境尝试；没有远程 Ubuntu 环境，不把远程机器当作当前前提。
- 后续到上海智元现场适配，因此需对齐现场机型与软件版本。RoboJuDo-Plus 等第三方步态方案不进入本项目主线。
- MaleCNS 负责高层动作目标，官方 MC 负责平衡和步态。首先搭建真实 X2 物理与官方命令闭环，再接脑模型；不先扩展单轴稳向研究。
- 清理单轴稳向网页/部署准备/未执行诊断，保留历史数值实验源码和原始数据；合并冗余过程文档，保留科学结论、必要规范及操作入口。

## 边界

本次仅清理与本地提交，不安装 X2、不运行训练、不推送。保留 data/、logs/、模型、录像、虚拟环境、Git 历史和来源许可，不操作 Noria/Docker。官方 Docker 在 ARM Mac 的转译、图形与运控兼容性均未实测；旧训练结果不能作为仿真接入成功证据。

此决定更新 Decision 019/020 的当前推进方向，历史结果保持原结论。任务见 [Spec 014](../../specs/spec-014-x2-repository-cleanup/spec.md)。
