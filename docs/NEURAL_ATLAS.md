# 本地神经活动图谱

浏览器 WebGL（Three.js）显示 MaleCNS 真实胞体位置与模拟神经群组活动。页面可查看已有刺激记录，或设置刺激运行完整脑。页面发起的实验使用现有固定 LIF 诊断模型。页面不启动训练和实体设备控制。前端依赖安装后从本地加载，不依赖 CDN 或外部大模型服务。

## 启动

在项目根目录 `/Users/yang/project/malecns_lab` 执行：

前端需要 Node.js 与 npm；本机使用 Node.js 24。Python 沿用项目虚拟环境。

```bash
.venv/bin/python -m pip install -e '.[atlas,data]'
.venv/bin/python -m malecns_lab.visualization.export
cd apps/atlas
npm ci
npm run dev
```

打开 `http://127.0.0.1:8765`。后续已有依赖和导出数据时，只需在 `apps/atlas` 执行 `npm run dev`，它同时启动网页与本地实验服务；终端按 Ctrl+C 结束。只查看已有记录时使用 `npm run dev:viewer`。首次导出需要本地完整参考图、官方注释和诊断记录；源码仓库不附带这些研究资产。

实验服务使用项目 `.venv`，监听 `127.0.0.1:8766`；网页通过同源代理访问。不要将其直接暴露到局域网或公网。新增的 `atlas` 可选依赖用于计算资源监控和读取官方注释，不安装 PyTorch，也不修改训练环境。

默认输入：

- `data/malecns_v2/full_reference.npz`：完整参考的节点及来源身份。
- `data/malecns_v1/body-annotations-male-cns-v1.0-minconf-0.5.feather`：官方胞体位置。
- `data/diagnostics_v2/standard_stimuli_20261016`：六种标准刺激的 V2 诊断回放。

默认导出：`apps/atlas/public/data/`。参数见 `python -m malecns_lab.visualization.export --help`。导出是新的展示产物，不改写原记录及其摘要，也不启动完整图重放。

生产静态文件可通过 `npm run build` 生成在 `apps/atlas/dist/`，再执行 `npm run preview` 本地查看。构建会复制当前导出数据，分享构建目录时需同时保留 MaleCNS 署名与数据说明。

## 怎么看

1. 选择静止、向左、向右、向上、向下或扩张刺激。
2. 播放、暂停或拖动时间轴，对照重建刺激、脑图颜色和群组放电率。回放倍率只改变播放速度，不改变仿真结果。
3. 旋转、缩放脑图，选择群组查看其记录曲线。相同色标用于比较不同刺激。
4. 查看来源与覆盖说明，确认模型、记录、完整节点数及有位置的节点数。

这组既有记录每段为 50 帧、20 Hz，包含 2 秒预热和 0.5 秒刺激观察。短记录可以放慢查看；不能把慢放时长当成模型实际经历的时间。

## 运行新实验

在“刺激响应”中：

1. 选择刺激、速度倍率、对比度和观察时长。首次可保留扩张、1倍、100%和0.5秒。
2. 点击运行，等待模型加载与逐帧计算；页面显示完成进度和实际等待时间。随时可以取消。
3. 成功后查看新生成的脑活动与曲线，或从实验列表重新打开结果。已有标准记录仍可切回查看。
4. 重复相同参数可比较可复现性；随后只改变一个参数，观察输入画面与响应如何变化。

每次包含额外2秒预热，完整图从独立初始状态运行。观察0.5秒对应50个输入帧、5000个神经步；每神经步0.5毫秒，合计2.5秒仿真时间。模型当前按CPU固定LIF路径计算，实际等待可能更长，不表示实时控制。

速度改变平移或扩张速度，对比度改变图像，不直接放大神经放电率。纹理种子7、神经种子0固定并保存。视觉输入无效、内存不足、超时或取消会如实显示；失败结果不会冒充完整实验。一次只运行一个计算任务，保留1GiB系统可用内存，不会关闭其他应用。

新实验保存在忽略目录 `data/atlas_experiments/`，包含参数、图和模型身份、输入帧、原始神经统计与浏览器回放资产。它们与旧诊断记录分开保存，不改写已有研究资产。

## 数据含义

- 点云位置来自官方 `somaLocation`，它显示胞体，不包含神经纤维形态，也不绘制全部突触连接。无坐标节点保留在完整参考统计中，不人为补位置。
- 动态色彩是**记录的群组平均放电率**。组内点共享该组颜色，不是每个神经元的逐时刻放电测量。未记录群组的背景点不编造动态活动。
- 模型是固定参数 LIF 诊断模型，**不是当前训练后的目标跟随策略**；新实验确实执行完整模型，完成后按仿真时间回放。画面不是活体记录，也不代表已实现实时控制。
- 旧记录的刺激画面按参数重建；新实验保存实际生成并送入模型的图像。二者均不是摄像头录像。
- 果蝇为静态形态示意，尚无肌肉、关节或完整果蝇物理仿真，也未接入设备。

缺少数据或格式不一致时应修复对应输入；页面和导出器不会回退到随机网络或假记录。
