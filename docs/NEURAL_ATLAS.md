# 本地神经活动图谱

第一版使用浏览器 WebGL（Three.js）显示 MaleCNS 真实胞体位置与已记录的模拟神经群组活动。Python 导出记录，Vite 提供本地页面；不需要 Electron、Tauri 或外部大模型服务，不启动训练和设备控制。前端依赖安装后从本地加载，演示不依赖 CDN。

## 启动

在项目根目录 `/Users/yang/project/malecns_lab` 执行：

前端需要 Node.js 与 npm；本机使用 Node.js 24。Python 沿用项目虚拟环境。

```bash
.venv/bin/python -m malecns_lab.visualization.export
cd apps/atlas
npm ci
npm run dev
```

打开 `http://127.0.0.1:8765`。后续已有依赖和导出数据时，只需在 `apps/atlas` 执行 `npm run dev`。首次导出需要 Python 的 `data` 可选依赖，以及本地已有的完整参考图、官方注释和诊断记录；源码仓库不附带这些研究资产。

默认输入：

- `data/malecns_v2/full_reference.npz`：完整参考的节点及来源身份。
- `data/malecns_v1/body-annotations-male-cns-v1.0-minconf-0.5.feather`：官方胞体位置。
- `data/diagnostics_v2/standard_stimuli_20261016`：六种标准刺激的 V2 诊断回放。

默认导出：`apps/atlas/public/data/`。参数见 `python -m malecns_lab.visualization.export --help`。导出是新的展示产物，不改写原记录及其摘要，也不启动完整图重放。

生产静态文件可通过 `npm run build` 生成在 `apps/atlas/dist/`，再执行 `npm run preview` 本地查看。构建会复制当前导出数据，分享构建目录时需同时保留 MaleCNS 署名与数据说明。

## 怎么看

1. 选择静止、向左、向右、向上、向下或扩张刺激。
2. 播放、暂停或拖动时间轴，对照重建刺激、脑图颜色和群组放电率。回放倍率只改变播放速度，不改变仿真结果。
3. 旋转、缩放脑图，选择群组查看其记录曲线。相同色标用于比较不同刺激。
4. 查看来源与覆盖说明，确认模型、记录、完整节点数及有位置的节点数。

这组既有记录每段为 50 帧、20 Hz，包含 2 秒预热和 0.5 秒刺激观察。短记录可以放慢查看；不能把慢放时长当成模型实际经历的时间。

## 数据含义

- 点云位置来自官方 `somaLocation`，它显示胞体，不包含神经纤维形态，也不绘制全部突触连接。无坐标节点保留在完整参考统计中，不人为补位置。
- 动态色彩是**记录的群组平均放电率**。组内点共享该组颜色，不是每个神经元的逐时刻放电测量。未记录群组的背景点不编造动态活动。
- 模型是这些记录对应的固定参数 LIF 诊断模型，**不是当前训练后的目标跟随策略**；画面是仿真回放，不是活体记录或实时推理。
- 刺激画面按记录参数重建，明确标注“刺激重建”；不冒充当时保存的摄像头视频。原生成器摘要与当前重建来源一并记录。
- 三维果蝇是形态示意，尚无肌肉、关节或运动物理仿真。没有动作记录时，界面显示动作和设备未接入，不用神经率硬编码编造行为。

缺少数据或格式不一致时应修复对应输入；页面和导出器不会回退到随机网络或假记录。

## 后续接入

当前边界为 `已有记录 → 导出契约 → WebGL 展示`。后续需要把活动采集接入真正执行控制的模型实例，复用展示层接入机器人仿真的动作和反馈；本版不声称已经实现该链路。浏览器展示可在需要安装包时再装入桌面壳，模型计算仍可保持独立进程。
