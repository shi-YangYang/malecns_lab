# 连接组数据与模型契约

本文统一记录完整 MaleCNS 参考资产、数据身份和 V2 离线模型的约定。可训练 LIF 与全 DN 策略见[神经计算](neural-model.md)，运行入口见[离线研究](../research/offline.md)。审计过程与阶段结果见 [Spec006](../../history.md#spec-006) 和 [Spec007](../../history.md#spec-007)。

## 官方来源与审计边界

母本为官方 MaleCNS v1 flat-connectome 发布数据；[官方下载说明](https://male-cns.janelia.org/download/)区分完整神经元和未归属片段。完整 weights 表是有突触片段之间的连接图，`minconf-0.5` 已包含官方置信度筛选，不是筛选前全部显微数据。

- 下载清单保留全部 11 个官方文件的版本、对象 generation、大小与哈希。派生子集仅核对对应关系，不与全量表拼接后重复计边。
- `body-annotations`、`body-neurotransmitters` 和完整 `connectome-weights` 构成图的主要来源；增加下载文件不会自动更新已保存 NPZ。
- 按作者 Methods 的 superclass 身份边界确定神经元集合，不增加 type、status、side 或度数筛选。当前参考资产为 **166,700 节点、25,582,938 条有向边、124,177,617 个突触**。
- 神经元间全部已发布非零连接、原始自环、孤立节点和未知递质节点均保留。`min_synapses=1` 表示不额外剪掉弱边。
- 未归属片段及其连接须保留可追踪分类。神经元参考图不等于包含所有原始 segment 的图，也不等于完整生物重建。

2026-10-16 的 V1 审计对应提交 `747a8aa38031ed927d121afbb85aaf9643256612`：旧过滤图有 10,520,377 条边，采用阈值 3 并删除自环。固定节点并统一排除自环时，阈值 1→3 删除 58.88% 的边和 15.97% 的突触计数；比例不是功能损失或生物还原程度。该旧图不能冒充当前完整参考图。

旧输入遗漏的长期教训：R1–R6 应使用其 rootSide，不能全图用 somaSide 替代；haltere 应按 subclass 选择，不能用 type 名称列表代替。旧校准输出混入固定巡航和逃逸规则，不能作为学习教师或神经动作能力证据。详细统计仍在 `data/audits/malecns_20261016/`，原始数据、脚本和模型不随文档合并删除。

### 注释与递质

节点保留 body ID、type、superclass、subclass、status、somaSide、rootSide、递质标签及各自缺失标记；缺失、空串与字符串值不能混为一类。派生侧别另记 `resolved_side / side_rule`，不覆盖原注释。

连接符号按突触前细胞 `consensus_nt` 统一赋值：acetylcholine 为正；gaba、glutamate、histamine 为负；dopamine、octopamine、serotonin 及未知值按现有模型取正。没有逐突触递质概率或额外弱兴奋缩放。未知递质默认正号是建模假设，必须在来源中公开，不作为删点理由。

精确突触总数以原始 int64 计数求和，不能用 float32 累加值替代。一个有向端点对是一条边，weight 是该边的突触数量，两者分别报告。

### 构建与身份

已有参考资产直接使用；重建必须写新目录：

```bash
.venv/bin/python -m malecns_lab.brain.reference \
  --data-dir data/malecns_v1 \
  --identity-dir data/audits/malecns_v2_identity \
  --out-dir data/malecns_v2_rebuild
```

`graph_id` 绑定来源哈希、版本、节点顺序、过滤规则与带符号权重。`source_id` 再绑定选组、感觉/时间协议、LIF、偏置、特征顺序和实现源码；输入事件种子与重连种子另记为运行身份。改变行为的参数或源码需要新身份与新产物，不能修改旧哈希伪装兼容。

阈值、子图或删自环只能另存为简化候选。先有完整基线，再固定数据、输入、预算与非劣容差进行配对比较；资源不足应记录未完成，不自动裁图或回退 MiniFly/合成网络。

## V2 离线模型的职责

```text
图像与时间 → 显式视觉编码 → 完整图冻结 LIF → 因果活动历史
                                                ↓
独立动作标签 → 离线拟合/评估 → 掩码读出 → FLU 期望运动
```

标签不进入感觉编码或脑仿真。固定巡航、阈值逃逸、旧 `MotorDecoder` 不进入主模型。拟合截距须与训练均值基线比较，恒定前进不是刺激驱动证据。

V2 是冻结脑的线性可解码性研究，与后续 0.1 ms 可训练核心是不同数值协议。保留已有 `flydrones.*`、`cnsbridge.*` 序列化标识，不随包名变化改写旧资产。

### 观察与动作记录

| 字段 | 单位/形状 | 约束 |
|---|---|---|
| `session_id / scene_id / source_family_id` | 非空字符串 | 会话、场景与同源素材族，用于隔离数据 |
| `frame_id / image` | 递增整数；H×W×3 uint8 | 显式 BGR，不猜测 RGB |
| `video_time_s / timebase` | 秒 | 旧 AVI 使用播放时间，严格递增 |
| `host_dequeue_time_s` | 可空秒值 | 取帧诊断，不等于曝光时刻 |
| `frame_valid / invalid_reason` | 布尔/原因 | 缺帧、解码失败和损坏明确标记 |
| `flow_quality / flow_valid` | 网格质量/掩码 | 无纹理的未知运动不能当可靠零运动 |
| `telemetry` | 值、单位、时间、来源与有效性 | 未对齐时钟或坐标时标无效，不补零 |
| `stimulus` | 区间标注 | 相机/物体运动、遮挡等刺激属性，不是动作标签 |

动作使用 `(vx,vy,vz,wx,wy,wz)`，机身 FLU（前、左、上）；前三轴 m/s，后三轴 rad/s，正 `wz` 左转。逐样本保存 `values / supervised_axes`、`target_time_s`、`policy_id / teacher_id / reason`。V2 首期仅监督 `vx/wz`，未知轴或区间不填成零标签。

预测另有 `supported_axes / prediction_valid`。未训练轴不代表会悬停；局部物体上移不自动标成上升；旧 RC、实测速度或旧控制器输出不是默认期望动作教师。Tello 正偏航命令向右，适配正 `wz` 时须反号。期望 SI 速度与实测速度、RC 比例分别处理；安全监督记录原始/执行目标与介入原因。

### 因果时间与重置

V2 固定使用 20 Hz 播放时钟：`t_k=k×0.05 s`。使用 `t_k` 及以前图像，驱动 `[50k,50(k+1)) ms`，预测 `t_k+0.05 s` 的动作。最后一步缺少段内目标则不评分；不能将这一目标时距解释为真实相机延迟。

| 神经字段 | 定义 |
|---|---|
| `feature_body_ids` | 六组并集 33 个节点，body ID 数值升序 |
| `spike_counts / rates_hz` | 每 50 ms 整数计数与 `count/0.05`；输入驱动率另存 |
| `history / history_valid` | 当前和此前 3 窗，共 200 ms，最旧在前，132 维 |
| `input_cutoff_s / decision_time_s` | 最新可用图像时刻/目标时刻 |
| `sim_start_ms / sim_end_ms / processing_ms` | 神经模拟时间与墙钟耗时分开 |
| `neural_valid / reason` | 预热、历史不足、无效输入、非有限值分开 |

每个独立连续片段重置视觉 EMA、膜电位、突触状态、不应期、延迟队列、随机流和读出历史；最初 2 s 用已提供图像预热，不训练或评分。有效但未标注帧仍推进网络；不得读取后续图像预热。

解码错误、倒退时间、未解释缺口、任一半幅必需运动估计失败时，当前步不生成率、不推进脑或视觉历史，结束该片段；保留有效前缀和失败原因。不补零、不持旧值、不跳坏帧假装连续。后续片段必须事先按输入有效性规则登记，保留原素材族并重新预热。全零放电属于有效观测。

### V2 群组与视觉编码

| 群组 | 选择规则 | 当前参考成员 |
|---|---|---|
| R1–R6 | `type=R1-R6`，该类按 rootSide 分侧 | L 1,112；R 2,265 |
| HAL 候选 | `subclass=haltere`，按 rootSide | L 104；R 101；主实验 disabled |
| T4/T5、LPLC2、LC4 | 保留经审计的 type 与适用侧别规则 | 成员 body ID 随身份保存 |
| DNg02、DNp03、DNp01 | 固定六组，body ID 排序 | 共 33 个只读探针，不是裁图边界 |

HAL 的零驱动表示禁用，不表示测得零角速度。设备偏航率到 haltere 的映射是另外的编码假设。输入覆盖修复同时改变总驱动，须同时记录每群人数、每节点率与实际总事件数。

图像缩为 96×72，BGR 灰度权重 `(0.114,0.587,0.299)`；每半幅 6×8 网格，光流以缩小图像 px/s 计。左右半幅是工程分区，不能称实测双眼视场。同群节点接收同一聚合率，不按索引臆造空间位置。

| 每半幅特征 | 定义 | 输入群/最大 Hz |
|---|---|---|
| brightness | 灰度均值 0–1 | R1–R6 / 40 |
| ftb/btf/up/down | 逐格整流，px/s 除 24，截至 0–1 后按有效格平均 | 对应 T4/T5 / 120 |
| loom | `e=min(ex,ey)`，s⁻¹；`clip((EMA(e)-0.1)/0.5,0,1)`，EMA 0.1 s | LPLC2 / 200 |
| loom_speed | `clip(max(0,(loom_t-loom_prev)/Δt)/5,0,1)` | LC4 / 150 |

率为 `max_hz×feature`。扩张拟合须满秩且有限，记录每半幅有效格数与比例；无有效光流、扩张不可辨识或非有限分别报 `no_valid_flow`、`unidentifiable_expansion`、`nonfinite_expansion`。两半幅都验证后才能更新 EMA。新片段第一帧可零运动初始化并使用亮度驱动，但只用于预热；此例外不能掩盖随后低纹理失败。

视觉特征由脑外计算，且同时注入早期和下游群，绕过部分生物视觉计算。映射、颜色或时间改变须重新提取缓存。

### 冻结动力学与学习范围

V2 参数：`v_rest=v_reset=-52 mV`、`v_th=-45 mV`、`tau_m=20 ms`、`tau_syn=5 ms`、`t_ref=2.2 ms`、`delay=1.8 ms`、`w_syn=0.275`、`poisson_factor=250`、`dt=0.5 ms`、`noise_mv=0`。实际离散延迟/不应期另存；DNg02 左右 8 mV 持续偏置是人为先验。

同编码与种子下，外部事件由输入 body ID 和仿真步确定，不因图遍历、内部发放或消融改变随机流。无膜噪声仍不等于无随机输入；当前事件为每步至多一次的 Bernoulli 近似。

阶段 A 仅拟合逐轴岭读出、截距与训练统计，验证集选择 `10^-4,…,10^4` 九个候选。输入增益和内部类型参数属于另行登记的实验，不能将冻结 NumPy/SciPy LIF 当作已有自动微分通道。33 细胞负结果也不能断言全连接组无用。

## 数据隔离与证据标准

同素材的裁剪、增强、不同输入种子不可跨 train/val/test；共享场景、会话和素材族按独立簇处理，帧数不是独立样本量。训练拟合统计，验证选参，确认协议冻结后才使用测试集；查看测试后改规则，应降为开发数据并另收测试材料。

比较必须保留同一因果输入、状态重置、预热、有效性与评分行，不静默求交集。每图/种子独立训练同容量读出，输入种子与拓扑种子分开。直接视觉基线含 14 通道×4 窗，再加 0.05/0.2/1 s EMA，共 98 维；神经为 132 维，参数量差异须报告。

主误差先在每场景/轴求 MAE，按预登记 SI 容差归一化，再等权聚合场景/轴/种子。配对改善 `Δ=对照误差−神经误差`；95% 簇区间下界严格大于实用量 δ 才支持该比较的实用优势，上界严格小于 δ 表示未支持达到该量，跨越或接触 δ 为证据不足。条件不足不生成区间，也不把“无优势证据”称为等效。

记录零覆盖场景、失败、预热、未提取尾段、静默/高频分布、延迟及资源，不能以剔除不利图/场景制造优势。图间随机性、多重比较和随机图排名检验需要另行登记；现有工具不自动证明随机化交换性或确认性显著。

完整图神经响应、离线可解码、闭环任务成功与真机效果是四种证据。读取真实图、出现放电、参数有变化或单次短窗较快，均不能替代后续层级的验收。
