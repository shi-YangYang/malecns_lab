# MaleCNS 第二版模型设计

第二版研究真实连接组产生的神经活动能否支持可学习、可迁移的运动读出。保留 MaleCNS 图与 LIF 仿真基础，重建感觉输入、活动契约和实验对照；先做离线 `vx/wz` 任务，再按证据推进闭环。本文定义设计约束；[Spec 007](../specs/spec-007-model-v2/spec.md) 的 P0–P3 工具已验收完成，操作分别见 [完整脑诊断](MODEL_V2_USAGE.md)、[掩码学习](LEARNING_V2.md)和[研究对照](EXPERIMENT_V2.md)。真实动作模型尚未训练，也未接入设备；M4 确认研究仍未完成。

## 现状与设计边界

[审计](MALECNS_AUDIT.md)确认现存 V1 过滤图与构建规则一致：166,700 个节点、10,520,377 条连接。这不是 V2 完整图的定义；旧 `min_synapses=3` 尚无本项目实测支持，不能作为已经验证的选择。主要问题包括 R1–R6 亮度输入只覆盖 13/3,377 个候选、HAL 群组为空、视觉网格按节点索引分配，以及动作读出混入固定巡航等规则。没有证据要求先替换整个 LIF 引擎。

| 层 | 第二版处理 | 保留的限制 |
|---|---|---|
| 数据与图 | 从完整官方发布数据建立神经元完整参考图，补齐元数据与来源身份 | 官方发布边界、神经元身份与未归属片段分开记录；完整下载不等于完整生物重建 |
| 神经动力学 | 沿用稀疏 LIF，先冻结并核查数值与时间契约 | 点神经元、统一参数、递质符号与偏置仍是建模假设 |
| 感觉输入 | 修正选组、颜色、时间单位；群组聚合驱动 | 外部软件计算视觉特征，左右半幅是工程分区 |
| 学习读出 | 复用岭回归基础，增加掩码、因果历史及公平对照 | 先验证线性可解码性，不预设一定成功 |
| 设备与工具 | 复用记录、回放、诊断和数值适配 | 设备安全监督与模型行为分开，旧实飞不是新读出的证据 |

本文不恢复 MiniFly，不创建缺失数据回退，不训练全脑每条突触，不把加载真实图称为恢复果蝇认知。旧图、旧读出和日志只读保留，作为历史参照。

## 分层数据流

```mermaid
flowchart LR
    V[图像与时间] --> E[显式感觉编码]
    E --> N[MaleCNS 约束的 LIF]
    N --> H[因果神经活动历史]
    H --> D[可训练读出]
    D --> M[带轴掩码的 FLU 运动目标]
    M --> A[设备适配与安全监督]
    A --> R[无人机或移动底盘]
    L[独立任务标签] --> T[离线训练与评估]
    H --> T
    T --> D
```

主模型只有感觉输入、神经计算和学习读出。标签不进入感觉编码或脑仿真；固定巡航、阈值逃逸及旧 `MotorDecoder` 不进入主模型。学习截距属于拟合结果，必须与训练均值基线比较，不能把恒定前进解释为刺激驱动。

## 数据与接口契约

以下定义设计语义，具体落盘字段见 [V2 诊断](MODEL_V2_USAGE.md)和[掩码学习](LEARNING_V2.md)接口。记录采用独立 V2 格式版本；已有 `flydrones.*` 标识不批量改名，新格式不冒充旧格式。

### 观察记录

| 字段 | 类型与单位 | 约束 |
|---|---|---|
| `session_id / scene_id / source_family_id` | 非空字符串 | 会话、独立场景、同源素材族；用于隔离数据 |
| `frame_id / image` | 递增整数；H×W×3 uint8 | 原始 BGR，颜色顺序显式声明；不自动猜测 RGB |
| `video_time_s / timebase` | 秒；枚举 | 旧 AVI 为 `video_playback`；时间严格递增 |
| `host_dequeue_time_s` | 可空秒值 | 主机取帧时间，仅作采集节奏诊断；不是相机曝光时间 |
| `frame_valid / invalid_reason` | 布尔值；字符串 | 缺帧、解码失败和损坏使图像失效；无纹理不等于缺图 |
| `flow_quality / flow_valid` | 质量值与有效性标记 | 按网格记录运动估计可靠性；不能把无纹理区域的未知运动当作可靠零运动 |
| `telemetry` | 可空的带来源记录 | 每项含值、单位、时间戳、有效性和时钟对应关系 |
| `stimulus` | 独立区间标注 | 固定相机/相机移动、物体移动、方向、遮挡和刺激类别；不是动作目标 |

遥测候选采用机身 FLU 的角速度 rad/s、速度 m/s；高度另有参考系和 m。SDK 原始值须经适配并保留原值及来源。没有可靠时钟对齐或坐标转换时标为无效，不能填零冒充测量。

首期复用原记录器的 20 Hz 播放时间：第 k 帧 `t_k=k×0.05 s`。流速使用该时间基准，不声称等于真实采样速度。主机时间抖动另报；不根据结果好坏在两种时间基准间切换。原生可变帧率或曝光时间协议另行版本化。

### 神经观察与时间

| 字段 | 类型与单位 | 约束 |
|---|---|---|
| `source_id / graph_id / encoder_id` | 内容摘要 | 绑定图、映射、动力学、源码及输入协议 |
| `feature_body_ids` | 固定顺序 ID 列表 | 首期为现有六组并集的 33 个节点，按 body ID 数值升序 |
| `input_cutoff_s` | 视频秒 | 当前结果使用的最新图像时间，不能引用更晚图像 |
| `sim_start_ms / sim_end_ms` | 仿真毫秒 | 每步推进 50 ms；与 CPU 处理耗时分别保存 |
| `spike_counts / rates_hz` | 整数计数；Hz | 每节点每 50 ms 的计数与 `count/0.05`；输入驱动 Hz 单独保存 |
| `history / history_valid` | 4×33 数组；掩码 | 当前及此前 3 个完整窗口，共 200 ms；最旧窗口在前 |
| `decision_time_s / processing_ms` | 视频秒；墙钟毫秒 | 目标时间与计算耗时不互换；迟到结果不是新观察 |
| `neural_valid / reason` | 布尔值；字符串 | 预热、历史不足、输入失败、非有限值等明确区分 |

首期时间对齐固定为：使用 `t_k` 及以前的图像计算输入，驱动 `[50k,50(k+1)) ms` 仿真，预测 `decision_time_s=t_k+0.05` 的期望动作。此时没有使用下一帧；它是固定一个步长的动作目标时距，不是相机真实延迟估计。最后一步没有相应标签则不评分。视觉对照采用完全相同的输入截止点和目标时距。

每个独立会话或显式新建的连续片段重置 Retina、全部视觉 EMA、LIF 膜电位、突触状态、延迟队列、随机流和读出历史，并记录片段身份与初始化种子。最初 2 s 按真实已提供帧预热，不训练、不评分；输入有效但未标注的帧继续推进网络。不得读取后续帧预热，也不按训练标签切换状态。

解码错误、时间倒退、无法解释的帧缺口，以及下述必需运动估计失效，均采用 fail-closed：当前步不生成任何群组输入率，不推进 LIF、读出历史或视觉 EMA；只记录 `neural_valid=false`、`prediction_valid=false` 与失败原因，不产生可用预测，不进入训练或评分，并结束当前连续提取片段。已完成的有效前缀保留；不补零、不持旧运动值、不跳过缺口后继续假装连续。允许按预登记的输入有效性规则从后续区间显式建立新片段，保留原素材族和分区，重置全部状态并重新 2 s 预热；不能按标签或模型得分挑选片段。全零放电是可记录的有效观测，不是缺失；持续静默与持续高放电作为诊断单独报告。

### 目标与预测记录

| 字段 | 定义 |
|---|---|
| `axes / frame / units` | `(vx,vy,vz,wx,wy,wz)`；FLU 前、左、上；前三轴 m/s，后三轴 rad/s，正 `wz` 左转 |
| `values / supervised_axes` | 六维期望速度与逐样本六轴监督掩码；首期只监督 `vx/wz` |
| `target_time_s / interval` | 与 `decision_time_s` 同一视频时间基准；标注区间左闭右开 |
| `policy_id / teacher_id / reason` | 标签规则版本、标注者或教师身份、选择依据 |
| `supported_axes / prediction_valid` | 模型已训练轴与预测有效性；未训练轴不默认为已掌握 |

未标注轴可以有零占位，但损失和指标必须排除；完全未标注区间不生成训练目标。首期不把 `vz=0` 解释为会悬停，也不把局部物体上移自动标为上升。旧控制器输出、RC 数值和实测速度均不是默认教师。

设备适配只接受可用且受支持的轴；Tello 既有正偏航向右，转换正 `wz` 时须反号。输出是期望速度，不是精确实测速度；RC 比例需独立标定。未来监督记录 `raw_target / applied_target / intervention_reason`，不把安全裁剪或停机效果计入模型能力。

## 真实图与感觉编码

### 图构建和身份

完整的官方 MaleCNS v1 flat-connectome 发布数据是 V2 的数据母本。保留全部原始表及下载清单、版本和哈希；11 个文件中的派生子集用于对应关系核对，不与全量表拼接后重复计边。官方权重表的 minconf 0.5 是发布边界，不称为置信度过滤前的全部原始数据。

P0 先按官方神经元定义建立完整 body ID 清单，并逐项对账官方口径、原始 segment 图和注释。不得预设旧 166,700 节点集合正确，也不得仅因普通注释缺失而静默删除神经元。本次已查证作者 Methods 明确用 superclass 界定 neuron；按这个有出处的身份边界得到 166,700 个神经元，没有附加 type、status、side 或度数过滤。逐 ID 证据和片段边界见 [Decision 007](../.ai/decisions/007-full-dataset-baseline.md)。未归属片段及其连接保留可追踪记录，明确是否进入神经元参考图及依据；不能当成完整神经元，也不能丢弃后声称保留了全部原始 segment 图。以后更换数据版本仍须先核实身份，不回退 V1 冒充完整图。

神经元完整参考图保留该全集之间所有官方已发布的非零连接；`min_synapses=1` 表示不再额外剪除弱边。原始自连接、孤立节点和无已知递质的神经元均保留。节点、边和突触数由该定义实算，不使用旧图数字作目标数量。

节点清单保留 body ID、type、superclass、subclass、status、somaSide、rootSide、递质标签及缺失状态。侧别选择结果另存 `resolved_side / side_rule`，不覆盖原字段。未知递质沿用正号时必须标为模型假设而非数据事实，后续符号敏感性须另作登记；缺失符号不能成为隐含删点理由。

`graph_id` 覆盖源文件哈希、版本、节点顺序、过滤规则和带符号权重；`source_id` 再覆盖选组、视觉与时间协议、LIF、偏置、特征顺序和相关源码。种子及输入事件身份属于运行身份，和图身份分开保存。任何行为变更生成新身份及独立产物。

### 简化必须由实测支持

阈值 3、子图或删自连接只能成为另存的简化候选，不能预先替代完整参考图。先运行完整基线，记录节点/边/突触保留情况、神经响应、任务误差、延迟和峰值内存；随后固定数据、编码、动力学、输入种子和训练预算，对每个候选独立训练并作配对比较。

候选范围、质量非劣容差和资源预算须在比较前登记；只用训练/验证数据选择阈值，独立测试集验收，不按测试结果修改容差。记录官方来源、建模假设、待测候选与实际测量四类证据。完整图资源不足时如实报告未完成基线及资源缺口，不自动裁图，也不将候选写成实测结论；采用简化后仍保存完整参考图与差异清单，不把简化图称为完整图。

### 按注释选组

| 群组 | V2 首期选择依据 | 审计基准 |
|---|---|---|
| R1–R6 | `type=R1-R6`，该类按 rootSide 分侧 | L 1,112、R 2,265；全部 3,377 应被覆盖 |
| HAL 候选 | `subclass=haltere`，按 rootSide 分侧 | L 104、R 101；205 个，不依赖 type 非空 |
| T4/T5、LPLC2、LC4 | 保留审计确认的 type 规则与现用侧别，并保存成员 | 与审计清单逐 ID 比较，不把 rootSide 全图替代 somaSide |
| DNg02、DNp03、DNp01 | 保留现有六组成员，按 body ID 固定读出 | 合计 33 个；变化须失败或升版，不静默补零 |

HAL 主实验标为 `disabled`，候选群组仍接受覆盖检查；零驱动表示实验禁用，不表示测得角速度为零。将设备偏航率映射为 haltere 输入是后续独立假设，需要对齐遥测、剂量与符号协议，不能直接称为生物等价。

R1–R6 覆盖扩大也会改变总外部驱动。P1 同时记录每群人数、每节点率、总输入事件数、静默与高放电分布；不能把修复前后的行为差异归因于一个未经隔离的因素。

### 首期视觉特征

图像缩为 96×72；BGR 灰度权重为 `(0.114,0.587,0.299)`。保留每半幅 6×8 网格作为特征提取网格，计算局部光流，使用相邻图像时间差得到缩小图像的像素/秒。颜色纠正和时间归一化均产生新编码身份，不复用旧特征缓存。

每个半幅得到亮度、ftb、btf、up、down、loom、loom_speed 共 7 个聚合量。方向特征先逐格整流、归一化，再取有效网格均值；亮度取均值。左右半幅及 ftb 镜像约定属于工程编码，不表示真实双眼视场；没有解剖位置依据时，同群所有节点接收同一个率，不按节点索引分配网格。

初始参数如下；它们是可复现的工程默认值，需在训练/验证 pilot 中检查刺激响应后冻结，不能据测试结果回调：

| 特征 | 定义与初值 | 驱动群与最大 Hz |
|---|---|---|
| brightness | 灰度均值，范围 0–1 | R1–R6，40 |
| ftb/btf/up/down | 对应方向的像素/秒除以 24，再截到 0–1；原始光流估计及纹理权重另存 | 对应 T4/T5，120 |
| loom | 对光流与实际网格中心像素坐标拟合扩张率 `e=min(ex,ey)`，单位 s⁻¹；`clip((EMA(e)-0.1)/0.5,0,1)`，EMA 时间常数 0.1 s | LPLC2，200 |
| loom_speed | `clip(max(0,(loom_t-loom_prev)/Δt)/5,0,1)`；记录变化率 s⁻¹ | LC4，150 |

扩张按每半幅独立估计，输入率 `rate_g=max_hz_g×feature_g`。每半幅均为必需输入：部分网格有效时，只用有效网格聚合方向量、拟合扩张，并记录各半幅的有效网格数及其占 48 格的比例；扩张拟合仍须有足够几何约束、设计矩阵满秩且结果有限。任一半幅无有效运动网格，或扩张不可辨识/非有限，即按上述 fail-closed 规则停止片段；记录侧别及 `no_valid_flow`、`unidentifiable_expansion` 或 `nonfinite_expansion`。先验证两半幅估计，再更新 EMA、生成输入率与推进网络，不能将已处理半幅的状态更新带入失败步。

每个新片段的第一帧因没有前帧，允许唯一的初始化例外：保存当前图像，运动特征和运动 EMA 从零启动，亮度按图像计算，并在预热期驱动网络；该帧不训练、不评分，也不产生可用预测。此例外只针对缺少前帧，不豁免图像自身有效性，也不能用来补偿后续低纹理或拟合失败。第一版同时向早期和下游视觉群注入，明确绕过部分生物视觉计算；“仅早期输入”属于后续独立编码实验。

## 神经计算与可训练参数

### 阶段 A 的固定底座

首期沿用当前 LIF：`v_rest=v_reset=-52 mV`、`v_th=-45 mV`、`tau_m=20 ms`、`tau_syn=5 ms`、`t_ref=2.2 ms`、`delay=1.8 ms`、`w_syn=0.275`、`poisson_factor=250`、`dt=0.5 ms`、`noise_mv=0`。保存离散实现后的实际延迟/不应期；不能把名义参数当成步长未量化的数值。

DNg02 左右各保留 8 mV 持续偏置，明确是人为驱动先验。所有主图对照使用相同偏置；0 mV 另作预先登记的敏感性条件，不能只给某个图调偏置。无膜噪声仍有随机输入事件，不能称为完全无随机性。

输入事件流由运行种子、输入 body ID 与仿真步定义；同一编码条件与种子下，各图复用完全相同的外部事件流。避免因遍历顺序、消融群组或内部放电数量改变抽样序列。每个图另有独立重连种子，和输入事件种子分开。

读出使用 33×4=132 维逐细胞历史；六组均值仅用于诊断，不替代主特征。33 个记录节点只是只读探针，不是裁图边界；其它脑区即使不被读出，也仍在 P0 确认的完整参考图中传播。

这 33 个细胞是隔离变量的首期读出假设，不是 MaleCNS 全部运动输出。若失败，可基于训练/验证诊断另版扩展下降神经元集合，所有图须采用相同选点、维数和搜索预算；不得看测试集选点，也不能由这 33 个细胞的负结果断言全连接组无用。

### 训练阶段与进入条件

| 阶段 | 训练或选择的参数 | 冻结部分 | 方法与进入条件 |
|---|---|---|---|
| A 读出基线 | 每个有效轴的岭回归权重、截距；训练集均值/尺度；验证集选岭系数 | 图、符号、突触值、LIF、偏置、编码、输出 ID 与历史 | 输入覆盖、时间、因果性和数据隔离通过后开始；主轴 vx/wz |
| B 输入适配 | A 加少量输入群组增益 | 拓扑、符号、LIF、输出集合 | A 的标签与对照有效，且响应诊断显示输入增益是具体瓶颈；预登记范围后用有限预算黑盒搜索 |
| C 受约束动力学 | A/B 加少量类型共享参数，例如时间常数或非负突触缩放 | 节点、拓扑、连接符号和未登记参数 | B 后仍有明确动力学瓶颈；数值稳定边界和参数计数先固定，独立 Spec 才实施 |

阶段 A 按轴掩码拟合；标准化统计只由训练分区计算，零方差特征尺度设为 1。各轴缺标签的样本不进入该轴损失。训练标签只覆盖两轴时，其他四轴不生成“已训练”的权重或指标。

初始岭系数候选为 `10^-4,10^-3,…,10^4`，所有条件相同；由验证场景的预定主指标选择，不能使用训练拟合 R² 选模型。主比较先保持 132 维线性读出；容量扩展需为所有相关条件提供相同搜索机会。

B 的首个候选为七类视觉通道的共享非负增益，左右绑定，倍率范围 `[0.5,2.0]`，其它编码常数冻结。它只是一套待阶段登记确认的候选边界，不授权本轮运行；搜索预算和优化目标确定后才能训练。避免以独立左右增益偷偷补偿某次测试场景。

C 优先选择少量类型共享参数，不直接逐边优化完整图；正缩放不能翻转符号，不添加缺失连接。当前 NumPy/SciPy LIF 没有可假设存在的自动微分通道；B/C 可用有界搜索，若引入代理梯度或替换引擎，另立架构与数值验证方案。不能把“计划训练”写成已支持端到端反传。

已有 `RidgeMotionDecoder` 可以复用计算与保存思路，但当前逐轴监督掩码、V2 时序身份、独立验证选择及下述对照尚未实现。不得只调用现有 fit 就声称满足本设计。

## 数据划分与任务标签

第一轮任务定义为：给定当前及历史视觉输入，预测独立协议指定的平面期望速度。协议必须在标注前说明停止、前进、左右转的语义、幅度、允许的组合与反应时间。固定相机前移动手机只能覆盖局部物体刺激，不能代替飞行中的自运动分布。

先以场景、采集会话和素材族建立分组清单，再分训练/验证/测试；同一来源的裁剪、重放、增强和不同输入种子不得跨分区。相同布景或物体造成的相关性要体现在分组策略中，不能只换文件名充当独立场景。

训练分区拟合统计、读出；验证分区选择参数、窗口或编码候选；测试分区在确认协议冻结后才使用。若看过测试结果再改增益、选组、神经元或时距，须降级该测试集为开发集并另建未见数据。不能把不同种子当新增独立场景。

先标刺激用于输入与放电诊断，再按独立任务协议标目标。标签文件保存版本、来源、轴掩码和不确定区间；不确定样本明确排除监督或使用事先固定的权重规则。没有动作标签时可以完成神经诊断，不能虚构动作准确率。

## 验证真实连接组的作用

### 实验条件

| 条件 | 保持与改变 | 能回答的问题 |
|---|---|---|
| G 真实图 | P0 完整参考图，固定工程输入、真实拓扑与原权重、独立训练读出 | 当前建模条件下是否可解码 |
| R 受控重连 | 同一完整母图，固定节点和输入输出身份；仅交换非自环边 | 真实连线组织是否优于指定随机图族 |
| W 权重置换 | 同一完整母图，固定拓扑和源符号；每个源内打乱非自环出边权重 | 权重分配到具体目标是否有贡献 |
| V 直接视觉 | 同样可用的视觉特征、因果历史和标签，绕过脑 | 相对工程视觉特征是否有额外收益 |
| M/Z 均值与零 | M 仅取训练分区各轴目标均值；Z 固定零 | 是否只学会动作先验或多数静止 |
| P 通路干预 | 预先指定视觉输入或中间通路，配规模匹配干预 | 特定传播是否相关，而非任意损坏都下降 |

旧人工读出只作历史描述，不作为训练教师或主竞争基线。图改造全部标为 `research_control`，只允许离线研究接口加载；主模型加载器、默认路径、设备入口必须拒绝这些资产。它们不是替代飞行网络或缺图回退。

### 重连的精确定义

G/R/W 都由同一完整参考图派生，原始自连接及其权重在 R/W 中固定不动，不得在对照中暗中删除。R 选取同符号源节点 `u,w` 的两条非自环有向边 `u→v,w→x`，改为 `u→x,w→v`；原 `u→v` 权重留在 u 的新出边上，w 同理。拒绝新增自环、重复边、无效或不改变图的交换；输入输出节点身份与所有节点元数据不变。

该操作保持逐节点入度/出度、逐目标正负入度、逐源出强度，以及总体有符号权重分布；**不保持每个目标的入强度、空间组织、类型间连接、具体可达路径或模体**。因此结果只支持相对于此随机化家族的结构比较，不能独立排除所有权重入强度或解剖因素。

保存随机种子、尝试/成功交换数、有效交换每边次数、边集合保留率、类型间连接变化、输入到输出的可达性与距离，以及放电静默率/高放电分布。训练/验证 pilot 先检查交换链混合情况，再固定交换预算；交换次数大本身不是已充分混合的证明。

有效性剔除只能依据预登记的机械条件，例如违反不变量或数值非有限；不可因动作分数差、静默或不再可达就删随机图。静默/爆发须作为结果和限制报告；若多数重连条件失效，不能宣称证明了任务特异的生物连接优势，需另研究强度匹配等更严格对照。

W 仅在每个源的非自环出边间置换权重，保留逐源出强度、图结构及总体权重分布，不保持逐目标入强度。非自环出边少于两条的源无法置换，记录实际改变比例及自连接比例。P 条件先按注释或已登记路径选定干预，匹配移除节点/边数、符号和权重规模的对照；不能看测试成绩再挑“重要神经元”。

通路干预同时区分两种问题：固定已训练读出的急性干预检验原策略依赖；干预后独立重训读出检验可恢复性。两者分开报告，不把固定真实图读出直接用于 R/W 当作主连接组对照。

### 公平训练与时间信息

每个 G/R/W 图及输入种子分别生成神经活动，独立拟合同容量读出，使用相同标签、分区、标准化规则、岭候选和选择预算。对应条件共享外部输入事件流、预热和时间对齐；B/C 若进入比较，所有图获得相同参数边界与搜索预算。

V 主基线使用与脑输入相同的 14 个聚合视觉通道，取最近 4 步，并增加时间常数 0.05、0.2、1 s 的因果 EMA。所有 EMA 从相同会话或片段起点初始化，处理相同预热及全部有效历史；不只给单帧。V 与神经条件使用完全一致的输入有效性、片段终止、状态重置、预热和评分样本清单；失败步也不推进 V 的 EMA，不允许仅神经方案排除困难输入。共 98 维视觉特征，配同一岭候选与验证协议，报告相对神经读出 132 维的参数量差异。

这让两者访问相同的因果输入前缀，但不保证两种表征的记忆能力相同。额外报告仅当前步、相同 4 步历史以及更强的视觉时序模型条件时，必须独立标识容量与预算；不能把胜过一个弱视觉基线推广成胜过所有视觉控制器。全网状态、输出历史及视觉过滤器的重置点全部一致。

## 指标、预算与结论门槛

### 预登记与探索阶段

探索性 pilot 使用 5 个重连图种子 `101–105`、3 个输入事件种子 `0–2`，真实图使用同样的 3 个输入种子；权重置换采用独立种子清单。此规模用于判断耗时、放电质量、标签覆盖、混合和效果量，不作确认性显著结论。

pilot 仅用训练/验证数据。确认阶段冻结任务、分区、图/输入种子、失败处理、主指标、比较顺序、参数预算、停止条件及最小实用改善量；保存登记哈希后才评测试集。算力不足时如实缩小探索范围，不挑选有利种子替代完整协议。

最小实用改善量由任务允许的速度/转向误差和训练/验证 pilot 确定，在测试前登记；本设计不虚构通用 5% 阈值。若容差、独立测试场景或预算尚未确定，结果只能是探索性或证据不足。

### 主指标和统计单位

每个场景分别计算 `vx` 的 MAE（m/s）与 `wz` 的 MAE（rad/s），先在该场景有效监督样本内平均，再对场景等权平均。主汇总为两轴 MAE 分别除以预登记任务容差后等权平均，越低越好；不对未监督轴评分。

同场景、同输入种子配对比较，先按登记方式汇总种子与随机图，再估计场景层面的差异与区间。报告每个图、种子和场景结果，95% 置信区间按独立场景族进行簇重采样；帧数不是独立样本量。有共享会话的场景应一起重采样。该区间条件于登记的图与输入种子集合，图间差异另报，不把场景重采样当成覆盖所有随机图的不确定性。

附加指标包括各动作方向的误差、非零动作覆盖、停止场景假动作、有效样本比例、神经静默/高放电比例、计算延迟分位数和实时倍率。按全部预登记场景和时间步报告各失败原因及其比例、预热排除数、停止后未提取数、重新分段数和有效监督/评分覆盖；分母须明确，未提取尾段不能伪报为已测得失效。保留零可评分样本场景及其原因，并报告完整场景清单、可评分场景覆盖率和每场景时间覆盖率，不能只报告可解码子集掩盖不可用输入；覆盖不足时结论为证据不足。方向判据与静止容差先登记，避免大量零标签掩盖失败。离线无轨迹、碰撞率或实测飞行距离指标。

若使用随机图排名检验，确认阶段至少需要 20 个随机图实例，且必须说明真实图与随机图的交换性假设并非自动成立。`(更优或同等随机图数+1)/(图数+1)` 只在相应随机化假设成立时具有检验解释；只有 20 个图不等于已经得到 p<0.05。优先报告该随机图族的经验排名、场景配对区间及实际效果量。

预先以 G 对 R 为拓扑主比较，G 对 V 为工程视觉增益比较；其余为机制或敏感性结果，若作多项确认性检验须登记校正方法。独立测试场景数与计算预算根据 pilot 的方差和目标精度确定，不用增加相关帧来替代。

### 允许的结论

| 结果 | 可报告结论 | 不能推导 |
|---|---|---|
| G 稳定优于 M/Z | 未见场景中存在动作相关可解码信息 | 真实拓扑必要、实体可控 |
| G 对 R 的改善超过登记实用量且场景区间支持 | 对该重连家族存在结构收益 | 完整生物还原、所有随机模型均劣 |
| G 对 V 同时满足登记判据 | 相对该视觉基线有收益 | 视觉特征完全由脑计算、全面优于视觉方法 |
| 结果接近或区间过宽 | 无实用优势证据或证据不足 | 通过挑种子/场景补成正结果 |
| 离线表现好，尚无闭环 | 可以设计后续闭环实验 | 已避障、已自主飞行、已跨设备通用 |

定义配对改善量 `Δ=对照误差−真实图误差`。只有预登记比较的 95% 区间下界高于实用改善量 δ，才报告该比较有确认性实用优势；上界低于 δ 表示当前条件下不支持达到该实用量，跨越 δ 则为证据不足，不能称为等效。多重比较时按登记的校正方案使用相应区间。失败、负结果和不确定结果均为有效研究产物；工程验收检查协议实现和记录完整，不要求真实图一定获胜。

## 产物、兼容和实施顺序

每次实验产物至少包括：源数据与图清单、选组 body ID、编码/LIF/偏置快照、随机事件协议、特征模式、标签规则及掩码、分区清单、实验登记、训练模型、逐场景预测和指标、计算耗时、失败及排除原因。缓存键包含影响神经活动的全部身份，不能只按录像名或图文件名复用。

本地数据继续置于被 Git 忽略的 `data/` 或 `logs/`，采用独立 V2 目录与不覆盖写入。旧图、旧 schema、旧读出与日志仍可用于原流程；任何映射、颜色、时间、窗口或参数变更均需重新提取新来源活动，禁止伪造兼容哈希。

| 阶段 | 未来主要模块 | 交付与门槛 |
|---|---|---|
| P0 完整图与契约 | `brain/connectome.py`、`learning` 数据模式 | 官方节点逐 ID 对账、完整参考图与原始片段追踪、注释/选组、独立身份、时间和轴掩码；旧资产不覆盖 |
| P1 输入与信号 | `senses/`、`brain/`、`diagnostics/` | 群组聚合编码、因果重放、固定输出与刺激诊断；记录参数和随机性 |
| P2 读出基线 | `learning/prepare.py`、`decoder.py`、训练与评估模块 | 掩码拟合、场景隔离、验证选择、视觉/M/Z 对照；阶段 A |
| P3 结构与简化对照 | `learning/` 离线研究模块，复用图和诊断纯计算接口 | 同一完整母图的对照与不变量；完整基线后评估简化、预登记容差和预算、独立测试；禁止硬件依赖 |
| P4 闭环与迁移 | `control/`、`drones/`、设备实验模块 | 另行明确环境、任务、时延、停止条件及用户授权，再进入实体实验 |

沿用现有职责边界，不另建重复业务框架；`learning` 可依赖 `control`，反向依赖不允许。上述路径是未来实现位置，不表示本轮已修改代码。按各阶段具体风险安排最小充分检查，不因本设计涉及全图就在文档阶段运行全量测试或仿真。

闭环必须评估观测随动作变化、延迟、轨迹与失败，不能用固定相机录像代替。跨设备实验需明确冻结的编码/脑/解码器、只改适配器的零样本结果、微调的数据量及从零训练对照。

统一六维接口目前只代表动作契约通用，标签和感觉适配仍可能依赖设备。更改相机标定、预处理或任何训练参数时，记录适配预算和新版本，不能跳过 source/schema 校验冒充同一模型的零样本迁移。
