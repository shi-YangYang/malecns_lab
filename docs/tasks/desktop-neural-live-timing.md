## 实现与验收

- 行为遥测仍最多 32 个、仍读取同一脑实例的实际 spikes。当前 frozen 引擎固定采样前 16 个真实输入通道与 16 个 DN 输出；输入通道内按真实出连接数选取代表，规则不依赖当前动作或活动。通道覆盖与未覆盖范围写入 manifest；其他策略保持真实群组轮询。旧档案不改写。
- 默认显示群组总览（已记录群组平均发放率的算术均值），保留单组查看；总览不是全脑平均。脑图继续使用真实各组数据，不随下拉选择伪造分布。
- 验收：动作下发前，新的前向批次应有可见的真实总览信号和实际采样脉冲；检查事件身份、时间顺序及停车/资源回收。
