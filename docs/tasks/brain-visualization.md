## 目标与边界

2026-10-26。先保存原工作区，本地基线提交 `d9082e1`。本任务只改桌面三维展示及其派生资产导出，不训练、不运行脑推理、不启动机器人仿真、不安装依赖。验证等级 S2：资产来源与映射检查、桌面构建、实际界面检查、独立只读审查；不运行完整 Python 测试。

## 源码与数据检查

- 原 `apps/desktop/src/brain.ts` 使用 atlas 的 139,662 个胞体位置（166,700 个模型节点中 27,038 个无胞体坐标）。不是突触或体素。两层加法发光、注释家族多色与近似同等权重的小点造成碎点和重叠发白；没有内部连接层。
- `data/malecns_v1/syn-points-male-cns-v1.0-minconf-0.5.feather` 含真实突触端点的 x/y/z、body、point_id 和 primary 等区域标签；syn-partners 表记录突触接触双方。突触接触坐标不等于连续轴突骨架。本地未找到果蝇神经元骨架或区域表面资产。
- `data/malecns_v2/full_reference.npz` 保存 166,700 个节点、25,582,938 条非零有向边。展示只抽取有空间支撑的少量边，不改变模型连接组。
- 活动取自 `desktop-20261026-093738-5a66765f/behavior_events.jsonl` 的实际 `raw_decision`。`features_mv` 是历史字段名；当前 `x2_frozen_history_policy.py` 与冻结来源 `neural_features_v2.py` 明确它是 L1/L2 的 **signed synaptic current g**，不是膜电位或发放事件。顺序为图节点顺序的 3,555 个 L1/L2，连续两个 250 步均值，共 7,110 维。
- 选择决策 1/9/17/25/29：前进/左转/右转/挥手/结束后的 HOLD。仅代表这些片段中的模型活动，不代表动作专属脑区或一般化的行为神经图谱。前四段都从 600 步开始；HOLD 是较晚的 FINISH 片段，不是静息生物基线，也不参与参考均值与色标计算。

## 分阶段方案

### v1（本次交付）

用官方突触位置的可复现空间抽样呈现主体体积；保持真实坐标，不补对称、不随机抖动。淡蓝柔和 splat、浮点亮度合成和小范围屏幕滤波是显示增强，不是实测体积。中层显示真实连接矩阵边的直线示意：各神经元取距离其采样质心最近的原始突触点作为端点，避免质心落在组织间隙造成虚假密集线束；端点真实不意味着直线为真实轴突路径。每个源节点最多两条强局部连接，最后均匀保留 18,000 条。

活动层对齐四个起始动作的对应 250 步窗口，减去四段记录逐神经元的共同均值，显示差幅值；统一 p99 色标为 6.249484894 mV，使用相同 smoothstep(0.08, 1) 显示曲线，不做动作专用掩码或增益。将神经元标量铺到所属突触、给关联边渐变着色，仅是显示方法，不是逐突触或沿轴突的测量。亮度不能解释为发放频率、兴奋程度或行为因果归属。

`npm run brain` 进入独立纯脑展示；鼠标操作时出现底部精简历史片段选择，闲置 3.2 秒自动隐藏。支持静态与两个已记录窗口的慢放；每窗口均值对应模型时间 25 ms，显示间隔 2.2 秒、过渡 0.65 秒，第二窗口显示后停止，不循环编造神经时间序列。原 `npm start` 仍进入实验工作台，保持原 URL 与控制流程。展示独立进程没有 preload、实验控制器、机器人 IPC 或仿真入口。资产缺失或哈希校验失败时报错，不生成替代脑结构。

### v2（后续，不在本次扩展）

利用已有区域标签进一步做区域密度、遮挡与选择层次；取得更完整活动记录后扩展可着色神经元覆盖。不能从动作名字推断尚未记录的活动。

### v3（需要当前缺失的数据）

引入官方真实骨架或区域表面，在已有 body ID、坐标系和活动身份校验下显示连续纤维束。参考图的连续解剖纤维质感不能用现有胞体/突触点直接证实；不以随机线条补齐。
