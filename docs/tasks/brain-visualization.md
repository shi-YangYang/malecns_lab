# MaleCNS 三维展示改造

## 目标与边界

2026-10-26。先保存原工作区，本地基线提交 `d9082e1`。本任务只改桌面三维展示及其派生资产导出，不训练、不运行脑推理、不启动机器人仿真、不安装依赖。验证等级 S2：资产来源与映射检查、桌面构建、实际界面检查、独立只读审查；不运行完整 Python 测试。

验收：纯黑背景，无顶部栏、标签、统计卡片；可旋转的完整 CNS 主体和内部结构；至少一种历史动作记录驱动局部高亮；支持静态查看。展示不能把连接示意当真实轴突、把电流当尖峰、把历史回放当实时推理。

## 源码与数据检查

- 原 `apps/desktop/src/brain.ts` 使用 atlas 的 139,662 个胞体位置（166,700 个模型节点中 27,038 个无胞体坐标）。不是突触或体素。两层加法发光、注释家族多色与近似同等权重的小点造成碎点和重叠发白；没有内部连接层。
- `data/malecns_v1/syn-points-male-cns-v1.0-minconf-0.5.feather` 含真实突触端点的 x/y/z、body、point_id 和 primary 等区域标签；syn-partners 表记录突触接触双方。突触接触坐标不等于连续轴突骨架。本地未找到果蝇神经元骨架或区域表面资产。
- `data/malecns_v2/full_reference.npz` 保存 166,700 个节点、25,582,938 条非零有向边。展示只抽取有空间支撑的少量边，不改变模型连接组。
- 活动取自 `desktop-20261026-093738-5a66765f/behavior_events.jsonl` 的实际 `raw_decision`。`features_mv` 是历史字段名；当前 `x2_frozen_history_policy.py` 与冻结来源 `neural_features_v2.py` 明确它是 L1/L2 的 **signed synaptic current g**，不是膜电位或发放事件。顺序为图节点顺序的 3,555 个 L1/L2，连续两个 250 步均值，共 7,110 维。
- 选择决策 1/9/17/25/29：前进/左转/右转/挥手/结束后的 HOLD。仅代表这些片段中的模型活动，不代表动作专属脑区或一般化的行为神经图谱。前四段都从 600 步开始；HOLD 是较晚的 FINISH 片段，不是静息生物基线，也不参与参考均值与色标计算。

## 分阶段方案

### v1（本次交付）

用官方突触位置的可复现空间抽样呈现主体体积；保持真实坐标，不补对称、不随机抖动。淡蓝柔和 splat、浮点亮度合成和小范围屏幕滤波是显示增强，不是实测体积。中层显示真实连接矩阵边的直线示意：各神经元取距离其采样质心最近的原始突触点作为端点，避免质心落在组织间隙造成虚假密集线束；端点真实不意味着直线为真实轴突路径。每个源节点最多两条强局部连接，最后均匀保留 18,000 条。

活动层对齐四个起始动作的对应 250 步窗口，减去四段记录逐神经元的共同均值，显示差幅值；统一 p99 色标为 6.249484894 mV，使用相同 smoothstep(0.08, 1) 显示曲线，不做动作专用掩码或增益。将神经元标量铺到所属突触、给关联边渐变着色，仅是显示方法，不是逐突触或沿轴突的测量。亮度不能解释为发放频率、兴奋程度或行为因果归属。

`npm run brain` 进入独立纯脑展示；鼠标操作时出现底部精简历史片段选择，闲置 3.2 秒自动隐藏。支持静态与两个已记录窗口的慢放；每窗口均值对应模型时间 25 ms，显示间隔 2.2 秒、过渡 0.65 秒，第二窗口显示后停止，不循环编造神经时间序列。原 `npm start` 仍进入实验工作台，保持原 URL 与控制流程。展示独立进程没有 preload、实验控制器、机器人 IPC 或仿真入口。资产缺失或哈希校验失败时报错，不生成替代脑结构。

### v2（后续，不在本次扩展）

利用已有区域标签进一步做区域密度、遮挡与选择层次；取得更完整活动记录后扩展可着色神经元覆盖。不能从动作名字推断尚未记录的活动。

### v3（需要当前缺失的数据）

引入官方真实骨架或区域表面，在已有 body ID、坐标系和活动身份校验下显示连续纤维束。参考图的连续解剖纤维质感不能用现有胞体/突触点直接证实；不以随机线条补齐。

## 实现与验收结果

已实现可运行 v1。生成资产在 `data/brain_visualization_v1/`（科研派生资产，按现有规则不提交 Git），包含 635,226 个真实突触采样点，覆盖 127,515 个神经元；3,555 个有电流记录的 L1/L2 全部有采样点。逐点保留源 Arrow 批号、行号与 body ID 映射，保留区域分类供后续使用。采样覆盖全部 5,455 个记录批次，通过原始行号的固定哈希在空间单元内选择真实点，避免源文件 z 排序形成横纹，不生成新坐标。

| 模块 | 位置 | 职责 |
| --- | --- | --- |
| 源数据导出 | `apps/desktop/scripts/export-brain-structure.py` | 真实突触抽样、真实边筛选、历史电流片段、来源哈希 |
| 源数据核验 | `apps/desktop/scripts/verify-brain-structure.py` | 原始 Arrow 点、记录电流、冻结来源与图身份核验 |
| 资产准备与加载 | `scripts/prepare-assets.mjs`、`src/brain-data.ts`（均在 apps/desktop 下） | 打包清单、二进制长度/SHA-256、身份与维度检查 |
| 三维渲染 | `apps/desktop/src/brain.ts` | 突触主体、连接示意、局部活动；静止时事件驱动、过渡上限 30 fps、隐藏时暂停 |
| 展示交互 | `apps/desktop/src/brain-presentation.ts`、`presentation.css` | 纯黑无栏界面、自动隐藏控制、静态与双窗口慢放 |
| 独立窗口 | `apps/desktop/electron/brain-display.mjs` | 隔离的本地 Electron 展示，不加载机器人功能 |
| 原实验界面 | `apps/desktop/src/workbench.ts` | 原 main.ts 迁移，仅增加结构资产加载；原控制流程未变 |

实际验证：

- 桌面 `npm run build` 通过（资产准备、TypeScript、Vite）；视觉修正后构建通过，未运行全项目测试。
- `verify-brain-structure.py` 通过：192 个分散采样点的坐标和 body ID 逐一核回原始 Arrow；全部 35,550 个电流数值核回五条原始决策；读出顺序、原始记录 hash、策略/检查点/冻结特征引擎身份一致。18,000 条连接已在导出时逐条核对原 CSC。
- 浏览器运行相同生产构建，实际检查黑底、无顶部栏、内部连接可见、局部高亮、五种片段切换、静态结构与慢放结束状态；截图保存在 `logs/brain-visualization-v1.png`。这是程序截图，不是生成图片。
- 独立 Electron 展示命令已启动。由于原 Electron 工作台仍有用户的仿真会话，本任务没有重载或停止该工作台；界面自动化只能绑定它的旧窗口，截图与交互验证在同一生产前端的本地预览进行。
- 独立只读审查及最后的数据参考/端点调整增量审查通过，无阻断问题。未训练、未推理、未启动新的机器人仿真、未安装依赖。

限制：这里只覆盖展示抽样和 L1/L2 的历史电流，不能展示每个神经元、每条连接的完整实时活动。五个动作的高亮都可能落在相近的视觉区域；记录差异不支持声称五个独立行为脑区。没有骨架，因此连续真实纤维束仍未实现。原工作台 3D 目前显示群组均值，原始 spike_events 继续显示在下方栅格，不再画为三维脉冲。完整 CNS 的实际比例和参考图不完全相同，没有拉伸/压缩解剖结构来强行匹配。

## 启动与复现

已有本地资产和构建时：

```sh
cd /Users/yang/project/malecns_lab/apps/desktop
npm run brain
```

拖动旋转，滚轮缩放，双击或 Home 复位；1–5 切换片段，0 只看结构，空格慢放/暂停；Electron 中 F 切换全屏，Esc 退出全屏/隐藏控制，⌘W 关闭。原工作台仍使用 `npm start`。

.venv/bin/python apps/desktop/scripts/verify-brain-structure.py
cd apps/desktop

npm run brain
