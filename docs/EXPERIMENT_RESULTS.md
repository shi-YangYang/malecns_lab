# 已有实验结果

记录已发生的计算与失败，保留研究资产。当前主线为[官方 X2 接入](AGIBOT.md)；目标跟随和单轴稳向不再是搭建 X2 的前置任务。本次清理没有重跑训练或改写原始结果。

## 完整参考与神经响应

完整参考资产实测为 **166,700 个节点、25,582,938 条内部有向连接、124,177,617 个突触计数**，保留 101 条自连接与 217 个孤立节点。“完整”指官方发布数据中所定义神经元之间的全部非零连接，不等于完整生物还原。数据范围和原始表账本见 [P0 构建报告](../specs/spec-007-model-v2/implementation-p0.md)。

完整图标准刺激、持续输入诊断和交互式刺激重放均已有实际记录，支持不同输入产生不同模拟神经响应；不证明真实动物机制或控制有效。[持续输入实测](../specs/spec-008-trainable-snn/sustained-observability-run-20261019-r1.md)、[交互刺激实测](../specs/spec-011-interactive-atlas/actual-run-20261021.md)。

## 三轴目标跟随训练

全 GPU 修复分支完成 160 窗、320 帧和 160 次内部增益与读出联合更新。训练轨迹中的前进正饱和由 230 降至 18 帧，负目标方向正确由 0/121 增至 81/121，仍有方向错误、超调和局部退化。这些是训练中变化参数的输出，不是固定最终策略的独立成绩；冻结脑对照未完成同等预算，拓扑优势和新模型实飞未获证据。[完整运行报告](../specs/spec-008-trainable-snn/gpu-recovery-run-20261019.md)。

CPU/MPS 核级比较出现超出预设逐元素容差的数值差异；用户随后接受披露差异后的独立 GPU 训练，不代表 CPU/GPU 轨迹等价。[原始数值报告](../specs/spec-008-trainable-snn/mps-fullgraph-run-20261019-r1.md)。

## 单轴稳向：保留失败结果，停止作为接入前置

该环境只有简化偏航、图像反馈和一阶执行器响应，没有 X2 的关节、接触、平衡或步态。网页果蝇也不是机器人或果蝇身体物理仿真。

固定 LIF 加人工读出的左右两次实验，角速度 RMS 相对关闭控制分别改善 0.97%、恶化 10.89%，没有一致优势。[基线实测](../specs/spec-012-yaw-closed-loop/actual-run-20261021.md)。

随后使用完整图 MPS SNN、工程视觉编码与下降神经元读出，联合训练内部类型共享增益及读出，并与仅训读出对照比较。两个分支各完成 80 窗；每窗两帧、每帧 500 个 0.1 ms 神经步、每窗一次 Adam 更新。控制帧模拟时间为 0.05 秒，计算墙钟时间另计；状态跨窗保留，场景切换重置。

固定第 80 窗模型在两个验证场景的角速度 RMS 改善率如下；负值表示比关闭控制更差：

| 模式 | 正向场景 | 负向场景 |
|---|---:|---:|
| 未训练同架构 | +2.97% | +5.59% |
| 冻结脑、仅训读出 | +24.54% | −30.89% |
| 内部增益与读出联合训练 | −208.62% | −99.27% |
| 独立纯视觉 P 对照 | +59.84% | +59.82% |

**联合模型控制门槛失败，锁定测试未开启。** 正向的冻结脑改善不能掩盖负向退化，纯视觉对照结果也不能归功于 MaleCNS。训练与评估执行完成只证明流程跑通；没有证明内部训练有效、拓扑优势、机器人接入就绪或实机控制。[完整运行记录](../specs/spec-013-yaw-learning/actual-run-20261021.md)、[固定模型验证证据](../specs/spec-013-yaw-learning/acceptance-validation.md)、[保存数组误差分析](../specs/spec-013-yaw-learning/online-error-analysis.md)。
