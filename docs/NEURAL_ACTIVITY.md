# 离线神经活动记录与刺激比较

先回答一个问题：同一段视频出现不同运动刺激时，视觉编码和模拟神经放电怎样变化。工具直接运行 `Retina → InputEncoder → Brain`，保存信号、曲线和热图，不经过旧动作读出，不控制无人机。

这里记录的是基于真实 MaleCNS 连接组的模拟活动，不是活体果蝇的神经测量。第一版读取本项目地面录制工具生成的会话目录，暂不导入单独的 MP4 或手机视频。

## 1. 准备环境和录像

在项目根目录激活环境并安装依赖；`analysis` 提供 OpenCV 和 Matplotlib：

```bash
source .venv/bin/activate
python -m pip install -e '.[tello,data,analysis,dev]'
```

已经有地面会话时可以直接进入第 3 步。录新会话时，关闭手机 App 和其他 Tello 程序，电脑连接 Tello Wi-Fi，将飞机固定在地面：

```bash
python -m cnsbridge.experiments.tello.record --scene-id room_a --seconds 30
```

采集只读取视频和遥测，不发送运动指令。保存目录中应有 `session.json`、`video.avi`、`frames.csv`；录制器还会生成空白 `labels.csv`，**本次无需填写它**。分析阶段可断开 Tello，重复使用同一段录像。

## 2. 30 秒怎样拍

保持 Tello、背景、照明不动，只移动一个物体。可用有明显边缘的卡片或手机背面，避免播放闪动内容。左右均按录像画面定义，不按操作者站位定义。先在预览里确认物体边缘可见，不要一直用物体挡满镜头。

下面是拍摄安排，时间是操作参考；最终标注必须以实际 `video.avi` 为准。

| 参考时间 | 怎么操作 | 刺激名称 |
|---|---|---|
| 0–6 秒 | 物体留在画面外，保持静止；前 2 秒供模型暖机 | `baseline` |
| 6–9 秒 | 物体与镜头距离基本不变，从画面左侧向右侧匀速移动一次 | `motion_right` |
| 9–12 秒 | 把物体移出画面，准备下一次；不要来回乱晃 | 暂不标注 |
| 12–15 秒 | 保持与上次相近的距离和速度，从画面右侧向左侧移动一次 | `motion_left` |
| 15–18 秒 | 移出画面，短暂停顿，准备正面靠近 | 暂不标注 |
| 18–21 秒 | 物体对准画面中央，平稳靠近镜头，使它在画面中逐渐变大 | `frontal_approach` |
| 21–24 秒 | 移出画面后复位，避免把后退与靠近混在同一标签里 | 暂不标注 |
| 24–27 秒 | 从相近位置再做一次正面靠近，尽量保持相同速度 | `frontal_approach` |
| 27–30 秒 | 移出物体后保持静止；仅最后真正静止的部分标基线 | `baseline` |

横向移动用于检查方向相关响应，正面靠近用于检查画面扩张响应。名称只描述视频里发生的事，不能据此假定模型识别了障碍物，或应该输出某个动作。一次录像只是初步观察；比较重复录像时尽量保持距离、路径、速度和光照一致。

## 3. 先看未标注的信号

默认使用 `configs/malecns.yaml`，需要已有的 `data/malecns_brain.npz`。相对模型路径按源码工程根解析；模型缺失时直接报错，不使用替代网络。诊断不执行动作读出，因此不需要旧读出的校准文件。下载与构建步骤见 [README](../README.md)。把 `SESSION` 替换为录制命令输出的实际会话目录名：

```bash
python -m cnsbridge.diagnostics.activity data/ground_recordings/SESSION \
  --out-dir data/neural_activity/run_01
```

命令逐帧处理完整录像，不要求 `stimuli.csv`。打开 `data/neural_activity/run_01/index.html` 查看曲线和热图；没有刺激标注时不会生成有效的分刺激比较。全量网络的处理耗时可能长于视频播放时长，模型仍按每帧 50 ms 推进。

每次用新的输出目录，工具拒绝覆盖已有目录。输入会话和模型保持只读。

## 4. 按实际视频时间标刺激

播放本次 `video.avi`，记录各段刺激真正开始和结束的时间。在会话目录中新建 `stimuli.csv`。它与未来训练用的 `labels.csv` 是两个独立文件：这里不写 `throttle`、`yaw` 或期望速度。

CSV 表头固定为 `start_s,end_s,stimulus`，区间为左闭右开 `[start_s, end_s)`。以下数值仅演示格式，不能未经看片就直接作为真实标注：

```csv
start_s,end_s,stimulus
0.0,6.0,baseline
6.0,9.0,motion_right
12.0,15.0,motion_left
18.0,21.0,frontal_approach
24.0,27.0,frontal_approach
28.0,30.0,baseline
```

使用 **AVI 播放秒数**，不是电脑墙钟，也不是 `frames.csv` 中的主机取帧时间 `t_s`。视频时间为 `frame_index / 20`；采集有间隙时，30 秒录制过程不一定对应 30 秒 AVI，请以实际视频时长为上限。

可以自定义刺激名称，也可以重复同一个名称。`baseline` 是静止基线的固定名称；没有明确标为 `baseline` 的区间就不计算相对基线差值。复位、操作不确定或没有刺激的空隙可留空，工具不会把未标记片段自动当作基线。区间必须有限、不重叠、位于视频时长内，名称不能为空。

标好后输出到另一新目录：

```bash
python -m cnsbridge.diagnostics.activity data/ground_recordings/SESSION \
  --stimuli data/ground_recordings/SESSION/stimuli.csv \
  --out-dir data/neural_activity/run_02
```

## 5. 打开报告，沿着信号链看

| 输出 | 怎么看 |
|---|---|
| `index.html` | 本地报告入口，汇总图表、配置和诊断信息 |
| `input_drive.png` | 视觉编码送给输入群组的平均驱动率，单位 Hz |
| `group_rates.png` | 输入、输出群组内全部成员的平均实际放电率，单位 Hz |
| `neuron_heatmap.png` | 有限采样神经元的逐 50 ms 窗口放电率；不是逐脉冲 raster |
| `group_rates.csv` | 逐窗口时间与群组信号，供进一步分析 |
| `stimulus_summary.csv` | 逐刺激区间和同名刺激汇总；`scope` 区分 `interval` 与 `stimulus` |
| `activity.npz` | 无 pickle 的原始活动数组，包含采样神经元计数与发放率 |
| `report.json` | 网络与源码身份、有效配置、时间信息、群组与采样映射、比较结果 |

建议按以下顺序检查：

1. **先看群组是否存在。** 缺失群组没有匹配神经元，显示为缺失或 N/A；它不同于存在神经元但没有放电的 `0 Hz`。不要用缺失群组推断模型不响应。
2. **再看编码驱动。** 移动物体时，相关输入驱动曲线是否变化。驱动 Hz 是编码器给模型的输入强度，不是摄像头帧率，也不是神经元真实发放率。
3. **看实际神经活动。** 输入群组、输出群组是否出现变化，左右刺激是否不同。若驱动变了而输出变化小，下一步应检查映射群组、网络参数和输入强度，而不是直接把旧 `yaw` 放大。
4. **看单神经元热图。** 群组均值可能掩盖个体差异；热图只展示确定性抽样的神经元，不代表全脑。采样全局索引、类型、侧别和可用的 body ID 记录在报告中。
5. **比较重复刺激。** 表格先计算每段的均值，再对同名刺激的有效区间均值等权汇总。相对基线差值使用有效 `baseline` 区间均值；没有有效基线时该值留空。单次或两次重复不能得出统计显著性结论。

所有帧都推进模型、保存原始活动。默认暖机前 2 秒不进入刺激统计；跨越刺激边界的窗口也不计入比较。未标注、暖机片段仍可在曲线中观察，不会从神经状态历史中删除。

单个神经元在 50 ms 内发放 1 次对应 `20 Hz`，2 次对应 `40 Hz`，因此单神经元热图出现离散值是正常计数结果。群组均值还除以成员数量，可以呈现更小的变化。模拟时间、AVI 时间与主机取帧时间分别记录；处理耗时不能解释为果蝇的生物反应延迟。

## 可选参数和结果边界

- `--config PATH`：加载另一份配置。有效配置包含人工 bias，比较时应核对来源和配置一致。
- `--max-neurons 128`：热图与原始单神经元活动的采样上限，允许 1–4096，默认 128；群组平均仍使用该组全部神经元。
- `--warmup-s 2`：用于刺激统计的暖机时间，默认 2 秒；不影响全部帧的因果重放。
- `--brain PATH`：明确指定另一份真实连接组 NPZ；需要记录其数据版本和过滤条件，不能将不同图的结果混为同一实验。

每次运行初始化新的视觉与网络状态，按固定 50 ms 窗口重放 BGR 视频，偏航角速度输入为零。固定相机、近似视觉编码、人工 bias 和配置 seed 都会影响响应。默认 MaleCNS 配置包含对 DNg02 群组的人工持续驱动，不能把静止时的持续放电全部归因于视频；录像重放不能替代飞行中的视觉与身体反馈。

此工具不训练网络，也不规定神经活动对应的动作。它帮助确认信号的来源与响应，为后续 [动作标注和读出训练](DATASET.md) 提供依据；曲线变化本身不能证明认知、正确避障或通用解码器有效。
