# Spec 013 — 完整 MaleCNS 稳向学习与仿真接入准备

> 当前定位：本阶段后续支线已停止，不再作为官方 X2 仿真接入前置。两分支各 80 窗训练完成、固定模型验证失败，锁定测试未开启；保留数值源与原始结果，移除单轴网页、部署包装和未运行的信号诊断。下文保留原实验设计以解释既有产物。

## 目标与完成条件

使用完整参考图训练网络内部类型增益与动作读出，让相机驱动的策略学会减小旋转；完成独立场景评估、同构冻结脑对照、训练结果网页回放及独立模型接口。准备的是慢速锁步机器人仿真接入，不要求本机实时20Hz；实际延迟必须报告。

完成须同时具备：完整图实际内部更新证据；最终固定策略满足下述留出控制门槛；对照完整且结论如实；保存模型可在新进程加载，接口仅接收相机和时间、输出 FLU BodyVelocity；网页可回放实际训练后闭环；独立验收通过。仅软件通过、梯度非零或生成一个模型文件不够。

## 模型与输入契约

- 生产入口只用 `load_training_graph` 校验完整 `data/malecns_v2/full_reference.npz`，保留166700节点、25582938条已发布内部非零有向连接及原始计数身份；不删节点/边、不改变拓扑、不回退小图。旧资产、旧hash绑定源与Spec011/012行为保持。
- 新独立策略复用现有 `MPSLIF`，不是旧目标跟随checkpoint续训。原dt=0.1ms、delay=1.8ms、refractory=2.2ms及固定lamina偏置保持。网络前向、伴随、输入事件、读出、loss、clip与Adam均在MPS，fallback=0；CPU负责仿真图像/教师生成、进程监督与存档。
- 新工程视觉前端在MPS float32实现现有VisionV2的96×72 BGR灰度、双半幅6×8局部Lucas–Kanade光流、有效性及14通道。按已绑定参考组广播到R1–R6、T4/T5、LPLC2、LC4输入IDs；T4命名组包含T5，必须如实说明。不同数值后端登记新来源，先以独立NumPy实现验证方向/数值/质量门槛。不把工程光流或组广播称为已恢复视网膜或端到端原始像素学习。
- 输入事件采用固定seed1702独立细胞相位、rate×dt累加、阈值事件及68.75mV增量，非输入节点无外部事件。完整网络均参与传播。策略不接收yaw、角速度、扰动标签、教师动作或未来画面；视觉量不能旁路到动作读出。
- 全部descending_neuron前后半帧膜电位均值为特征。每段40帧静止预热，最后20帧均值冻结为神经基线；特征减基线后除以7mV，单输出线性层后 `.35*tanh(logit)`，其余轴0。预热动作0。读出seed1703小非零初始化、bias0；初始化规则记录并在joint/frozen/untrained一致。
- 参数仅 `brain.theta`、`readout.weight`、`readout.bias`。theta按突触前细胞类型共享，增益 `1+.5*tanh(theta)`；基础连接矩阵固定。这是脑内传播强度学习，不是每条边独立学习。frozen对照theta固定初值，只训读出。

## 时间、训练与接口

- 控制周期0.05s；每帧500个0.1ms神经步；两帧一窗、1000神经步、一次参数更新。checkpoint分块50步，递归反向信用100步；窗末detach但不清空神经/感觉/延迟队列。每场景入口重置一次、完成40帧预热；预热不更新参数。
- 首轮在线模仿训练：每帧渲染当前姿态→视觉/SNN→模型动作→机身积分。教师目标 `clip(-2*(yaw_t-yaw_(t-1))/.05, ±.35)` 只来自刚发生的区间，首帧0；只进入loss，不能代替实际模型动作或窥视本帧外扰。joint/frozen各自产生闭环轨迹，使用同初始权重、场景顺序、编码、教师、更新次数和学习率，不能声称两者闭环输入图像完全相同。
- loss为 `mean(softplus(2*z)-(1+y)*z) + 1e-4*mean((gain-1)^2)`，y=teacher/.35；分别记录动作MSE、正负方向错误与静止漂移。新单轴MPS fused Adam：theta lr=.001，readout lr=.001，两个组分别做稳定L2裁剪上限1，标准betas(.9,.999)、eps1e-8；frozen不登记theta优化器组。
- joint和frozen各执行一次可丢弃完整图双帧更新门槛，分别覆盖不同优化路径。joint核对输入信号、MPS驻留、有限/非零内部梯度、实际theta与读出/Adam更新；frozen核对内部theta保持初值、只有读出及其Adam更新。二者均记录内存/耗时，通过各自门槛后才运行正式首轮；gate参数不得混入正式初始化。
- 第一轮每分支4场景×40观察帧=80次双帧更新。先用验证场景检查；若不满足控制门槛，分析训练/验证证据后登记下一版方案，不开启锁定测试或按测试结果调参。测试开启前冻结最终checkpoint与协议。必要的后续迭代由新版本记录原因，禁止覆盖阴性结果。
- 新独立接口 `reset()`、`observe(frame_bgr, timestamp_s)` 返回单轴BodyVelocity及明确状态；时钟不连续、尺寸/数据错误或无纹理时零动作并报告失效，需reset恢复。初始化预热明确返回零。模型身份/图/参数/来源强校验，旧三轴checkpoint拒绝。锁步调用才推进神经状态，不宣称壁钟实时。
