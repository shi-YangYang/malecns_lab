# Spec 021 — 完整MaleCNS到X2的纵向反馈MVP

状态：Ready。2026-10-23。Spec020已独立PASS，完整状态精确一致，单帧约2.30秒。以下协议在联调前冻结，受用户持续MVP目标授权。

## 目标

把已核实的完整脑冻结推理与Spec018官方运动适配器连接起来，记录实际里程计→虚拟标记图像→完整脑原始三轴输出→有界纵向意图→官方MC→真实仿真运动→下一次新观测的因果执行链。至少两轮使用运动后的新观测完成推理和动作决策，不能用固定脚本、离线重放或人工距离控制代替神经输出。

这是一项纵向工程闭环MVP，不要求继承的三轴无人机策略已经学会X2目标跟随；不宣称真实相机、自动起身、可靠导航或真机能力。传感器明确命名为“实时里程计驱动的虚拟标记”。源场景只有地面，官方配置未发布RGB；本轮不修改官方SDK/MC/Sim、模型和物理参数。

## 已冻结协议

- 固定采用Spec019训练最终checkpoint、同一完整图、相机编码与Spec020验收通过的后端。单场景600步空白预热，跨轮保存状态；无训练、无优化器。
- 初始官方SD及GUI重置后，确认STAND/RUNNING、直立、新鲜odom/MC及至少1秒连续水平速度<0.02m/s；初次源为空时只允许观察，不伪称已拥有控制权。初始朝向接近世界+x（yaw绝对值<0.05rad），否则结束；目标固定在首个合格位置的世界+x方向2.0m处、相同y/z，0.2m世界y/z平面红标，不随机器人移动。
- 每轮仅在停稳状态采集并保存新观测，按完整姿态投影160×120BGR输入。观测ID、原始odom/MC序号和接收时间、世界目标、图像hash、脑状态时钟、原始三轴动作及执行意图全部关联。
- 沿用Spec019事先登记的唯一门限：原始vx>0.03m/s请求固定MC FORWARD `(0.2,0,0)`，否则STOP。vz/wz原样记录为本纵向实验未执行轴，不通过BodyVelocity静默丢轴，不用真实距离改写脑决策。
- 每次FORWARD脉冲1.0秒，之后持续发零，最多12秒等待Spec018连续反馈停稳。最多3轮、累计最多3秒非零命令；脑计算期间始终发零，不保持上次前进。失败不自动恢复运动。
- 脑与ROS发布分属进程。共享目录消息使用唯一运行ID和单调序号，原子写入；输出只可对应当前未消费观测，重复/乱序/旧输出拒绝。脑计算超时30秒即结束。
- 计算结束后重新核对当前新鲜反馈，水平位置较输入观测漂移<=0.02m、姿态夹角<=0.03rad，且STAND/RUNNING、直立低速；超限丢弃本轮输出并结束，不把旧观测时间重写为当前时间。动作TTL从接纳请求时起计，仍受原有起步/控制权/反馈检查约束。
- 初次空源仅允许在神经FORWARD决策后走原有0.5秒CLAIMING；其他非空源不抢占。初次STOP不能为了抢源先发非零；此时仅记录空源STAND低速观察，不能伪称本源已接管。

## 资源与环境

本阶段才允许为必要联调同时驻留一个完整脑和一个私有GPU仿真VM；此前基线/优化继续保持VM关闭。必须使用前两阶段实测资源，持续保留系统available>=1GiB，脑RSS申请<=6GiB、MPS受同一有效预算约束，0.1秒父进程监督、完整脑共享锁。CPU仿真保持停止；默认Docker context、Noria及Docker Desktop不动。

先加载脑并完成预热，再按需启动既有GPU环境。总脑进程墙钟上限240秒，仿真联调窗口上限120秒；资源越界、脑或ROS退出、通信异常均归零并结束，协调者随即关闭本项目容器和私有VM。不能靠结束其他服务腾空间；资源不够就报告本机联调失败，保留证据。编码、审查和分析期间关闭仿真，不因截图复开环境。

## 验收

1. 默认不加载脑/ROS或执行动作；实际执行须明确sim-only和隔离域。已有运动核心的失效停止、5秒上限和连续反馈停稳不放宽。
2. 单次受监督完整图联调至少完成两轮神经决策，其中至少一次实际前进>=0.2m，后续输入来自真实运动后的新odom且图像内容变化；输出、意图和反馈可逐轮关联。全部STOP或未移动不算动作闭环成功，不为通过调门限。
3. 每个实际前进都确认停稳，最终无活跃前进意图；错误不回报成功。离线检查、仿真运动与策略任务效果分别报告。
4. 系统预留、单进程、阶段超时、完整参数/来源身份和最终关闭均有记录；新独立验收后本地commit，不push。

S2：仅新闭环通信/调度、投影与原运动核心的接口交互。定向检查采用假时钟/假消息覆盖新协议及失效路径，不重复Spec018已通过检查；之后一次有界真实联调。任何具体失败保留证据并限定修复，不机械追加实验。
