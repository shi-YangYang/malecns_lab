## 顺序与接口

1. P0：新增完整参考图构建器与版本化元数据，复用 CSC 容器但保留原始注释和精确整数计数；官方 neuron 身份证据、逐 ID 清单、全部内部非零边、自环、孤立节点、片段边界、来源及构建账本一起保存。输出独立路径，不覆盖旧图。选组包含 R16 rootSide、HAL subclass/rootSide，固定输出 body ID；HAL 在主实验不驱动。构建命令应可复现。
2. P1：群组聚合视觉编码，BGR/px每秒/质量失败和重置；body ID 与仿真步确定的共同输入事件；真实完整图因果重放、132 维神经和 98 维视觉特征。标准人工视觉刺激用于输入/神经诊断，明确其不能证明真实动作效果。
3. P2：版本化掩码目标/数据/解码器与 train/val/test 场景族隔离。阶段 A 冻结全脑，仅拟合标准化与岭读出；与视觉、零、均值基线同评分清单。无真实标签时完成契约及工具，不伪造研究数据。
4. P3：真实完整图派生 R/W/P 控制，机械不变量及离线隔离；登记配置、图/输入种子、预算、容差和证据。每图独立拟合。阈值简化只是后续候选，必须有完整基线实测。缺确认数据时如实记录未完成。
