# P2-01 定向返工

依据 [独立验收 FAIL](acceptance-p2.md)，仅修正 `paired_scene_comparison` 的置信区间解释：下界严格高于登记 δ 支持实用优势；上界严格低于 δ 不支持达到该实用量；跨越或接触 δ 为 `insufficient_evidence`。已有覆盖不足分支保留。

不改变拟合、评分样本、误差、bootstrap 或 P3 接口。同步文档语义，在一个相关评估检查中覆盖三个分支和等于 δ 的边界。风险 S1，只运行该定向检查，不重复已经通过的学习或脑检查。由新的实施 Agent 修改并报告，再由新的独立验收 Agent 验收；原 FAIL 与其他通过证据保留。
