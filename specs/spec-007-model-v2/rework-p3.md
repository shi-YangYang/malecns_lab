# P3-01 调度预算闭环返工

依据 [P3 集成独立验收 FAIL](acceptance-p3-integration.md)，只修复实验调度层的总墙钟预算。在急性 P、聚合评分、配对计算和最终成功保存的阶段边界核对 deadline；不可中断的当前计算可返回，但超时后不继续非必要计算、不输出完整比较或成功状态。

保留全部登记任务和局部产物，记录预算耗尽阶段与原因；剩余任务明确未执行。输出 `incomplete` 或失败记录，完整比较为空。不得改变图/标签/评分/独立拟合规则，不缩短 bootstrap 或挑选可用条件以凑预算。

风险 S1：单个实验调度函数及必要局部辅助。只运行对应的最小定向检查，覆盖末次比较超时及急性/最终保存边界；采用合同 fixture，不重复前序测试或任何完整脑运行。由新的实施 Agent 返工并报告，新的独立验收 Agent 关闭 P3-01；原 FAIL 与其他通过项保留。
