# Implementation Report — P2 掩码读出与离线评估工具

## Summary

实现独立 V2 录像记录导入、逐轴标签、严格分区、阶段 A 岭读出、直接视觉/均值/零基线及场景配对评估。消费 P1 的版本化记录，不修改 P1、脑、感觉或旧 V1 学习入口。用户确认还没有真实录像与标签，本批只验证工具合同，没有训练真实动作模型或取得 M4 研究证据。

## Files Changed

- `src/cnsbridge/learning/contracts_v2.py`：登记协议、132/98 维来源/顺序模式、FLU 六轴标签和 vx/wz 掩码、显式旧区间 CSV 导入、哈希。
- `src/cnsbridge/learning/dataset_v2.py`：P1 源身份、计划段、时间和有效性核对，按目标时间取标签，场景/会话/素材族/来源/视频内容哈希隔离，失败尾段覆盖和关联簇，条件间逐行一致性检查。
- `src/cnsbridge/learning/decoder_v2.py`：仅监督轴拟合、训练集标准化、未知轴无权重、模式严格校验，预测有效性与支持轴，模型拒绝覆盖。
- `src/cnsbridge/learning/evaluation_v2.py`：逐场景/轴/输入种子 MAE、登记容差归一、覆盖/零样本场景、评分清单哈希、场景族簇 bootstrap 与明确证据不足状态。
- `src/cnsbridge/learning/train_v2.py`：CLI prepare-only/fit，分别训练每个图和输入种子；固定九个 λ 的验证选择；pilot 不生成 test 预测/指标；登记、数据、模型、预测、指标、耗时/内存/失败产物。
- `tests/test_learning_v2.py`：小数组和持久化格式合同 fixtures，不构造或运行替代脑。
- `docs/LEARNING_V2.md`：可复现协议/标签格式、准确 CLI、限制和 P3 集成接口。

## Important Decisions

1. `prediction_valid` 是必要条件，再以 P1 `target_time_s=t+0.05` 匹配半开标签区间。核对 2 s 预热、每步 50 ms、源视频时间、末步目标边界及首个失败即停止；不自行更改 P1 行语义。
2. 多个图/来源模式不混合拟合。一个图协议内多个输入种子按 `for_input_seed` 各自训练；同一视频内容即使改名及更改声明 ID，也用 `video_sha256` 拒绝跨 split。裁剪/增强关系仍依赖用户真实声明 family。
3. 只接受真实录像类型的学习来源；生成工程刺激明确定义为诊断，拒绝导入动作训练。独立教师为 `independent_human` 或 `predefined_task`，没有自动 RC/实测速度/神经目标教师。
4. 每样本六轴 bool mask，当前只允许 vx/wz 监督。训练统计仅使用 train 中有效且至少一轴有标注的行；各轴根据自身 mask 独立拟合有截距的岭回归，缺轴保持无参数占位。
5. 神经/视觉读出均使用 `10^-4…10^4` 九个候选，只有 val 场景指标选 λ，不使用 test 特征/标签或训练 R²。模型训练身份不包含 test 标签/特征。M 为 train 各轴均值，Z 为零，共用严格评分行。
6. 保存完整评分行身份 hash；配对不只检查数量，也要求 row key、mask、目标及场景覆盖一致，不静默取交集。区间按共享会话/素材族/来源连通簇重采样，输入种子不当独立场景。图种子总体变异留给 P3 单独报告。
7. CLI 不覆盖产物；预算按候选边界检查，无法中断单次线性求解，超预算后不宣称完成。登记快照不构成用户未查看 test 的证明。

## Validation

- 实施过程阅读了所有本批新文件；未运行项目全测试、构建、真实动作训练、设备步骤或 Git 提交。

## Known Limitations

- 没有用户录像和动作标签，所有测试数据仅为数值/序列化合同 fixtures；不可写成真实动作任务效果或全脑实验。
- 学习协议容差、静止判据、实用改善量、独立场景与确认预算必须由具体任务在测试前登记；文档数值只是格式例子，工具没有暗设实测推荐值。
- 至少两个独立簇、全部登记场景/轴/输入种子可评分才给 CI；保留覆盖不足状态。报告仍需结合每场景时间覆盖解释，不能把有少量可评分行等同完整场景可用。
- 图条件独立训练与跨图公平性由公开接口支持；完整 R/W/P 实验调度、图种子变异及研究判据由 P3 整合，不由本批宣称研究完成。
- 命令面向离线分析，没有学得模型到 Tello 的设备入口或安全控制。
