# Spec — MaleCNS 第二版控制模型

状态：当前 P0–P3 离线工具批次 Done；M4 真实动作研究待数据。用户授权“开始做，自由决策”，并确认尚未录制、先完成诊断和工具。完整参考图、全脑诊断、掩码学习及对照工具已分批独立验收通过；既有 D1–D7 文档验收和各次返工报告保留。工具通过不代表动作模型有效。

## 背景

用户已确认基于真实 MaleCNS 连接组，重建感觉输入、神经表征和可训练解码器，保留可追溯的图与 LIF 基础，并以无人机为首个研究平台，后续检验移动底盘迁移。本轮要求写出第二版设计和 Spec，明确输入输出、可训练参数及连接组贡献的验证方法。

[数据与通路审计](../../docs/MALECNS_AUDIT.md)发现输入侧别与 HAL 选组缺失、按索引分配视觉网格、人工巡航与神经读出混合等问题。目前没有证据证明必须重写全部 LIF 引擎。

用户进一步明确：必须基于完整官方数据开展研究，不能未经实验沿用阈值 3 等删减规则。本要求取代先前“旧节点集合和阈值 3 为 V2 主图”的决定。阈值 3 没有本项目实测依据，旧图仅作历史基线。

## 目标

1. 定义可实施、可复现的第二版离线模型及其接口。
2. 明确训练参数、冻结参数、分阶段扩展条件和动作标签来源。
3. 规定能够区分真实连接结构、工程视觉特征和人工控制规则贡献的实验。
4. 明确从离线读出到闭环、跨设备的证据门槛，允许得出负结果。

## 非目标

本次实施覆盖 P0–P3 的离线工具、完整图资产与全脑标准刺激诊断。用户已确认“还没录，先完成诊断和工具”；本次完成条件是这些实现及相称检查/诊断完成，不要求当前缺少数据的真实动作训练与确认性研究。M4 研究证据继续单列未完成，不伪造动作监督或填写确认性研究通过。P4 实体闭环、B/C 参数优化另按其进入条件定义，不接设备、不 commit 或推送。不恢复 MiniFly、合成飞行替代网或兼容入口。不宣称完整生物还原、已实现自主飞行或论文新颖性。

## 当前行为

- V1 实际运行的过滤图为 166,700 节点、10,520,377 条有向连接；这不是 V2 完整数据基线的预设规模，来源、过滤条件与限制见审计。
- `brain/` 提供真实图加载及 LIF；`senses/` 在网络外计算光流和膨胀，再驱动多个神经群。
- 旧 `MotorDecoder` 与飞行监督包含人工行为；新 `RidgeMotionDecoder` 训练链路独立，尚未接入实飞。
- 统一动作采用 FLU 的 `BodyVelocity`；现有动作标签只覆盖 `vx/wz`，不能把其他零值当成已学会的自由度。

## 目标行为

离线录像与可选遥测 → 显式感觉编码 → 真实连接组约束的 LIF 网络 → 因果神经活动窗口 → 可训练解码器 → 带轴能力与有效性信息的期望机身速度。设备适配和安全监督位于模型之外；训练标签不进入神经仿真。

设计细节、字段、参数表和实验协议以 [MODEL_V2.md](../../docs/MODEL_V2.md) 为实施依据。以下需求编号用于未来实现追踪。

## 功能需求

### F1 数据与模型身份

- 保留 body ID、type、class/subclass、status、somaSide/rootSide、递质及其未知状态、原始来源；同一节点的各字段不得互相覆盖。
- 图、选组、编码、动力学、随机过程、读出特征、时间基准及训练数据划分共同组成模型身份；变化必须生成新的来源身份和独立产物。
- 以完整官方 v1.0 flat-connectome 发布数据为不可改写的母本，登记全部来源及用途，不将重复表示或派生子集重复计入图。官方 minconf 0.5 是发布边界，不能声称拥有阈值前全部观测。
- P0 必须依据官方定义建立完整神经元 body ID 清单及逐项对账；不得直接把旧 superclass 非空集合、Traced-only 集合或 166,700 的数量当作已核实的全集。普通注释缺失不能单独作为删节点理由。查证作者 Methods 明确以 superclass 定义 neuron 后，可以按此有出处的神经元/片段身份边界构图；必须保留逐 ID 分类与边界差异，不附加 type/status/侧别/tbc/度数筛选，见 Decision 007 的 P0 证据补充。
- 原始 segment 图与神经元参考图分别留存来源与统计。未归属片段、已确认非神经元及待定记录必须保留分类、依据和受影响连接清单；不能把片段伪称完整神经元，或静默丢弃后称保留了全部原始图。全集边界未核实就停止在 P0，不回退 V1 进入正式实验。
- 神经元完整参考图保留该全集之间官方已发布的所有非零连接及原始突触计数，默认不额外剪弱边（正整数权重下相当于 min_synapses=1），保留原始自连接与孤立节点；未知递质以未知标记和显式符号假设处理，不因缺注释删边。
- 阈值 3、子图、去除自连接等只可作为独立简化候选，必须先有完整参考图结果，再在其余条件受控的实验中评估信息/行为变化和资源成本。实验前登记容差，训练/验证集选择，独立测试集确认；不能因当前设备跑不动而暗中改主图，资源不足须如实记录。

### F2 感觉输入

- 输入为带时间基准、颜色约定、有效性及场景身份的图像；可选遥测必须有来源、单位、时间戳和缺失标记。
- 第一版采用显式工程特征编码：亮度、方向运动和膨胀。明确特征在脑外计算，不称为原生全视觉重建。
- 修正按细胞类别的侧别和 subclass 选组；R1–R6/HAL 覆盖以审计候选为依据。禁止直接把神经元排序视为视网膜位置。
- 无可靠视网膜拓扑时使用明确的群组聚合驱动；有依据的空间映射作为独立后续版本。左右半幅仅是工程视野分区。
- 主离线实验关闭 HAL 驱动；缺失遥测不是测得零。将 SDK 偏航映射到 haltere 的实验需独立标识，不能冒称生物等价。

### F3 神经状态与读出

- 第一阶段复用 LIF，实现冻结图、符号映射、动力学和编码参数的可重复运行；固定随机种子与初始化规则。
- 主读出先固定现有六组的 33 个输出细胞，按 body ID 稳定排序，逐细胞记录 Hz；群组均值仅作为辅助诊断。细胞数量变化必须显式失败或生成新模式。
- 神经窗口只包含当前及过去信息，初始化、预热、重置、丢帧及失效语义明确。仿真时间、视频时间和计算耗时分开保存。
- 输入活动和神经输出单独记录。无效、缺失或全静默需单独诊断，不得以人工巡航掩盖。

### F4 动作输出

- 输出沿用 `(vx, vy, vz, wx, wy, wz)`，FLU 前左上，平移 m/s、旋转 rad/s，正 `wz` 左转；值是期望速度。
- 首个确认范围为 `vx/wz` 平面任务；训练、报告必须有轴掩码。其他轴占位为零不构成升降/横移学习证据；扩展 `vz` 需相应独立标签。
- 解码器不叠加固定巡航、阈值逃逸或设备 RC。设备适配执行能力和符号转换，安全监督单独记录模型原始目标、实际目标及干预原因。

### F5 训练范围

- 阶段 A：只拟合读出权重、截距与训练集标准化统计；岭系数由验证集选择。连接结构、突触幅值与符号、LIF、编码、输出细胞、窗口保持固定。
- 阶段 B：A 的数据与对照有效后，才研究有界的输入群组增益与读出；无穿透当前 LIF 的自动微分能力假设。
- 阶段 C：B 仍存在具体瓶颈时，再研究拓扑与符号约束下的少量细胞类型参数；不默认训练全脑每条边或补造缺失连接。
- B/C 的参数范围、预算和实验登记需在实施前固定；本 Spec 不授权直接启动它们。

### F6 数据与标签

- 刺激标注与期望动作标签分离。移动物体、移动相机、自运动和遥测有效性分别记录；局部物体上移不能自动标成上升。
- 先按独立场景/采集会话及其关联素材分组划分训练、验证、测试，再提取或拟合涉及统计量的步骤；同源裁剪、重放、增强、随机种子不跨分区。
- 动作标签来自预定义任务规则或独立教师，明确时间对齐与轴掩码；未标注轴和区间不按零监督。旧读出、旧 RC 和实测速度不自动成为目标。
- 测试数据不得用于调增益、调选组、选神经元、定预热/延迟或选图。历史录像可重放，但须注明时间基准及固定相机域的限制。

### F7 连接组贡献验证

- 必须比较真实图、受控重连图、直接视觉读出、均值/零动作；旧读出仅作历史参考。
- G/R/W 由同一经 P0 核实的完整参考图派生；原始自连接在主重连与权重置换对照中固定，重连只处理非自连接且不得新增自连接。阈值等简化的影响另列，不能与拓扑变化混为同一因素。
- 重连图以真实图为母图，通过同符号源节点的有向双边交换生成，保持节点/输入输出身份、逐节点入出度、符号入度及规定的权重统计；记录未保持的入强度、结构可达性与放电分布。
- 每个图独立训练同容量解码器，使用相同训练数据、特征定义、超参数搜索预算和种子协议。真实图训练的读出直接套到重连图不构成主对照。
- 同时设计固定拓扑权重置换与相关通路干预，区分拓扑、权重分配、整体失活和任务相关传播；消融需有规模匹配对照。
- 图改造仅是标记为 `research_control` 的离线实验对象；不能进入生产加载器、默认模型、设备控制或缺失回退。此设计不改变当前真实图加载限制，未来实施需显式落实隔离。
- 协议预先定义主指标、配对单位、随机种子、实验预算、正/负/证据不足判据和停止条件；按场景而非帧计算泛化证据。

### F8 证据与产物

- 保存实验登记、图/配置/源码哈希、特征模式、标签协议、分区、种子、模型、逐场景指标、延迟与失败记录；缓存身份必须覆盖上述影响结果的因素。
- 离线可解码性、闭环控制、实体效果和跨设备迁移分别验收。统一运动接口不等于通用解码器已成立。
- 计算预算不足或结果不支持真实图优势时如实记录；不得通过删失败种子、挑场景或增加人工规则制造正结果。
- 参数和删减决策标注为官方数据属性、文献假设、工程候选或本项目实测；只有存在可复现运行记录、比较条件和结果时才可称“实测得出”。后续简化不得覆盖完整参考资产及其结果。

## 边界条件

空群组、模式/来源不匹配、时间倒退、非有限数据、缺失必需输入、未经标注的轴、没有足够独立场景均须给出明确错误或未验证状态；不能静默降级。未知递质符号继续作为有记录的模型假设。图结构可达不代表功能有效。

## 技术约束与兼容性

沿用 `brain/`、`senses/`、`learning/`、`diagnostics/`、`control/` 分层；`learning → control`，诊断不发动作。保留既有序列化标识、来源与版权。新来源/契约不得伪装成旧特征，旧资产只读保留；V2 使用独立版本产物，无自动覆盖或迁移。
