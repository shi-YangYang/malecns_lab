# Spec — MaleCNS 数据过滤与输入输出审计

状态：Done。独立验收 AC1–AC4 PASS，见 [acceptance.md](acceptance.md)。

## 背景

用户要求先完成原始数据到脑模型的数据过滤审计，以及视觉输入、神经输出和缺失群组审计，交付报告。官方 v1.0 flat-connectome 目录 11 个文件已下载并通过大小与 MD5 校验，现有运行模型为 data/malecns_brain.npz。

## 目标

以本地官方原始表、当前模型和实际代码为证据，说明数据经过哪些过滤、哪些信号经过哪些群组、哪些群组缺失或映射存在局限。

## 非目标

不修改业务代码、模型、配置或读出，不重建模型，不训练网络，不进行刺激响应或硬件实验，不提交或推送 Git。

## 当前行为

构建器对注释和连接进行过滤，并将递质类别转换为连接符号。视觉编码、LIF、人工读出与设备监督共同组成现有实验路径；学习读出是另一条路径。

## 目标行为与功能需求

1. 统计原始注释和权重表，逐项给出筛选前后连接数与突触计数，区分官方置信度阈值、端点筛选、自连接和本地 min_synapses。
2. 对照当前 NPZ 的节点、连接、标签、元数据，核对数据一致性；检查递质缺失及默认符号。
3. 解析合并后的实际配置与读出文件，列出群组正则、左右侧、角色和实际数量，区分未匹配、侧别缺失、过滤丢失与生物学未知。
4. 追踪像素、特征、外部刺激、神经传播、输出读出、动作和监督的代码路径，标明人工规则及未接入路径。
5. 如用图可达性定位断路，只报告结构可达性，不推断功能、因果或真实果蝇行为。

## 边界条件

片段不等同于完整神经元；原始重建缺失无法通过本地文件补全。官方 traced-only 和 significant-only 文件为不同分布，不作为完整图分母替代品。统计区分有向连接与多个突触，过滤顺序和分母必须可追溯。

## 技术约束与兼容性

沿用项目真实连接组约束。大表按批读取；分析脚本与机器可读结果保存在 data/audits/malecns_20261016，报告保存在 docs/MALECNS_AUDIT.md。已有数据与运行资产保持不变。
