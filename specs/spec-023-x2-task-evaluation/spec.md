## 问题与范围

两轮纵向 MVP 证明脑输出可接到官方 MC 并得到运动/停车反馈，但两轮均 FORWARD，尚未证明输入改变后决策正确。先检验同一完整 MaleCNS、同一最终 GPU checkpoint、同一冻结优化后端和既有纵向适配规则，在预登记输入下能否前进或停止。

本阶段是确定性的离线任务筛查。输入是明确标记的虚拟方标投影，非仿真RGB或真实相机；不模拟运动，不向ROS/设备发送动作。停止意图不是机器人实际停车证据。模型能力FAIL仍可构成已完成的评估；不能为取得PASS调门限、改样本、训练或扩大实验。

## 冻结任务与样本

工程任务目标：清晰居中远目标应前进，近目标或无目标应停止。此目标是本轮拟定的X2纵向任务要求，不声称等于历史无人机训练标签。仅作受控基线，不推断目标跟随、可靠避障、泛化或完整连接组优势。

复用 `senses.x2_marker.marker_frame`：160×120 BGR，水平视场72°，方标0.2m，灰32背景与原红标色；相机位置(0,0,0.65)、单位四元数，目标在(距离,0,0.65)。缺目标帧为相同灰32背景，不以伪造位姿表示目标消失。标签与距离只用于生成/评分，不进入脑或动作适配器。

固定顺序运行下列5个场景，每场景重新执行原600步空白预热，独立神经/感觉初态；场景内连续3帧，每帧500步（50ms神经时间），保留递归状态。总15帧、10500神经步。各场景初态摘要需一致，避免混入前一场景的历史。

| 场景 | 三帧距离（m） | 三帧期望意图 |
|---|---|---|
| far_hold | 2.0, 2.0, 2.0 | FORWARD, FORWARD, FORWARD |
| near_hold | 0.5, 0.5, 0.5 | STOP, STOP, STOP |
| absent_hold | 无, 无, 无 | STOP, STOP, STOP |
| approach | 2.0, 1.5, 0.5 | FORWARD, FORWARD, STOP |
| disappearance | 2.0, 无, 无 | FORWARD, STOP, STOP |

唯一决策为既有 `control.x2_protocol.intent`：原始vx严格大于0.03才FORWARD，否则STOP；vz/wz完整记录但不评分/执行。不增加距离、目标可见性、教师标签或其他规则覆盖模型输出。

逐帧记录期望/实际、原始三轴输出、logits、features、输入像素/hash、场景/帧索引、实际神经步、前后状态摘要与执行身份。每场景保存预热与最终完整状态；逐帧保存输出数组。沿用真实spike旁路，22群组/32神经元、50步一批，每场景独立telemetry目录以防神经步重置混淆；每场景42批、总210批，采样错误/缺批须可见。

## 判定与报告

评分冻结在首次完整脑运行前：每场景3/3正确才通过，整体15/15正确且无无效输出才 `behavior_pass=true`。分别报告FORWARD命中（6帧）和STOP命中（9帧）、混淆计数、逐场景与逐帧结果；同时列恒FORWARD=6/15、恒STOP=9/15的无模型基线，避免总体正确率误导。

近目标和消失后的首帧即要求STOP，后续第二/第三帧用于观察是否持续或延迟响应；50ms是单帧神经窗口，不是墙钟延迟承诺。说明固定场景/单次执行、重复帧相关、不具备统计泛化证据。不以群组脉冲变动单独证明正确决策。

技术执行状态与行为得分分开：身份/冻结/完整性/有限值/监督失败属于执行FAIL，不得评分为已完成成功；有效完整执行但行为不合期望如实报告能力FAIL。必要软件检查不要求模型达标。所有原始失败保留，不自动重试或跑仿真来掩盖离线问题。
