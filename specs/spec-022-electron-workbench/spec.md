# Spec 022 — Electron 仿真与脑活动工作台

状态：P0、P1/P2 均已完成。2026-10-23 用户认可原型并授权正式实施后，同一控制脑遥测、离线回放与官方GPU仿真生命周期已接入；完整图开关遥测配对、原生桌面两轮闭环与资源关闭通过，见[实测](actual-integration.md)、[独立验收PASS](p1-p2-acceptance.md)及[冻结协议](implementation-contract.md)。交付为本机开发运行，无安装包。

## 背景与目标

将 X2 仿真和 MaleCNS 脑图放进同一个桌面窗口：左边观察机器人，右边观察产生控制输出的脑，能够沿同一实验时序查看输入、神经活动、动作与反馈。保留现有 Python/MPS 与官方 Sim + MC + AimDK，桌面负责呈现和编排，不重写 SDK 或数值模型。

当前 `apps/atlas` 是 TypeScript + Three.js 的真实胞体图谱，回放固定 CPU LIF 诊断模型的群组平均发放率；它不是 X2 的训练后 MPS 控制脑。Spec021 的控制进程未输出逐神经元脉冲历史，完整边界状态也不能替代脉冲记录。现有两张页面并排，只能作为布局原型。

## 分阶段范围

### P0：已完成的示例原型（历史范围）

- 新建 `apps/desktop`，Electron 主进程与 TypeScript/Three.js 渲染界面分开。保留现有 atlas 入口，优先复用其数据契约和实际胞体坐标，不引入框架迁移。
- 一个桌面窗口，左右分栏可调整；左侧使用 Spec021 已有 X2 截图，右侧用真实胞体坐标与已有诊断活动记录展示旋转、选择群组及曲线。按用户最新截图要求，删除整块底部播放区和状态栏、顶部页面标题行，让左右面板使用腾出的空间；保留最上方应用标题栏及两侧面板内容。
- 保留“原型预览”“历史截图”“诊断回放”等既有面板标识；不显示假实时连接、假逐神经元脉冲、假性能或假运行成功。删除播放区后只显示既有向左记录首帧与其群组曲线，不启动自动播放或发送机器人命令。
- 所有科研资产继续在原目录，启动时按明确白名单读取或复制到 gitignored 原型素材目录；不把模型、图谱导出、日志或截图提交到 Git。缺素材给出错误，不生成替代网络。
- 静止/窗口隐藏时不持续执行无意义渲染，限制像素倍率。只启动轻量桌面原型，不启动 VM、仿真、完整脑或训练。

### P1：同一控制脑的真实活动与回放（已完成）

- 从实际执行控制的冻结 MPS 进程采集遥测，不另起 CPU 诊断脑来冒充。记录 checkpoint、图/源码身份、run_id、观测/决策序号和神经步号。
- 区分神经模拟时间、宿主单调时间、接收时间与显示延迟。批量传输真实群组统计；被选神经元的脉冲事件必须来自真实 spike 张量。未记录的神经元和丢批数据明确显示缺失。
- 全脑、全步脉冲归档不是默认需求；先确定可观察群组和按需神经元数量、批次大小及有界缓冲预算。不能每个神经步同步 GPU 到 CPU，不能为了流畅插值生成脉冲。
- 显示层背压不能阻塞控制循环；丢弃显示批次须显式计数，落盘完整性单独记录。开关遥测的数值等价与耗时/内存差异需在实现前冻结验收预算。
- 界面支持实时与回放，两者清楚区分。现有单帧约 3.68 秒的共驻留计算不是 60 Hz；展示更新不能伪称计算频率。

### P2：官方仿真和资源生命周期（已完成）

- 使用受限的本地 noVNC 视图接入现有 GPU 仿真；Electron `WebContentsView` 与本地应用分隔，不使用 Node-enabled 远程页面或 `<webview>`。不得给 noVNC 暴露进程/文件操作能力。
- 实验准备、运行、等待计算、停车、结束、失败均有真实状态；统一控制台沿用 Spec021 的零速等待、超时、观测新鲜度及有界动作契约。
- 停止/退出先完成安全停车及证据封存，再关闭本应用拥有的子进程、项目容器和私有 VM。启动失败/退出异常也有清理路径，不停止 Noria、不重启 Docker、不改默认 context。
- 只有同一次实际运行的神经事件和机器人反馈才可称“同步”；截图时间、视频帧时间和遥测时间各自保留，明确视觉传输滞后。

## 技术与安全约束

- Electron + TypeScript + Three.js；沿用 npm 和 package-lock，局部依赖，不替换 Python 环境。第一版面向当前 macOS，Windows/Linux 打包、签名、自动升级另定范围。
- 主进程承担有限系统能力；渲染进程 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，CSP、导航/弹窗/权限限制。P0 不提供 shell、任意文件读写或真实实验 IPC。
- 资源白名单不可暴露整个仓库或允许路径遍历。科研资产来源和序列化身份保留；新增遥测须新增版本，不回写旧结果/哈希。
- 运行完整脑与仿真的后续验证须有明确阶段执行范围、单进程锁、至少 1 GiB 系统预留和有界时长。编码与原型预览期间保持重资源关闭。
- 不涉及新训练、真实相机、真实机器人、动作轴扩展、官方 SDK 改造、现有策略任务能力结论。
