# P0 原型显示修复

2026-10-23。范围：`apps/desktop/src/style.css`、`apps/desktop/src/brain.ts` 的显示参数。风险等级 S1；不修改模型、活动数据、控制逻辑、相机或 Electron 主进程。

## 问题与修复

1. 历史截图容器同时固定 `height: 100%` 并使用 `max-width: 100%`，高窗口/窄分栏会压缩宽度而保留高度，造成机器人纵向拉长。现在以仿真区域为 CSS size container，裁剪视口宽度取可用宽度与可用高度对应宽度的较小值，再由 `667 / 678` 比例确定高度；不足部分留背景。源截图只设置宽度、保留其自然高度，按原图 1280 × 720、裁剪 x=307..974 / y=20..698 的比例与偏移显示。未修改或重采样科研截图文件。
2. 静态胞体点云过暗。冷色基底从 `(0.22, 0.36, 0.46)` 调为 `(0.33, 0.50, 0.63)`，基础 alpha 从 0.27 调为 0.40；活动项相应从 0.60 调为 0.47，最大 alpha 维持 0.87。同步更新图例冷色端。真实群组平均发放率、归一化、选中态、点大小与暖色端保持原逻辑，未增加或伪造脉冲。
