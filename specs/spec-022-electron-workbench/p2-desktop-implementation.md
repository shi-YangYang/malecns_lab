## 实际修改

- `apps/desktop/electron/controller.mjs` 固定启动本仓库 `.venv-train` 的 `malecns_lab.experiments.x2_desktop --execute --sim-only`，输出目录由主进程生成。stdin 仅 continue/stop；不暴露命令、参数或路径输入。拒绝重入准备，只有 runtime 安全终态及子进程实际退出后才能正常关闭窗口；exit=0 不自行当成停车/清理成功。
- `preload.cjs` 只暴露具体实验、快照、封存记录与视图位置方法；每个 IPC 校验主窗口、主 frame 和完整应用 URL。
- 官方 noVNC 使用独立内存 session 的 WebContentsView，无 preload/Node，网络限固定 127.0.0.1:6081 HTTP/WebSocket，导航/弹窗/下载/权限默认拒绝。视图随左侧 bounds 调整，离线、回放和隐藏时不可见。左侧包含必要的官方 Reset/Run 操作提示。
- 主进程快照读取缓存 250 ms，并限制单批 256 KiB、manifest 1 MiB；回放仅接受已封存 desktop-* 目录，验证根目录/符号链接/路径/总档案 16 MiB，并按批读取。记录未封存、不完整、缺批均不冒称完整。
- 资产准备只复制真实 atlas 坐标及原图来源，不读取旧 CPU 诊断活动。点云按当前控制脑 manifest 的 body_id 映射；群组均值着色与 32 个选定神经元的真实 spike 栅格分开。每批替换栅格，不延续/补造脉冲；显示端跳批、采集丢批、缺坐标分别呈现。
- 标题栏提供准备、开始、停止、记录选择；面板内提供逐批前后操作。实时快照默认 250 ms，无积压轮询；隐藏窗口暂停读取，脑图保持按需渲染。回放不计算当前墙钟延迟，不展示实时仿真作为历史画面。
