# Spec 016 — 官方 X2 仿真运动 MVP

状态：Done（限官方仿真动作 MVP，独立验收 PASS）。2026-10-23。用户已授权开始 MVP 第一阶段，并要求不用仿真时关闭以减少发热。

## 目标与范围

在已经跑通的 GPU 环境中，使用原版 AimDK、MC、sim_mujoco 验证站立、短时前进与停止。记录指令、服务响应、模式、实际姿态和位移，区分程序执行成功与机器人动作成功。本阶段不接 MaleCNS、不训练、不连接真机、不改官方控制器或物理参数。

## 运行协议

- 只操作私有 `runtime-rebuild` 与 `malecns-x2-gpu-trial`；CPU 仿真保持停止，不改变默认 Docker context，不动无关服务。
- 阅读、编写与分析时关闭 GPU 容器和私有 VM；仅在实际动作窗口启动，结束后关闭，不留常驻仿真。
- 先建立只读里程计与 MC 状态记录，再使用官方示例切换模式。按官方状态转移要求处理 PASSIVE → JOINT → STAND；需要时通过仿真 GUI 暂停、重置恢复初始姿态。
- 稳定站立后进入 LOCOMOTION；沿官方示例发送前进 0.2 m/s、横移 0、角速度 0，持续约 5 秒，然后持续发送零速度并观察停止。仅在当前步骤有反馈且未倾倒时继续。
- 站立观察至少 5 秒；停止后观察至少 5 秒。出现明显倾倒、状态拒绝或持续失联时停止动作，保存证据，按具体故障定位；不反复盲试。
- 如需转弯扩展，另记录为附加检查，不作为本次前进与停止的必要门槛。

## 验收标准

- [x] AC1：只运行隔离 GPU 仿真，原版组件和模型未改，原始命令与日志可追溯。
- [x] AC2：STAND 模式确认；画面与里程计支持机器人直立并保持至少 5 秒，不能仅凭服务成功判定。
- [x] AC3：前进命令期间实际沿起始身体前向产生至少 0.2 m 位移，未倾倒；记录实际位移与耗时，不把目标速度当实测速度。
- [x] AC4：零速度后末 3 秒水平位移小于 0.1 m，保持直立；模式与画面作辅助证据。
- [x] AC5：结果与失败均如实记录；结束时 GPU 容器和私有 VM 关闭，CPU 仿真保持停止。

运行链路按 S2 处理，限定当前仿真接口与实际动作；只读采集脚本按 S1 做一次最小语法检查。独立验收复用已有记录，不重跑动作、测试、构建或模型。既有 60 FPS 结果不重复测量。当前授权不包含本阶段 commit/push。
