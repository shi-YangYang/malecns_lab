# Spec 018 — X2 最小动作适配器

状态：Completed / 独立验收 PASS。2026-10-23。用户“继续”授权实施 Spec 017 的 STOP/FORWARD 适配器，并在现有隔离 GPU 仿真做一次有界验证。

## 范围

新增局部控制状态机与仿真专用 ROS 入口；默认不动作，显式启用后仅发 STOP 或固定 MC 目标 `(0.2,0,0)`。这不是实际速度承诺，也不是 MaleCNS 闭环。保持 BodyVelocity 等既有契约，不修改官方 SDK/MC/Sim/模型/参数，不升级依赖，不训练、不接真机。用户后续授权每阶段完成后本地commit；不push。

控制核心可注入单调时钟与发送回调，不依赖 ROS；ROS 只在显式执行仿真入口时导入。输入源自定义且与官方示例不同；不接管其他来源。发布与神经计算解耦；本轮仅用受控意图驱动。

## 行为

- 构造/导入/帮助/默认 CLI 不连接 ROS，不注册输入源，不发布或启动进程。
- 显式启用后先发零并观察。正常 FORWARD 需要新鲜里程计、MC STAND 或 LOCOMOTION、直立状态、自定义输入源匹配；不自动排队。首次从无输入源启动采用下述有界 CLAIMING，不能永久放宽控制权检查。
- FORWARD 带有限有效期，单次从开始起最多 5 秒，续期不能绕过该上限；非法输入、未支持轴或目标、意图过期、反馈过期、控制权丢失、姿态异常均转零，条件恢复后不自动续走。
- 反馈默认年龄限制：odom 0.25 s、MC 0.5 s；这是本地默认监测阈值，不是硬件保证。接收时间使用注入单调时钟，未来/倒序/非有限值无效。
- 停止时持续发零；只有停止请求之后的连续新鲜观测支持 STAND、直立、水平速度<0.02 m/s 持续>=1秒且水平位移变化一致，才确认 STOPPED。同一旧样本不得靠重复tick累积确认；MC在窗口内切离STAND、数据间隙或位置异常均重置确认。
- 超时、失联或发送失败不得回报成功。控制核心保留失败原因；进程结束前做有界零速/反馈处理，不能只清零变量后立即销毁ROS。所有退出路径记录停止是否确认。

## ROS 入口与实际运行

### 2026-10-23 集成后限定修正

首轮实际 ADD 成功、1033次零发布、209条MC反馈，但当前输入源始终为空，未发非零。随包官方 `MC_control.html` 明确：零指令不切换输入源；新源必须发送有效非零才能接管。原“零发布先取得控制权”前提不成立，失败证据保留于 `data/x2_sim/agibot/data/var/x2-adapter-20261023/evidence/`。

仅在显式本轮前进请求、注册成功、当前源为空、STAND与直立及两路新鲜反馈齐备时，允许一次 CLAIMING：仍用固定0.2目标，最多0.5秒等待**请求后新的MC反馈**确认为本源，然后转FORWARD。其他非空源禁止抢占；超时或出现其他源/异常立即持续发零，恢复不自动重试。CLAIMING时间计入同一意图TTL和5秒硬上限，续期不得延长CLAIMING期限。已有本源继续按原门控；零速停止仍需真实反馈确认。纯核心此启动能力须显式启用，默认行为不变。限定修复后允许一次有依据的集成复验，旧日志和源码快照不覆盖。

第二轮已发起前进，首次本源反馈为 `STAND_DEFAULT / 200`，下一条为 `LOCOMOTION_DEFAULT / 100`；原代码将其视为异常，0.10秒内取消后确认停稳。官方 `McActionStatus.msg` 定义200为TRANSITION，100为RUNNING。限定支持一次起步切换窗口：显式前进请求后最多0.5秒内，允许本源STAND/LOCOMOTION的200态，保持新鲜、直立、源匹配与原TTL要求；必须在原窗口到期前收到本源LOCOMOTION/RUNNING（或保持STAND/RUNNING），不得靠重复200或意图续期延长。请求前200仍拒绝；窗口后再次200或未知状态按故障停止；停车确认仍只认STAND/RUNNING。修改后只复验这一具体失败，旧数据保留。

第三轮完成约1.995秒非零发布、约0.953m前向位移并返回成功；原始数据审查发现窗口从152.282秒起算，但最后一条超0.02m/s反馈在152.329秒。虽本轮确认时实际已低速约1.049秒，窗口算法仍可把较慢MC样本回溯到超速之前。限定修正：任何速度/姿态/模式/数据间隙/位置异常导致窗口重置后，窗口只能从重置点之后**两路均推进的新样本**开始；不得用重置前的另一话题样本回填时长。增加快odom/慢MC的定向检查，复验停车窗口后再验收，旧成功标记不直接作为AC3通过。

`python -m malecns_lab.experiments.x2` 默认为无ROS预览；实际运行必须显式指定执行与仿真限制，并核对 domain47/localhost隔离。使用现有 ROS Humble Python3.10 环境，无需安装整个>=3.11科研包，限定模块保持3.10兼容并按源文件加载。不得引入宿主ROS依赖。

只操作 runtime-rebuild 与 malecns-x2-gpu-trial。准备、编码、分析期间关闭；测试需要时才启动，结束马上关闭；CPU仿真保持停，默认context/Noria不动。原始日志在忽略目录保留。先官方SD和GUI重置恢复站立，再由本适配器发前进意图2秒（<=5秒），然后零速观察最多12秒。预期至少0.2m实际前进、直立并停止；若具体失败，保存并只修相关问题，不盲目重试。
