# Mac 上的完整 MaleCNS 学习路线

日期：2026-10-17。状态：Planning / 下一批实施方案；尚未实现训练后端或运行学习实验。本文细化 [Spec 008](spec.md) 与 [Plan](plan.md)，不把整个 Spec 提前标为 Ready。

## 已确认方向与当前证据

用户确认：基于完整 MaleCNS 训练网络本身，让其学习指定目标跟随，输出前进、升降和转向；当前算力限这台 Mac。研究贡献需要区分任务完成、内部学习作用和真实拓扑作用，不宣称完整生物还原、全球首次或性能领先。

2026-10-17 本轮只读核对：

- 本机 Apple M5、10 个物理 CPU 核、16 GiB；项目 `.venv` 为 Python 3.14.6。模块发现查询显示 NumPy/SciPy 已存在，PyTorch/MLX/JAX 不存在；未安装新依赖。
- `data/malecns_v2/load_check.json` 已记录完整参考图 166,700 节点、25,582,938 条内部有向边、124,177,617 突触计数。沿用既有完整数据定义和账本，不重新下载、裁图或重建。
- `data/diagnostics_v2/standard_stimuli_20261016/run_summary.json` 记录旧前向诊断耗时 96.8296 s、峰值进程 RSS 1,102,233,600 bytes；对应六段共 15 s 仿真。这个比值约 6.46，不能推算新后端训练速度。
- `brain/lif.py` 为 NumPy/SciPy 原地更新；`learning/train_v2.py` 训练固定活动特征上的岭回归。现有工具不能完成网络内部反向学习。
- V2 感觉输入按左右群组广播，未保留群内像素空间位置；现有简单房间仿真尚非经验证的目标跟随训练环境。

上述是读取已有记录和本机环境的结果，不是新训练性能测量。

## 第一个里程碑：完整图内部学习可行性

交付目标是可训练后端、数值参考、一次完整图内部更新及资源报告，不是飞行成功。P0/P1 无需真实录像、动作标签或连接 Tello。

### P0：先明确数值模型并验证训练算子

1. 以 [Shiu 官方模型](https://github.com/philshiu/Drosophila_brain_model/blob/main/model.py) 为核对来源，实施时固定源码版本和摘要。它是参数与方程来源，不等同于 MaleCNS 生理真值。
2. 独立登记输入施加位置、积分顺序、阈值、复位、不应期、突触延迟及时间步。旧引擎向 `g` 加外部输入，官方实现向 `v` 加输入并取消被驱动细胞的不应期；不能把旧引擎输出当作唯一正确答案。新语义需要单细胞、双细胞的独立数值参照，保留差异记录。
3. 首选评估 PyTorch CPU 稀疏后端，使用独立训练环境，保留现有 Tello `.venv`。先核对 Python/软件包兼容性，固定实际安装版本；不得仅依据 Apple GPU 存在就宣称稀疏 MPS 训练可用。
4. 验证固定稀疏矩阵乘密集状态的前向及对密集状态的反向；使用微型数值夹具检查代理梯度。小图仅作算子和动力学检查，不作为脑模型替代品。
5. 旧实现按实际发放的索引遍历边；直接照搬该索引筛选会遗漏部分静默细胞的代理梯度。训练实现应保留完整状态的梯度通路，优化前先建立正确基线。

P0 的数值契约须先单列为可实施子任务；确认输入和事件顺序后，才能把相应实现子批标为 Ready。目标外观等任务决策不阻塞这一工程阶段。

### P1：训练内部共享增益，保留完整图

首个参数化候选为：

```text
W_effective[post, pre] = W_base[post, pre] * gain[type(pre)]
recurrent_input = W_base @ (gain_by_neuron * delayed_spikes)
```

- `W_base`、body ID、全部原始边和突触计数只读；已有递质符号及其未知项假设随模型记录。
- 优先按突触前细胞类型共享增益；缺失类型进入显式缺失组，分组清单与参数数量在运行前保存。增益初始化为 1、有界且为正，具体边界与正则在 P1 协议中预登记。
- 这些增益改变递归网络内部有效连接强度，属于内部学习。保留完整图不要求首轮为每条边创建独立可训练变量，也不表示所有边或群组在一次刺激中都有非零梯度。
- 第一轮固定感觉编码与读出，仅更新内部增益，隔离内部学习作用。使用确定性输入、独立新参数文件；先验证数值更新与下游响应，再增加联合学习。
- 不生成 N×N 密集连接矩阵。166,700² 个 float32 数值理论上约 103.5 GiB，超过本机容量；共享增益也不会消除完整图每步传播和反向计算成本。

资源探针建议默认：单进程、单序列、float32、CPU；先验证算子，再从很短的模拟窗逐级扩大。预热可不存梯度，但必须完整保留并记录神经状态与延迟；短窗不能证明长时任务可学习。首轮子进程 RSS 中止阈值建议 6 GiB、单次探针墙钟预算 10 分钟，启动前依据系统实际余量收紧；这些是试验限制，不是预测内存或耗时。资源监控应覆盖载图、前向、反向和保存过程，阈值轮询不等于操作系统硬内存保证。

首轮停止条件：完成一次有证据的内部更新，或预算/数值条件失败并完整记录。未通过时不得静默删边、换小脑、改称仅读出训练成功；扩展窗口与预算需基于本轮具体结果另行登记。

报告与 checkpoint 至少包含：

- 完整图身份、节点/边数量、模型与数值版本、分组表、随机种子、输入与损失定义；
- 内部梯度、实际更新量及有效连接强度变化，确认输入/读出在该探针未变；
- 同一输入下更新前后下游状态/响应，以及将内部参数恢复后得到的对照；
- 前向/反向/更新耗时、峰值 RSS、模拟时间与墙钟时间；失败、截断及未观察到变化也须保留。

一次更新只证明实现可用及内部参数具有可观察作用；不得以单次 loss 下降宣称已学会控制。

## 第二个里程碑：小任务中的闭环学习

建议初期使用已知尺寸、外观明确的标记目标，先学习三轴跟随控制；这仍是任务建议，尚未把任意目标识别视为需求或已实现能力。目标指定方式、距离、容差和丢失处理需在此阶段实施前确认。

数据流：相机图像 → 明确的感觉编码 → 完整可训练 SNN → 小容量动作读出 → `vx/vz/wz` → 环境更新 → 新图像。外部标记检测如被采用，应明确识别由该模块承担。目标真值只进入教师、奖励和评分，不能进入部署策略；视觉特征不得直接绕过 SNN 进入动作读出。

1. 在当前 `drones/` 职责下建立三轴目标跟随任务，动作改变相机位姿与下一观察。生成场景和教师示范不需要用户先录像，但仿真结果不能充当实飞结果。
2. 为目标位置和尺度提供保留空间信息的新感觉编码；不能沿用节点编号猜测视网膜位置。新映射、输出集合与模型须有独立身份，不静默更改 V2 的群组校验或复用固定活动缓存。
3. 先进行短轨迹模仿学习，再让模型闭环运行，在其实际访问的状态上收集教师修正。教师是可解释的工程基线；前进/升降/转向分别形成课程，随后联合。暂不把昂贵长时强化学习作为第一步。
4. 以短窗反向和单序列控制内存，保留状态及截断记录；时间窗必须覆盖实际通路响应，不能为了适配内存而把远端输出训练断开。
5. 训练、验证、测试按场景与轨迹族隔离；记录跟踪误差、目标保持、距离误差、三轴覆盖、平滑性及失败。先冻结任务阈值，再看测试结果。

## 第三个里程碑：验证学习与连接结构的贡献

采用相同输入、输出接口和公平的参数/训练预算记录，比较：

1. 冻结完整脑＋同容量读出；
2. 训练内部增益＋读出；
3. 将已训练内部增益恢复初值的急性干预；
4. 直接视觉控制基线和受控重连图的重新训练。

恢复参数检验当前策略依赖什么；重新训练冻结脑检验训练内部是否有收益；受控重连检验真实拓扑的作用。这三类证据不可互换。先做可负担的试验，再按资源与效果登记研究规模，不能只用训练 loss 形成性能结论。

## 第四个里程碑：部署时延与真实 Tello

先测相机到动作的完整时延及抖动，再做地面实时影子运行。旧前向约慢于实时时间 6.46 倍，不能直接用于承诺部署；训练成功也不自动解决推理速度。

若只适合较低频策略，要在包含真实延迟的闭环仿真中重新验证，再决定实机范围。Tello 机载控制器继续负责姿态稳定；网络学习的是三个运动目标，不宣称直接控制电机。实飞另立明确范围，当前方案不启动硬件。
