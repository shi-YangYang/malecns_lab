# 视觉输入的可观测性问题与下一步

日期：2026-10-17。状态：诊断发现；[Decision 010](../../.ai/decisions/010-lamina-tonic-variant.md)及[P2c](p2c-tonic.md)已登记可选数值变体，原P0/P1协议保持。没有启动新的全图仿真；实现与验收状态以P2c报告为准。

## 本地元数据与方程证据

只读 NPZ 的注释数组（未加载权重矩阵）得到：R1–R6 共3,377个，全部标为 histamine；L1 1,776个全部 glutamate；L2/L3/L4/L5 分别1,779/1,772/1,770/1,787个，全部 acetylcholine。当前 `NT_SIGN` 将 histamine/glutamate 设为负、acetylcholine设为正；这是模型符号规则，不能推断为每个真实受体的生理作用均已测定。

P0 从 v_rest=-52mV、g=0、空延迟队列初始化，阈值-45mV，无背景偏置/噪声。P1 仅在 R1–R6 施加外部电压。由此可作归纳：在第一批非输入细胞发放前，所有外来的突触输入仅来自被强迫发放的 R1–R6，均为非正；膜电位从静息只能保持或降低，无法跨越更高的阈值。因此这些条件下不会出现第一批非输入脉冲，也无法产生依赖这些脉冲的多跳传播。

这是现有模型的数学推论，不是新全图实测，也不表示真实果蝇缺乏视觉功能。直接连接的非输入细胞仍可能有膜电位变化；不能把“无下游脉冲”扩大为所有下游状态绝对不变。

P1 的 L1 膜电位目标仍可以隔离内部增益的数值作用，但其通过不能充当视觉已经传到下降神经元或学会控制的证据。代理梯度非零也不等于前向脉冲传播。

## 科学来源与边界

[Lappalainen 等，Nature 2024](https://www.nature.com/articles/s41586-024-07939-3)的连接组约束视觉网络同时估计细胞类型的静息参数、时间常数和突触尺度，并通过任务训练与独立神经响应比较约束模型。这支持“连接图不能独自决定动力学”的方法论，不是本项目任意背景电流数值的来源，也不等同于当前 MaleCNS SNN。

[Fly visual transmission 实验，Scientific Reports 2019](https://www.nature.com/articles/s41598-019-38850-x)描述光感受器 histamine 引起下游 lamina 细胞超极化。当前用统一阈值脉冲替代多种神经元动力学，必须说明其额外假设。

## 接续顺序

1. 完成 P1 固定协议及实际资源测量，不为追求视觉输出篡改该实验目标。
2. 独立建立完整输入/下降神经元集合、工程空间映射与可重复的事件编码；不猜测 body ID 的视网膜位置，不沿用旧33细胞读出。
3. 登记无梯度响应诊断，分别测脉冲与膜电位，比较空白、位置、尺度刺激及静默；结果与上述预测相符或不符均保留。
4. 视觉中继的背景工作状态候选已在P2c单列数值契约：仅L1–L5的有界平衡电位偏移，初始8mV，严格零背景仍由原模型表示；不得悄悄恢复旧DNg02常量偏置。这个候选尚无完整图传播证据，不据此确定最终神经动力学。
5. 特别分开“允许外部输入”和“取消不应期”：当前 input_mask 同时控制二者，不能通过把背景细胞加入输入集合来暗中改变其动力学。

完整图、原始计数和来源保持不变。正式动作训练应先具有从视觉到指定神经读出的可观测信号；没有信号时先处理模型假设，不堆训练轮数掩盖问题。
