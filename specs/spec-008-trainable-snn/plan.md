状态：Implementation，按子批验收后提交。2026-10-17 用户授权完整实施、清理和逐步 commit，见 [Decision 009](../../.ai/decisions/009-fullgraph-training-execution.md)。

[Mac 执行路线](mac-execution-plan.md)保留最初规划时的环境事实。当前 P0 可训练数值核心、P1 完整图实际更新和 P2a 独立目标跟随环境已验收；任务学习、贡献比较及设备接入尚未完成，具体证据以各子批报告为准。

## 涉及模块

复用 `brain/reference` 与图来源校验、`senses`、`diagnostics`、`learning` 的对照和登记概念及 `control` 的动作契约。已新增 `brain/trainable*` 核心和 `drones/follow_*` 环境；两者仍待策略集成，不复用旧固定活动缓存假装联合训练。

## 修改顺序

1. P0 数值与资源方案：固定所对照的官方模型版本，说明外部输入、复位与不应期语义；定义最小独立参考及资源预算。检查完整图训练候选所需的稀疏操作，不先承诺 MPS 支持。
2. P1 内部学习可行性：在完整图保留全部节点／边的条件下实现一组有界共享突触参数，验证一次真实更新及前后响应。先登记参数分组、范围与学习方法。数值单元检查与完整图资源探针分开，前者不算主模型。
3. P2 目标跟随任务：明确指定方式、目标外观与尺度、三轴范围、跟随距离和失败定义；建立动作改变观察的训练环境及独立场景划分。仿真真值隔离于策略输入。
4. P3 学习与比较：以同条件冻结脑作对照，进行示范学习及按预算选择的闭环修正；保存内部参数变化、干预和未见场景指标，再扩展真实拓扑贡献实验。
5. P4 部署可行性：单独测端到端观察时延、策略周期和监督介入；具备证据后另立 Tello 试验范围。当前不启动设备。

P0、P1、P2a 均有独立子规格且已验收。P1 于2026-10-19按1GiB预留完成实际更新，采样峰值RSS 1.830GiB、总墙钟362.64s，其中反向291.70s，见[运行报告](p1-run-20261019-r3.md)与[独立PASS](acceptance-p1-run-r3.md)。接下来依据反向成本评估保持完整图与梯度语义的性能优化，再冻结配对神经响应实验；本次短窗内存条件已满足，不继续等待释放通知。P2a 已登记标记物、距离和任务容差。后续策略集成与训练仍需登记输入输出映射、时间窗与实际资源预算，不提前宣称可学习。数值与仿真工作不需要先采用户录像；正式闭环学习不能仅由固定录像验收。

P2b 的[输入/输出与空间事件接口](p2b-mapping.md)已验收，提交 `4eada75`。其注释核对结合 P0 方程发现[静息工作点障碍](signal-observability.md)。新增 [P2c 数值变体](p2c-tonic.md)先独立实现有界早期视觉背景，原 P0/P1 无背景协议不变。数值实现不依赖完整图运行；背景是否改善视觉到下降神经元的可观测性，仍须后续预登记实验，不能由数值测试代替。

P2c已独立验收并提交 `d9d79a5`。[P2d](p2d-observability-tools.md)将配对可观测性的软件工具与实际完整图实验分开：先完成严格协议、完整状态分支、全部DN记录及独立证据校验，再依P1实测资源冻结实际协议运行。工具完成不能勾选AC2或宣称视觉通路通过。

[P3d神经闭环评估](p3d-closed-loop-evaluation.md)已独立协议PASS并完成新的[软件返工验收PASS](acceptance-p3d-rework-r1.md)：最终joint/独立frozen父终态准入、实际参数身份、任意帧完整状态、环境重放及全val后test规则实现，失败终局不算正式证据完成。新增模块保留已绑定训练源码；两份完整epoch参数具备后才运行首次1+1帧实际门槛。训练继续与工具准备不等于闭环结果。

[P3b r2联合更新实测](p3b-run-20261019-r2.md)及独立[实际PASS](acceptance-p3b-run-r2.md)已完成：完整图两帧动作损失更新内部参数和读出，恢复内部参数会改变动作，但本步内部影响使动作误差相对急性恢复增加0.00700335，未证明正向收益。五分支总238.29s、采样RSS2.757GiB。[P3c1](p3c-resumable-state.md)完整状态/Adam/游标续训存档已软件PASS，51项检查通过；[P3c2连续训练](p3c-training-runner.md)27项检查及首两窗跨进程/首次四窗实际续段均已独立PASS，后续同协议累计26/160窗。继续同一冻结run完成训练和独立frozen，再做未见场景与拓扑比较，不能用短前缀的数值效应关闭AC3–AC6。

[P2e有状态策略](p2e-neural-policy.md)已完成新的独立[软件PASS](acceptance-p2e.md)：28项定向数值检查证明跨帧完整状态、全部DN两半窗电位读出、内部theta动作损失梯度及controller边界。该接口仅有数值fixture证据，实际完整图动作更新、独立策略checkpoint及场景训练仍待下一批；旧gain-only持久化不能保存新策略。

性能子批[伴随 CSR 缓存](p1-adjoint-cache.md)及[共享SciPy前向](forward-csr-cache.md)均已软件和实际独立验收；最新[完整对照](forward-csr-run-20261019.md)P1耗时32.39s、配对诊断108.56s，全部已保存可比数值与前版精确相同。[首轮配对诊断](observability-run-20261019-r1.md)的科学边界保持：当前20ms刺激窗的DN差异在撤除后才出现，单纯总发放率不足。下一步细化保留完整状态、DN电位/时间信息的可微三轴策略，按新前向成本确认持续刺激/控制时间契约；不能把每帧重置的20ms窗口作为已证明的策略。后续任务训练、参数干预、冻结/视觉/拓扑对照及设备接入仍需对应登记与证据。

任务输入 → 感觉编码 → 有状态完整图 SNN → 小读出 → `BodyVelocity` → 环境 → 新观察。训练更新进入真实图内部参数，生成独立 checkpoint；参考图只读。训练日志应区分原始策略、监督执行、教师目标与环境真值。

## 风险与迁移策略

训练可能超出 16 GiB Mac 的可用资源；降低可训练变量数不等于降低完整状态传播成本。数值对齐、感觉映射和学习目标均可能影响结果，需要版本化与对照。既有 Spec 007 的实现／验收仍作为历史事实保留；冻结脑流程转为基线，不删除或重写旧记录。
