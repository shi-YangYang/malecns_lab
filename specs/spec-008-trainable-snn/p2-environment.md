# P2a — 三轴视觉目标跟随环境

状态：Done，独立[验收 PASS](acceptance-p2a.md)。本子批不导入训练核心，唯一动作边界是既有 `BodyVelocity`。训练预算及训练后端集成仍依赖 P1 实测；环境验收不表示 SNN 已学会控制。

## 任务与边界

初期采用 20 cm 红色方形标记，目标距离 1.5 m；首轮不声称任意物体识别。相机输出 BGR uint8 图像（160×120，水平视场 72°），只由图像检测标记。检测器属于外部视觉前端，不把目标真值直接作为部署输入。

世界坐标右手系，z 向上；无人机局部 FLU，正 wz 左转。动作只接受 vx/vz/wz，范围分别 ±0.3 m/s、±0.2 m/s、±0.5 rad/s，其他轴非零报错。默认控制周期 0.1 s；简化机载速度响应为一阶滞后 tau=0.25 s。动作会改变无人机位置、相机位姿和下一图像。声明这是运动目标层面的仿真，不是经标定的 Tello 刚体/电机模型。

目标独立运动，包括左右、上下、远近及组合轨迹；不可跟随模型输出作弊。默认无人机高度 1 m、目标初始约在前方 1.5 m。场景参数显式包含初始偏移、目标轨迹、背景/光照、遮挡、视野外情况和随机种子。目标是固定世界平面上的方形，投影与可见性明确；不可把图像边缘裁出的尺寸当成完整有效距离观测。

## 模块与接口

- `drones/follow_env.py`（可按职责拆一个几何/场景文件）：环境、机身运动/目标更新、投影图像；不导入神经网络、DJITelloPy或训练库。
- `senses/target.py`：只接受 BGR 图像和相机/标记标定；输出 immutable 观察，至少有 detected/valid、归一化位置、表观大小、置信或覆盖、明确失效原因。不能接受环境对象或真值。提供保留空间信息的降采样标记 mask，供下一批感觉编码选择；别把 body ID 排序当解剖视网膜。
- `learning/follow_task.py`：教师、评分、场景登记与 rollout。教师允许使用真值，必须与部署 policy API 分开；视觉基线可以只用图像观察，两者来源分别记录。policy 回调只能获取图像/相机观察与时间，不接触环境真值。
- 复用 `control.body.BodyVelocity`；frame与truth分别访问，rollout明确区分原始policy动作、限幅执行动作、教师动作与评分真值。

API 可由实施者在上述边界内细化并记录，后续训练集成使用已定接口。不得修改 P0文件、共享动作契约或现有旧 sim；旧 sim 的替换/删除在清理阶段独立提交。

## 评估协议

先登记 pilot 场景族与固定随机种子，以完整轨迹划分 train/val/test。测试轨迹/背景组合不得进入教师训练或选参；不能把同一轨迹相邻帧随机切开。

首轮建议成功定义：评分时标记有效且水平/垂直归一化误差各不超过 0.15、距离误差不超过 0.25 m；整个轨迹合格比例至少 80%，无碰撞或越界；遮挡期间独立报告失去目标及恢复，不能自动把停住计成功。记录横向/垂直/距离 MAE、有效观察比例、合格比例、每轴动作覆盖、动作变化与介入/失败。指标阈值在本文件定义，后续若改变须形成新协议，不追着测试结果改线。

场景包括每轴单独刺激与联合刺激；目标丢失时默认执行零速度并报告失去目标（该保护不算 SNN 学会搜索）。先做视觉教师/零动作的环境自检，完整 SNN 的控制效果必须后续实际运行才可报告。
