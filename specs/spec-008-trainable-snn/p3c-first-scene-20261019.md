全部 80 帧标签有效，无缺帧；本次使用的动作、标签、索引和时间数组全部有限。动作顺序为 `vx/vz/wz`，FLU 正向分别为前进、上升、左转，单位为 m/s、m/s、rad/s，表示网络期望速度，不是实测飞行速度。

误差口径与已有父进程 `numeric.metrics` 一致：原始 float64 教师标签先转 float32，再提升 float64 做归约；尺度 `[0.3, 0.2, 0.5]` 同样先按 float32 表示。每轴归一化 MSE 为 `mean(((action − target) / scale)²)`，SI RMSE 为 `sqrt(mean((action − target)²))`，不含 gain 正则。每窗派生误差已与保存的父复核 per-axis 指标匹配；原 float64 教师标签另存于 CSV，避免混淆末位舍入。

图的横轴是教师轨迹时间 `0.0–7.9 s`，相邻帧间隔为 0.1 s。每帧 SNN 传播为 50 ms，这个场景累计 4.0 s 神经时间，另有场景初始的 60 ms 预处理。教师轨迹时间、神经时间和计算墙钟是三个不同口径。
