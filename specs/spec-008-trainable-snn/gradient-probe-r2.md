# 梯度诊断 r2：先区分重放末位差异与观察器影响

状态：Ready；r1失败记录不变。这是对具体失败的新诊断，不是把r1事后放宽为通过。

## 新的最小对照

单个受监督worker固定旧159→160档及输入，串行执行：原生产 `policy.forward_tensor` 无hook完整1000步两次；再执行带hook的500/250/100步三支，共5次反传。每支从同一父档重新恢复，不执行任何optimizer。首次两支保留原生产前向调用，不能仅把观察器换为空函数后声称等同生产路径。复用并绑定r1已保存的hook1000分支及其来源，不额外重跑已保存的观察分支。

所有分支的动作、全部特征、末态和读出梯度仍必须逐位一致。无hook两支与旧160及已保存r1比较；短分支前向对同次无hook1000基线比较。

theta保存exact、差异数量、maxabs/maxrel、ULP、相对L2、零支持/非零符号差异。数值重放判断采用项目已有 `tests/test_mps_continuation.py` 的theta跨路径 `rtol=1e-5, atol=1e-7`，同时强制零支持和非零符号一致、全部有限；不将数值通过称为逐位相同。该阈值来自此前检查标准，不由这次4个差值拟合。短范围theta本来就会变化，不对它强制近似原梯度。

判断分层：无hook两次不同，表示普通重放末位变化已观察；两次相同而与r1不同，只能确认观察版本或运行环境相关；两次都匹配r1而与旧160不同，则旧档差异原因仍未定位。任一超过上述数值门槛则停止，不继续以此做根因结论。该实验不证明具体硬件归约实现是唯一原因。
