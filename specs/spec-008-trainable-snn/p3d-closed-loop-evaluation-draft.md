# P3d — 神经闭环评估候选

状态：历史候选，未运行。已收敛为[正式评估子规格](p3d-closed-loop-evaluation.md)，后续实施以该文件状态与契约为准；本文件保留早期接口与成本依据，不改变已Ready的[P3c2训练协议](p3c-training-runner.md)。

## 目标与现有接口

在独立完整场景中让神经策略动作实际改变相机位姿和下一帧，再比较joint、独立训练frozen_brain、acute_restore与直接视觉基线。固定教师录像上的损失不能替代闭环结果。当前完整目标AC3–AC6仍未完成。

- `follow_task.rollout`每次重建环境并跑到结束，没有分段恢复接口。
- `FollowEnvironment`没有公开存档API，但场景身份和已执行动作可以确定性重放环境：初始化背景按seed产生，目标位置是时间和seed的纯函数。可只重放廉价环境，直接恢复完整神经状态，避免重新计算神经前缀。
- P3c1训练存档要求正Adam步、训练身份和两帧游标，不应冒充评估存档。评估需要独立状态格式，无Adam。
- 旧`evaluation_v2`只处理固定监督帧的vx/wz且要求配对监督行相同；各策略闭环会产生不同观察，不能沿用该配对假设。可绑定并复用`follow_task`的三轴轨迹评分语义。

## 候选执行与恢复

每场景从最终参数开始；acute_restore先把theta恢复初值，再调用一次`initial_state()`。不把训练末尾隐藏状态带入评估。

逐帧数据流为：环境渲染 → 像素 → no_grad神经前向 → 原始动作 → 独立监督/限幅 → 环境step → 新观察。策略只取得图像、相机和控制时钟；真值隔离到评分器。目标丢失时仍推进并记录神经输出，监督置零单独报告。

候选每段最多40帧，每10帧形成持久边界，共80帧/场景。这些数值尚待正式协议审查，不能直接启动。边界包含完整PolicyState、环境位置/yaw/实际速度/时间/失败态、已执行动作前缀、下一图像摘要和父存档身份；最终manifest最后封存。恢复时逐帧重放环境并核对像素/真值/检测，再恢复神经状态；下一次前向前核对实际恢复摘要以及环境、神经、感觉和帧时钟。不再预处理或重演神经前缀。

已封存有效前缀和未封存尾部分开；资源失败如实失败，后续显式续段可以使用有效前缀。环境物理失败是正式场景结局，不能补造80帧。整段参数不应变化，前后摘要核对。

## 候选比较

现有场景注册表包含4个train sine、4个val triangle/stripes、4个test chirp/checker及test遮挡/出画场景。正式协议应绑定全部实际定义、顺序、相机、容差和源码；不用相邻帧随机拆分。

| 条件 | 来源 |
| --- | --- |
| joint | joint登记一个epoch完成后的最终参数 |
| frozen_brain | 独立frozen一个epoch的最终读出，theta保持初值 |
| acute_restore | joint最终读出，theta恢复初值后重新初始化场景 |
| direct_visual | 现有手写visual_teacher，不称作同预算训练的视觉网络 |
| zero | 零动作任务下限 |

各条件共享外生场景、初始位姿和监督规则，但产生各自闭环图像、轨迹和有效率。独立frozen不能被acute_restore替代。不按训练loss挑选中间checkpoint。可先完整val再执行冻结test；若据val改变模型，须登记新候选，不把已看过的test继续叫未见。

全部场景仍使用相同红色标记；结果不支持任意目标、真实房间泛化或全面性能领先声明。

## 实施与验收候选

训练runner验收后再确定可复用的稳定公共辅助。预计新增轻量评估入口、worker、评估完整状态存档和Torch-free证据复核；保持已绑定环境/策略/数据源码。父复核独立重放环境、复算检测/监督/三轴评分和封存链。

每场景保留原始帧、全部DN特征、原始与执行动作、检测/监督原因、真值轨迹、资源和耗时。报告水平/垂直/距离误差、合格率、有效观察率、三轴覆盖、碰撞/越界、目标丢失恢复、监督介入、计划/实际帧和失败。神经时间、环境时间、墙钟分别列出。

定向数值检查验证连续与恢复一致、无真值泄漏、动作改变下一观察、缺状态/坏链/假成功拒绝；不重复完整脑前缀仅为增加信心。实际有效负结果可以通过证据验收，不能要求成绩变好才算实验有效。

## 成本与未决边界

P3b r2两帧无梯度前向约19.36–19.62秒，据此线性估计40帧387–392秒、80帧约13分钟，另加加载/存档/首次预处理；三个神经条件的6个test场景约3.9小时，4个val约2.6小时。均非长场景实测。继续600秒/段、1GiB额外预留和6GiB RSS请求，Noria/Docker保持。

受控拓扑实验另立子批：当前生产图/映射/策略只接受full_reference，不能伪装研究资产角色。需独立研究入口、全部节点/注释、受控R重连、不变量验证和同预算训练。W只打乱权重不替代重连；交换数不自动等于充分随机化。重连预算、种子与选择规则在看成绩前冻结。

正式Ready前仍需结合已验收runner接口确认评估存档/API、首次实际恢复门槛、完整场景矩阵与成本；本草案不授权绕过训练或运行尚未冻结的评估。
