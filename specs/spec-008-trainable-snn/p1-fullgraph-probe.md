## 输入、目标与更新协议

- 唯一主图：`data/malecns_v2/full_reference.npz`，通过 P0 生产 loader；保存母图与模型身份。禁止剪图或从小图成功外推。
- 确定性电刺激：取原始类型 `R1-R6` 的全部 body ID 为外部驱动；每 67 个神经步施加一次 68.75 mV 增量，其他细胞严格零。dt=0.1 ms；首次窗口 20 ms（200步）。这是数值可行性刺激，非相机编码或生物响应实验。
- 固定观察集合：原始类型 `L1` 的细胞（不在输入集合中），读取最终膜电位。损失为其对固定 -50 mV 目标的平均平方误差；该目标只用于数值优化，不能解释为期望飞行动作。不存在输出解码器参数。
- Adam 单次更新，lr=0.01，内部 theta 初始化为0；仅更新 type gain。保存实际梯度范数/非零组、theta/gain更新量、原始边保持证据；不得用非零梯度代替实际参数更新。
- 相同初态和输入，分别记录更新前、更新后、恢复theta=0后的观察向量；恢复向量应在登记的float32数值容差内回到初值（atol=1e-5mV, rtol=1e-6）。报告损失是否下降，但单步上升不隐去，也不能改目标制造成功。
- 若20ms没有可用梯度或响应变化，保留失败报告；仅在定位具体原因后登记新一轮，不自动换观察群或加未经记录的偏置。群组数量来自实际资产，空群明确失败。

## 资源与过程

CPU float32、单序列，torch CPU线程固定为4并记录；不启动 MPS。父进程监督子进程，6 GiB RSS、600秒墙钟为首轮上限，覆盖导入/载图/构造/前向/反向/优化/保存。检查现有可用内存，不足以留给系统至少4GiB时降低本轮阈值或明确失败，不自动占满内存。父进程短周期采样并记录最大观测RSS、退出状态和阶段；监控不是绝对硬内存隔离。

增益前向、稀疏伴随性能先以该实际探针记录。避免每步重建稀疏图或保存无必要的全部输出；保留当前核心的数值/梯度语义。发现实际热点后另行最小优化并独立验收，不凭猜测扩展本批。

输出目录必须是新目录。开始先写registration.json，再启动子进程；异常、超时、资源停止要有失败终态，不能将残留checkpoint计为完成。不覆盖任何旧资产。记录实际环境版本、代码摘要、阶段耗时、峰值RSS、仿真与墙钟时间。
