## Spec Coverage

- 相机与运动闭环：`follow_env.py` 使用目标在世界平面上的四角投影、FLU 坐标、一阶速度响应和位姿积分；正左转、上升、前进分别改变水平对准、垂直对准及投影尺寸。目标轨迹独立于策略；固定种子与 reset 的重放检查已有通过记录。
- 像素观察：`senses/target.py` 只接受 BGR 图像与标定，不依赖环境真值；观察不可变。空白/损坏、过小、边缘裁切、多候选及明显缺损有显式失效原因；无效观察不输出假零误差。空间 mask 保留图像行列位置，不声称解剖映射。
- 策略隔离：`FollowPolicyInput` 仅包含独立图像、像素观察、相机与时间。真值教师是单独函数，日志区分原始策略、限幅/丢失保护后的动作、特权教师和评分真值。保护在策略外实施；文档明确 API 不是恶意 Python 代码的安全沙箱。
- 任务与指标：14 个已登记场景按完整轨迹族及背景分为 train/val/test，三个轴与组合、遮挡、出画恢复均有定义。合格容差与 80% 成功门槛固定；提前终止仍用计划样本数为分母，并要求全程无失败。未观测帧不算成功，丢失/恢复单列。
- 输出与证据：新目录写入 JSON/JSONL，保存完整场景、相机、动作单位、协议、阈值及策略身份；已有运行记录符合 schema。`docs/FOLLOW_TASK.md` 说明命令、接口、字段、简化动力学和检测局限，未宣称学习或实飞成功。

- 环境没有经过 Tello 动力学标定；碰撞为距离代理，不能用于证明避障能力。

- 当前接口隔离真值并不自动保证后续训练没有旁路；SNN 接入需再次审查输入来源、网络依赖和数据分区。
- 本轮只在训练场景使用常规视觉/零动作基线，尚无未见场景的神经控制结果。
