# Spec — 可训练 MaleCNS 脉冲网络与目标跟随

状态：Implementation / 分阶段执行。2026-10-17 用户授权全部路线和逐步提交；[P0 可训练核心](p0-core.md)及[P1 完整图实际更新](p1-run-20261019-r3.md)已独立验收通过，AC1、AC2 完成；AC3–AC6 按实测和预登记推进，整体目标尚未完成。

## 背景

用户明确要求网络自身学习控制，首个任务为跟随指定目标，学习前进、升降和转向，算力暂限当前 Mac。当前阶段 A 的冻结脑＋岭回归读出只能作为对照。方向依据见 [Decision 008](../../.ai/decisions/008-trainable-malecns-control.md)。

## 目标

- 完整 MaleCNS 图在控制策略中执行计算，任务优化确实更新其内部有效连接参数。
- 在目标跟随的离线闭环中学习 `vx/vz/wz`，区分网络学习、外围视觉计算和读出各自的贡献。
- 给出可复现的数值、资源与行为证据，再决定是否进入 Tello 实体阶段。

## 非目标

不默认逐边解冻全部连接、不恢复 MiniFly、不把物理环境仿真换成合成脑、不把动作训练称为恢复真实果蝇学习机制。不承诺 Mac 的实时性或全任务训练时间。当前已获实现和本机训练授权；实际硬件仍需满足现场条件，不能由自动化测试启动。

## 当前行为

完整参考图为 166,700 个节点、25,582,938 条内部有向边。旧完整图诊断合计 15 s 仿真耗时 96.83 s；旧 NumPy/SciPy 引擎和固定活动岭回归保留作基线。P0 已新增 CPU PyTorch 可训练 LIF 核心及独立数值检查。2026-10-19 P1 实际完成一次内部共享增益更新：仅 R1–R6 组改变，809 个 L1 电位随之变化，恢复及重载通过；采样峰值 RSS 1.830 GiB、总墙钟 362.64 s。该短窗数值优化没有动作目标。P2a 已完成三轴目标跟随环境、像素前端、独立场景与评分的验收，尚未接入 SNN 策略。

LIF 的外部输入、积分和不应期处理与其引用的 Shiu 官方实现有差异；新后端必须明确采用何种语义，不能把旧引擎一致性等同于论文复现。

## 目标行为

指定目标与相机观察 → 显式感觉编码 → 完整 MaleCNS 可训练 SNN → 小容量运动读出 → `BodyVelocity(vx, vz, wz)` → 环境更新 → 下一次观察。

目标位置／距离等仿真真值可用于训练教师、奖励和评分，不能进入以相机为输入的部署策略。监督及限幅放在策略之外，保留策略原始输出、实际执行动作和介入原因。无人机姿态稳定依靠机载控制器，不计入网络已学会的能力。

## 功能需求

### F1 数据与可训练参数

- 主模型保留完整 body ID 和边集合、原始突触计数、来源及缺失注释。训练后的有效权重另存，不能覆盖原始数据。
- 首选候选为 `w_ij = w_base_ij * gain(group(i,j))`：gain 为有界正值，初始为 1；group 由预先登记的注释类型／通路确定。分组、缺失注释归组、上下界与正则强度须在训练前明确，不能按测试表现临时调整。
- 原始拓扑与已知递质符号固定，未知符号单列为假设。LIF 参数先按经验证语义固定；时间常数、阈值或偏置的解冻另作有界扩展。原 8 mV 偏置不作为已知生物常数，需显式比较其影响。
- 编码器和小容量读出可以学习，但必须记录内部参数实际更新量、有效权重变化和状态变化，不能只更新两端。

### F2 数值与训练实现

- 先建立单细胞、双细胞的独立数值参考，覆盖输入施加位置、突触到达、复位、不应期与延迟；小电路仅用于数值测试，不替代完整脑主模型。
- 代理梯度是可评估训练方法：前向仍使用已声明的脉冲动力学，训练时近似处理发放阈值的导数；不能宣称是果蝇真实学习规则。完整时间反传、截断时间反传、局部／无梯度方法分别记录其近似与成本。
- 对代理梯度实现，比较登记的平滑反向规则和独立参考；硬阈值真实导数不能用普通有限差分直接当作代理梯度的正确性标准。
- 先量化完整图前向与一次内部参数更新的耗时、峰值内存、时间窗、精度和后端。16 GiB 内存是容量事实，不是可全部占用的训练预算；运行前设明确资源和中止门槛。资源不足如实报告，不降图冒充完成。

### F3 感觉编码与目标指定

- 目标外观、指定方式、距离参照与相机标定必须固定并记录。第一候选为已知外观、已知尺寸的标记目标；尚未视为用户已确认任意目标识别能力。
- 使用保留空间信息的输入。不能把现有左右半幅聚合特征当作完整视网膜；没有解剖证据时，不把节点顺序编造为空间位置。
- 感觉映射可作为受约束工程编码或学习模块，但需说明哪些对应有解剖依据，哪些是训练所得。主动作读出不允许跳过 SNN 直接读取图像／目标误差；直接视觉策略作为独立对照。
- 若采用外部目标检测器，明确识别由外部模块完成，不能据此宣称 SNN 自行识别目标。

### F4 学习任务与数据

- 跟随过程中同时评估水平／垂直对准、跟随距离、目标保持与控制平滑；目标需包含三维运动，分别覆盖前进、升降、转向，不能以零轴占位计作已学习。
- 训练可先采用显式仿真教师示范，再用策略闭环收集的状态修正分布偏移；奖励优化为成本验证后的候选。教师方法和误差必须公开，不将拟合教师说成独立发现生物行为。
- 目标运动不由待测策略控制，动作须改变相机位姿与下一时刻观察。固定地面视频的离线拟合不能代替此闭环。
- 按房间、目标外观与轨迹族划分训练／验证／测试，包含遮挡、出画及恢复条件。真值仅供教师／奖励／评分。跟随距离、丢失后的任务定义、各轴范围与容差在测试前冻结。

### F5 贡献验证

- 比较冻结脑＋同容量读出、训练内部参数＋读出、直接视觉策略、受控重连图，并报告各自参数量、训练预算和失败。编码若训练，主比较保持同样编码架构与优化机会。
- 内部参数恢复到初始化的急性干预检验策略是否依赖学到的内部变化；独立重新训练冻结脑对照检验是否有训练收益，二者不能混称。
- 真实图与受控重连图接受相同数据、学习参数化与选择机会。研究图仍仅用于离线对照，不进入设备产品路径。
- 评价未见场景的跟踪误差、目标保持率、碰撞／越界、各轴覆盖、监督介入与端到端耗时。允许负结果，不只报告训练 loss 或梯度非零。

## 边界条件

现有 Mac 已测得 P1 单序列 20 ms 窗口的完整图更新成本；长轨迹和目标跟随训练成本仍未知，不能从短窗结果外推。目标跟随成功不代表避障、任意目标识别、真实生理复现或跨设备泛化。遮挡、失去目标、无效输入和监督接管必须单独评分；停住不能自动算跟随成功。

## 技术约束

沿用 `src/cnsbridge` 及既有模块职责，保留完整图资产，不引入缺失回退。独立 `.venv-train` 已安装 PyTorch 2.14.1，当前核心仅支持 CPU 稀疏计算；未采用 MPS。缓存伴随矩阵后[P1同协议对照](p1-run-20261019-r4.md)反向耗时从291.70s降至13.79s，总耗时83.69s；有效增益及响应精确相同，梯度末位差在比较容差内。该单次比较不构成实时控制或稳定提速保证。

## 兼容性要求

新模型具有独立来源、参数、输入／输出和时间身份。旧 V2 特征缓存只供冻结脑对照，不用于伪装网络更新后的活动；不覆盖旧模型、数据和运行记录。保持 FLU、SI 单位和轴能力掩码，设备 RC 换算仍在适配器中。

- [ ] AC4：`vx/vz/wz` 均有独立任务覆盖；场景划分、任务容差和失败处理在确认测试前冻结。

## 待确认问题

- 用户已确认：指定目标跟随、前进／升降／转向、当前仅本机 Mac。
- 已登记的首轮任务：20 cm 红色方形、1.5 m 跟随距离，三轴范围与评分见 [P2a](p2-environment.md)。该环境与常规视觉基线已实现；尚非神经策略能力。AC3/AC4 的完整验收还需 SNN 接入与实际三轴任务覆盖。
- 工程研究：输入细胞与空间映射的依据，输出细胞集合、类型／通路分组、优化器、时间窗、资源门槛与框架；由只读分析和限定成本实验形成方案，必要选择再与用户讨论。
- 研究登记：教师／奖励定义、独立场景数量、任务容差、训练停止预算。不得先看测试结果再定。
