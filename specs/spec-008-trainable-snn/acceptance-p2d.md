## Regression Risks / Limits

- 尚无完整生产图的该工具运行记录；生产规模的耗时、内存和神经响应仍未知，数值夹具不能代替它们。用户尚未通知内存释放完成，实际窗口/预算仍需按 P1 成本证据冻结后登记。
- 来源与产物校验确保保存证据的一致性，并依赖受身份约束的生产加载/采集代码；不声称能够识别任意恶意重新伪造的完整证据包。
- 资源保护是采样监督，非操作系统硬隔离；当前源码变化后校验旧记录需回到对应登记版本。
- 主 Spec 的完整图内部更新、三轴策略学习、对照研究和新模型实飞仍未完成；本 PASS 不可用于勾选这些验收项。
