# P3e1 — 可续段的完整 R 生成方案

状态：Draft，未独立审查、未实施或执行。仅将首次[完整图成本实测](p3e-generation-run-20261019-r1.md)转成可审查的下一步方案；不得用本稿启动正式R生成。正式神经G/R模型及比较仍由后续子规格处理，不能把本批图生成计为AC6完成。

## 目标与固定候选

当前R生成器不能保存随机状态或续接；100000提案完整成本样本耗时约16秒，未测纯提案速度，不能据此保证更长预算。为保留600秒单段保护，候选沿用原交换分布、增加显式续段，而不更换图算法或删边。

- 正式候选seed1901，从完整母图重新开始；不把generation_probe_only图变为训练图。
- 非自环边E=25,582,837；总成功交换上限E、总提案上限4E=102,331,348，先到任一上限结束。固定原始101自环；全部166700节点/25582938边保留。
- 每次显式调用最多1000000个新提案，不跨过总上限；没有自动跑完整预算或失败重试。每段完整封存一次真实CSC/RNG/累计计数，最后一段可短。
- 每段复用同OS锁，1GiB预留/申请6GiB/600秒/0.1秒。每段实际耗时未知，不把粗略成本外推当承诺。若中止，保留失败和未封存尾部；只允许从最后已验收封存状态显式续段，不从未封存数组猜测进度。

这是单种子探索性扰动，不是均匀随机图总体抽样；交换次数/边重叠均不证明充分混合。达到提案上限而成功不足，报告实际扰动，不追加预算或更换seed；零成功不能形成有效拓扑反事实。上述科学预算只依据工程成本选定，运行前还需正式冻结；不能看神经静默/任务成绩后选择R。

## 最小实施边界

只涉及 `learning/graph_controls.py`、`graph_diagnostics.py` 及必要的新生成步进/存档/入口模块；实施前再次核对当前run的29个绑定训练源码清单，全部保持。首次探针保留旧实现摘要/脚本及原始结果，不覆写成新版。

1. 将现有逐提案循环提取为能够接受已有CSC、PCG64对象和累计计数的步进运算；原 `_rewire` 使用同一运算保持输入输出和随机序列语义。两次边位置抽样、拒绝次序、源权重留存、排序列移动全部保持。提取公共数组操作时避免循环导入或复制两套提案逻辑。
2. 登记绑定完整母本身份、总预算/seed、源码/runtime/算法版本。每段保存上个checkpoint ID、开始计数、配额、资源；worker在任何新提案之前保存实际恢复CSC摘要、PCG64状态和计数，与父封存状态比对。
3. 生成状态采用独立schema/purpose，不伪造full_reference或可训练research_control。保存真实规范CSC三数组、母本/元数据身份、累计attempts/success/rejections、PCG64完整状态、父ID和前缀摘要；以manifest最后封存。节点元数据可从已验证只读母本重建，但不能遗漏nullable注释、群组或原始body顺序。
4. 恢复校验真实数组shape/dtype/整数/非零/有序/无重复、全节点/边数、自环、逐源符号、图摘要、随机状态与非布尔计数，且attempts=success+拒绝总和、预算不超限；不只信manifest摘要。途中状态不允许进入脑loader。
5. 最终到达登记总边界时，运行完整机械诊断再以真实research_control身份封存主候选图；身份包含全部新调用源码。加强独立逐源权重多重集检查：每个源列各自排序比较，包含自环、空列及缺注释源，内存只需当前列临时数组。
6. 生成时节点/符号入出度/逐源权重多重集保持，逐目标入强度不保证；最终必须报告边重叠、类型对变化、全部节点正/负/绝对入强度变化，以及按实际3377输入/1314DN的双向多源最短跳数与不可达项。路径检查不可误标全对最短路或功能传播。

父只轻量登记/监督和文件来源核对；完整图验证也必须在受监督worker中，不在无预算父进程加载。最终图生成完成、机械证据通过、混合充分与神经行为是四个不同结论。失败终段不能因为有NPZ就升级完成；保留父/worker原始终态及来源清单。

## 验证与进入实际实验的条件

实现为持久化/共享图工具的S3范围，仅验证相关子系统。低成本夹具至少覆盖：旧单次生成与连续/新OS进程分段的CSC和RNG完全一致；成功/提案双停止边界；零交换/自环/重复边拒绝；逐源多重集反例；有向路径及不可达；错误母本/来源/随机状态/计数/数组/父链；保存中断、资源失败保留、终局拒绝继续；旧生产loader继续拒绝研究图。不得无理由重跑完整训练或全项目套件。

新的独立软件验收并提交后，首实际两段各100000提案，作为正式R唯一前缀保留；第二worker前向提案前验证真实恢复CSC/RNG/计数。新的独立实际验收后才扩到每段最多1000000提案，不重复首前缀或重置seed。实际续段成本、资源和任何阴性结果全部保留。
