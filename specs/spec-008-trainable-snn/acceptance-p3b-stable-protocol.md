## Spec Coverage

- **目标与范围：通过。** 候选继续使用完整 MaleCNS、内部 theta 与读出共同更新，符合 Spec 008 和 Decision 009。它明确将分组裁剪列为新的优化规则，而非与 r1 统一裁剪等价的实现修复；没有删除节点/边、缩短 100 ms 信用窗、帧间 detach、改变代理梯度或引入视觉到动作旁路。
- **数值依据：通过。** r1 报告区分有限梯度元素与 float32 范数归约溢出；对这些 float32 参数梯度使用 float64 平方/求和足以避免本次范数溢出。单纯修复全局范数仍会使读出与内部巨大梯度共享极小系数，分组候选正面处理这一尺度耦合。文档中的 Adam 步幅预测明确来自已有数组的假设算术，没有冒充实际参数更新，也未预判本次损失或动作效应。
- **裁剪与更新：通过。** 两组固定为 theta 和 weight+bias，各自 L2 上限 1；系数公式、原始梯度逐元素非有限拒绝、float64 统计、实际 float32 乘法系数以及完整裁剪前后梯度均有要求。合并上限变为 sqrt(2)，不继续称为全局范数 1。Adam 超参数、一次 step、同帧教师目标、正则与其初始零梯度约束保持。
- **优化器证据：通过。** 要求按稳定参数名保存三个参数对象的 step、exp_avg、exp_avg_sq，并由轻量父进程从零初始矩与实际裁剪后梯度独立复算；这比只记录 optimizer_steps 或理想化步幅更能检验更新。文中“三组 Adam”应按三个参数对象理解，优化器参数组仍只有两个，不能据此创建第三个超参数组。状态仅是此次证据，不被称为可恢复训练存档。
- **因果比较与版本：通过。** 原五分支、全部动作/全部 DN、恢复及重载容差、三层结论均保留；同固定输入的 r2 baseline、初始参数和原始梯度与已保存 r1 比较，不重跑 r1。仅优化阶段改变的主张可由该比较约束。协议/结果 schema 升版，当前核心、策略、数据和部署 checkpoint 源码保持；旧记录及其源码摘要不被重写或作为缺字段的新格式接受。
- **预算与停止：通过。** 维持轻量父进程、受监督完整图 worker、1 GiB 额外预留、6 GiB 申请上限、600 秒及 0.1 秒采样；Noria/Docker 不动，不并行全图。原约 303 秒仅是完整试验规划估计，r1 的未完成用时不能替代。新实现独立验收和提交后才在新目录执行一次；失败或阴性保留，不自动搜索超参数。
- **科学结论：通过。** 分组裁剪不能解释巨大内部梯度来源，也不能证明生理合理性、稳定长期训练或未见场景控制。两个标签全正、离线教师轨迹、初始预处理无梯度等限制保留。protocol_complete、joint_numeric_update、internal_action_effect 分开，loss 增加或无内部动作作用不隐藏；AC3–AC6 仍未完成。

## Issues

无阻断问题。以下是该契约在软件验收中应落实的具体解释，不是新的研究选择：

1. float64 系数与真正乘入 float32 梯度的系数分开保存，实际 dtype/转换顺序在版本化协议或实现中固定；父进程使用保存的原始梯度独立复算，不接受 worker 自报系数。浮点舍入导致的组范数末位误差需使用预先固定的数值容差，不能运行后放宽。
2. 三个命名参数的矩状态须具有严格字段、shape、dtype、有限性和 step=1 检查。独立复算应考虑实际 float32 Adam 的矩更新与舍入/下溢，不能仅用 float64 的理想首步公式替代矩证据；篡改矩或步数必须拒绝。
3. 协调者在审查期间明确的第 6 条澄清合理：新登记绑定 r1 原 registration/protocol ID 和被比较文件摘要，保留原字段顺序、全部元素以及 exact/allclose/maxdiff；baseline 动作/特征、初始参数与原始梯度必须在既定容差内一致。任何超容差使本次协议无效，保留诊断而不能“解释后放行”。该澄清应纳入 Ready 文本与实现，是“只改变优化环节”归因的门槛，不改变候选算法。新源身份允许优化与证据模块改变，不允许核心/策略/数据随之改变。

## Regression Risks

分组裁剪是新的优化偏置：它保留各组内部方向，但重新分配内部与读出的更新机会，不代表两者贡献相当。theta 原始梯度巨大可能使该组的绝大部分裁剪后分量或 Adam 二阶矩发生下溢，实际内部有效增益变化和动作作用仍须独立量化。即使 r2 五分支通过，也不能据此承诺长轨迹梯度稳定；完整运行后半程资源峰值仍未知。
