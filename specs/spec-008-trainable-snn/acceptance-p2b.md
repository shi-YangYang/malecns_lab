## Spec Coverage

- 完整集合与身份：生产入口要求 `TrainingGraph` 的 `full_reference` 角色并核验训练图身份摘要、来源与图摘要绑定；NPZ 元数据核验相同来源、完整注释摘要及 body ID 顺序。精确选择全部 `type == R1-R6` 与 `superclass == descending_neuron`，输出不依赖 DN 名称前缀或类型是否缺失，保留两种侧别及缺失掩码。空集合明确拒绝；既有参考图群组未改动。
- 读取边界：`_read_bound_metadata` 仅访问 meta、body IDs、字段名及注释／缺失数组，不访问 data、indices 或 indptr。该接口依赖调用者已经通过生产图 loader 的完整校验，文档没有把元数据绑定写成重新校验全部权重。数值夹具具有独立角色，生产入口在读文件前拒绝测试图。
- 空间映射：缺失 rootSide 单列、非缺失原始字符串按 Unicode 排序，每组按 body ID 排序后共享 PCG64(1701) 流置换，按 j % 192 均衡分配；身份保存每格计数与未覆盖格，明确属于工程编码。成员、格号、事件和导出状态均为不可写 bytes-backed 数组，身份属性返回独立对象。
- 连续刺激：默认 0.1 ms、150 Hz、68.75 mV 与登记一致；拒绝单步可能超过一个事件的配置。相位使用 PCG64(1702)，跨帧连续，空白只推进时钟而不产生事件；reset 与身份绑定的 restore 有明确语义。mask 和恢复状态全部验证完成后才修改状态，失败不会部分推进。
- 无旁路：接口没有动作读出、仿真真值或硬件导入；完整向量仅按需创建，非输入细胞增量为零，没有背景电流或输出偏置。输出集合暂时只定义成员。
- 文档与实施报告明确区分数值接口、完整脑响应、任务训练及设备证据；未把登记时的完整资产统计当成本批新运行结果。
