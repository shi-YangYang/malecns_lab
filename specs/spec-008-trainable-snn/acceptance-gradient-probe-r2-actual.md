## 实测与原因边界

下表为保存的GPU稳定范数，独立用保存float32数组转float64重算后符合`rtol=2e-6`（差别来自统计归约精度，不改写原数值）：

| 递归信用范围 | theta原始梯度L2 | 读出权重梯度L2 |
|---|---:|---:|
| 1000步，生产重放1 | 9.760240474e29 | 28.675574394 |
| 1000步，生产重放2 | 9.760240474e29 | 28.675574394 |
| 500步 | 3.661612147e11 | 28.675574394 |
| 250步 | 410.734344945 | 28.675574394 |
| 100步 | 0.006620554 | 28.675574394 |

全部五支三个参数组的finite/maxabs/nonzero与保存数组一致，L2独立重算通过。仅改变递归状态的反向路径，保持前向、读出梯度和末态不变，即造成上述数量级变化，因此支持“此固定窗口的大theta梯度主要受长递归代理梯度路径放大影响”。它不证明原稀疏伴随算子错误、真实生物机制、100步在全部场景最优，或较短信用必然提高任务表现。

原窗口vx读出梯度精确为零，动作vx为正而归一化目标为负。固定原特征/读出的候选logit损失在MPS给出六个有限非零logit梯度，vx两帧梯度约`+0.17292580 / +0.17337350`，下降方向会降低错误正logit。独立计算`(tanh(z)-y)/6`与保存梯度一致，原动作逐位保持；本地logit变量以0.1步下降后损失`3.792141914 → 3.786087275`，独立float64复核相符。这是饱和时纠错梯度的候选数学证据，**没有更新模型参数**，未证明新损失训练后的控制功能。
