## 目标 / 当前行为

P0 的完全静息状态和抑制性输入造成第一批非输入脉冲无法启动。新增可选研究变体，用于后续比较背景工作状态是否改善可观测性。完整图保留，不能把数值小电路当作替代脑。

## 目标行为与功能需求

1. `TrainableLIF` 默认无背景，不注册 rho，不增加默认非零项；原方程、事件顺序、输入集合、不应期与 P1 theta-only 优化保持。共享核心只增加一个返回 None 的可扩展背景接口，默认分支不增加额外数值运算。
2. 新 `brain/tonic.py` 提供显式变体，例如 `LaminaTonicLIF`，复用核心积分而不复制 step。生产图中全部精确原始类型 L1–L5 依次入组，5个 rho 初始化0；每组必须存在。数值测试工厂可显式指定这些类型的非空有序子集；生产不能由调用方缩减或添加类型。类型缺失或空值不能推断为 L1–L5。
3. `offset=16*sigmoid(rho)` mV，有限值下保持严格(0,16)，浮点饱和可按 nextafter 保护。非成员严格0。偏移只改变膜电位平衡点：`integrated_v += (1-a)*offset`，`a=exp(-dt/tau_m)`；g 不增加背景项，不应期内 v/g 保留原语义。背景细胞与外部 input_body_ids 必须不相交，不改变 input_mask。
4. 支持显式 `learnable` 与 `fixed` 背景模式：两者初值8mV、前向一致；前者 rho 是参数，后者 rho 是固定 buffer，不允许通过 optimizer 更新。严格零背景使用原 `TrainableLIF`，不以极负 rho 近似。实际模式与范围进入身份。
5. step 前验证背景参数形状、CPU/dtype及有限值；拒绝非有限 rho，不允许 silently broadcast。模型身份记录独立 schema、模式、类型顺序、成员 body ID 摘要与数量、公式、范围、初值、源码哈希；状态身份不能混用。`reset` 不改学到的参数。全部 raw counts、节点与边不变。
6. 现有 `learning/checkpoint.py` 仍只支持原始 gain-only schema。save/restore/load 明确核对支持的动力学 schema 和精确参数集合，拒绝 tonic（包括 fixed 模式）或任何额外参数，且拒绝发生在目录创建或参数修改之前。read 验证 metadata 参数键严格等于 theta，不能接受遗漏/额外参数声明。变体完整 checkpoint 本批不实现，不允许用户误以为已持久化 rho。已支持原核心的往返继续有效。

## 非目标与科学边界

不添加 DNg02 动作偏置，不调视觉/动作规则，不改变 tau/阈值/符号，不创建新仿真脑，不运行实机。不声称8mV来自生理测量，不声称背景发放本身证明视觉传播。全部神经元的统一 LIF 仍是建模近似。未来诊断须有同一预热协议下空白与位置/尺度响应对照；不同背景下结果不可直接归因于内部增益学习。
