## Spec Coverage

- **完整训练准入与独立对照**：两个模式须分别通过 `validate_run`、唯一封存链及最终训练存档检查，达到冻结的第160窗/末场景80帧；不信进度文件、不挑中间最优档。源码中的场景顺序确为 combined/forward/vertical/yaw，最终游标与协议一致。独立 frozen 读出训练和 joint 参数急性恢复具有不同目的，协议未混用；拓扑贡献留给单独子批。
- **参数数值身份**：`NeuralPolicy.identity` 记录结构、初始化规则和源码，不包含当前学习参数。新增 `parameter_set_id` 绑定 theta、读出权重和偏置摘要，及各层原始训练/参数存档身份，能防止同结构不同参数互换。acute 从原始封存数组恢复 theta，且发生在 `initial_state()` 前；不假定初值必定为零。
- **独立有状态评估格式**：既有 `PolicyState` 和 `_drive_for` 接受非负整数帧并按预处理与每帧步数核对时钟；不是只能偶数帧。独立无 Adam 格式支持 frame 0、奇数帧和终局，保存全部 pending、相位、事件计数及细胞状态。`checkpoint_state_digest`/`validate_state_digest` 可复用，但协议同时要求真实数组和严格游标验证，未把训练档的正 Adam 步/两帧限制带入评估。
- **闭环与信息隔离**：`forward_tensor` 只需图像和自身状态；环境动作更新确实影响位置、偏航和下一图像。检测及真值可留在父评分/监督层。失去目标时先推进神经再外部置零，原始动作与介入单列，符合主 Spec 的非泄漏要求。
- **环境恢复与父验证**：`FollowEnvironment` 的背景由固定 seed 生成，目标位置由时间/场景确定，`step` 无额外随机状态；从初始环境重放执行动作能重建私有速度、位姿、时钟和失败态。协议要求逐帧重验图像/检测/真值和边界摘要，避免用私有字段赋值冒充恢复，也不重演神经前缀。父读出重算仅证明保存 DN 到动作的变换，未夸大为独立证明全脑计算。
- **场景、评分与失败**：四个 val 和六个 test 名称、顺序、相机/时间参数与注册表一致。五条件全部 val 终局和验证汇总先于 test；最终参数固定，不靠 test 选档。评分与现有 `_errors`/`_metrics` 的三轴、80帧分母、0.15/0.25/0.8 阈值一致；空记录、物理终止、资源/数值失败和缺失分开，允许有效负结果。
- **封存链与资源边界**：event→prefix→checkpoint→chunk 的顺序无循环哈希，块编号与段编号分离；未封存尾部不算进度，坏封存链拒绝回退，资源有效前缀须独立核验。与训练共享现有 OS 锁；1 GiB 额外预留、申请6 GiB/有效动态上限、600秒/0.1秒监督及 Noria/Docker 保留符合 Decision 011/012。29个已绑定训练源码保持不变，可通过新增模块实施。
- **首次实际门槛**：同一正式 val 场景的1帧＋新进程1帧检查奇数边界，随后沿正式前缀继续；不为增加信心重复完整脑连续对照。软件数值 fixture、完整图实际状态证据和行为成功明确分开。
