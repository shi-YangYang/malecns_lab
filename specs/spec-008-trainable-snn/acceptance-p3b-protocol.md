# Acceptance — P3b 一次联合更新协议

## Result

**PASS**（协议设计范围）。2026-10-19，由未参与本协议编写的新验收 Agent 独立审查。该结论允许在前置条件满足后实施工具，不代表 P3a 已完成、P3b 软件已验收或完整图动作训练已经运行。实际登记仍须等待 P3a 软件验收、实际教师数据封存验证，以及 P3b 工具独立验收和提交。

## Spec Coverage

- **图、输入与时间：通过。** 完整参考图、3,377 个输入、全部 1,314 个 DN、固定背景及 CPU 精度保持已有契约。持续刺激实测中固定背景于 21–25 ms 出现 DN 差异，20–50 ms 已有方向/大小差异，足以作为选择 50 ms 观察窗的工程依据；协议没有将其称为最优窗口或生理时钟。两帧连续形成 100 ms 梯度窗，帧间不重置或 detach，60 ms 空白预处理明确在 no_grad 下。控制时间 0.1 s 与神经时间、实际墙钟分开。
- **数据与监督：通过。** 数据依赖 P3a 的完整四训练场景封存；仅使用事先固定的 train-sine-combined 第 0、1 帧。相机、时钟与 valid 为前置条件，失败不改选。标签是同帧真值教师经限幅的三轴 SI 目标，不取下一帧或行为策略执行值；输入/标签副本、数据身份与摘要均进入证据。该设计没有使用验证/测试结果选帧，也没有把两帧教师轨迹冒充神经策略闭环。
- **优化与梯度归因：通过。** theta 与读出参数组、学习率、Adam 选项、一次更新、三轴归一化 MSE、正则和统一梯度裁剪均明确。初始 theta=0/gain=1 时，正则及其 theta 梯度须为零，避免把正则梯度误报为任务梯度；clip 前后全部梯度、范数与系数要求保留，非有限值停止。内部任务梯度和参数变化按独立条件记录，不以 loss 必须下降作为完成协议的条件。
- **干预与存档：通过。** baseline、updated、acute_restore、full_restore、checkpoint_reload 五分支的参数组合明确，均从各自相同输入下的 fresh initial_state 开始；急性恢复保留训练后的读出，仅将 theta 归零，并明确该干预包含预处理状态的变化。恢复、重载、内部作用使用预登记容差和全部动作/全部 DN 特征，不挑轴或神经元。P3a 存档仍仅为完整策略参数，不伪装成含优化器和隐藏状态的续训档。
- **资源与进程：通过。** 轻量父进程登记并监督，所有完整图、Torch 模型、反向和生产重载位于 worker；重载前释放旧完整图、优化器与带图引用，避免双图常驻。成本项对应五次 160 ms 前向和一次 100 ms 反向，代入 r5 的 3.897782291 s/20 ms 前向与 13.44389775 s/20 ms 反向，得到约 302.757 s，按约 303 s 表达正确。该数值明确只是线性量级估计，100 ms 反向内存未被无梯度 RSS 替代。1 GiB 额外预留、6 GiB 请求上限、600 s 墙钟和 0.1 s 采样均保持；Noria/Docker 不动，失败不缩窗、裁图或重复到阳性。
- **证据与结论：通过。** 保存输入、参数、梯度、五分支动作/特征/损失、状态摘要、时钟、完整身份、checkpoint 和监督原始记录；父校验不得只信 worker 状态或再运行模型。protocol_complete、joint_numeric_update、internal_action_effect 分开，协议完整但效应阴性仍保留。一次动作损失更新不关闭整体 AC3–AC6，也不替代后续冻结脑、未见场景、拓扑和部署验证。

100 ms 反向的实际内存、时长和梯度稳定性尚未知；采样监督不是硬内存隔离。持续刺激可区分性不保证三轴目标可学；两帧示范即使更新有效，也不足以评估长时信用分配、泛化或闭环稳定性。急性恢复测得的是本次参数变化在整个分支中的作用，不能定位为唯一刺激期间通路或解释为真实果蝇学习机制。
