# P2d — 完整图配对可观测性工具

状态：Done（软件子批）。47项不同定向检查有通过记录，独立[验收PASS](acceptance-p2d.md)，详见[实施报告](implementation-p2d.md)。[候选实验协议](observability-plan.md)仍为Draft，实际运行在P1资源测量后另行登记。用户尚未通知内存已释放，本批未加载完整图或运行资源探针。

## 背景 / 目标

P0/P2b/P2c已提供完整图动力学、全部输入/输出集合与可选背景。下一项研究需要公平比较同一预处理状态下的空白与空间刺激响应，不能把背景自发活动、裸子进程成功或非零梯度当作视觉通路证据。先实现可运行、可审查的诊断工具，实际完整图结果单独验收。

## 目标行为 / 范围

入口 `python -m cnsbridge.diagnostics.observability --graph ... --protocol ... --out ...`，另提供 `--write-template PATH` 生成新协议文件、`--validate-run DIR` 只读验证保存的结果。不得覆盖已有协议/输出目录。模板为候选，工具不自动执行模板。

沿既有diagnostics职责拆分CLI/父监督、子进程采集与轻量证据校验，避免单文件兼管全部逻辑。复用既有resource_guard，不修改P1逻辑。不增加依赖、设备读出、训练或图裁剪。所有生产计算只走load_training_graph与load_policy_neuron_map；数值夹具只能通过显式test-only内存接口，不能通过CLI替换主图。

## 协议与登记

- 独立schema与角色 `engineering_input_observability`，固定CPU float32/4线程、dt=0.1ms、1ms统计桶、theta=0；比较 `zero_background` 和 `fixed_lamina_8mv`，不启用梯度、不优化rho或theta。
- 固定全部R1–R6输入、全部descending_neuron观察、P2b种子1701/1702、150Hz/68.75mV；按原始类型分别观察L1–L5，生产必须齐全。
- 固定七条件与顺序：blank、center、left、right、up、down、large；掩码精确来自observability-plan，不能传动作含义或选择性少跑条件。
- 模板时间为预处理100ms、刺激50ms、撤除50ms。协议可在运行前显式调整这三个正有限时长，均须是1ms的整数倍；逐项上限1000ms，且总神经步账本在登记中写出。没有“根据响应自动延长”或运行中改协议。预处理不得称已达稳态。
- 浮点差异阈值在协议中固定：电位/g均使用atol=1e-5mV、rtol=1e-6；发放计数整数精确差异。同时保留未阈值化的原始差异。这些只是数值比较阈值，不是生物学显著性。
- 默认总墙钟600s、RSS最大6GiB、系统预留4GiB、采样0.1s。可在协议中收紧预算，不允许放宽已接受上限/预留。开始前按available-reserve收紧有效RSS；载图/导入/构造/采集/保存均在父监督范围内。
- 父进程在导入Torch和加载图之前创建新目录写registration：UTC、绝对图路径、规范化协议/hash、资源预算、环境与相关实现hash、registration_id。校验器/父CLI不导入Torch或载图。

## 配对采集数值契约

1. 完整图只载入一次；两动力学顺序构造/释放，不同时占用两套完整权重实例。模型/图/策略神经元图/空间图/事件驱动身份都保存。全图原始计数摘要在结束时复核，内部theta保持0、fixed rho保持0。
2. 每种模型使用新SpatialDrive，空白预处理后保存完整LIFState与SpatialDriveState。七分支都从同一预处理状态和相位开始；记录起始状态摘要、初始相位/事件计数与时钟。分支之间不得继承上次运行状态；同一分支刺激撤除时保持时钟和相位连续。
3. 记录全部DN每1ms桶的脉冲计数(int64)、平均v/g(float64累加后平均)，包含全部body ID与绝对模拟时间。v/g明确采样每步返回的复位后状态，不能混称阈值前膜电位。
4. 同样保留L1–L5每类型每桶发放总量和跨神经元/步的平均v/g；R1每桶实际输入事件总量和发放总量。输入另外保存每个R1细胞每阶段事件数，复算均衡与相位配对。
5. 全节点按预处理/刺激/撤除分别记录累计发放计数；预处理只算一次，其记录与分支基态分开。保存每个分支两阶段各自的全节点计数，以便与DN、L组、R1桶汇总交叉验证。保存模型全部body IDs、R1/DN/L组对应indices，以保障顺序。
6. 原始数据分支完成即写非pickle NPZ及hash；每个统计桶更新phase.json的模型/条件/阶段/实际累计神经步/墙钟，超时可定位，不需要中断时补造未完成分支。记录阶段耗时、总模拟步及真实墙钟。

## 汇总与结果契约

- 相对同动力学blank，逐DN/桶报告脉冲整数差、v/g原始差；写出每个条件的增加/减少细胞数、最大绝对差、超过登记容差的细胞数、输入事件量。左右、上下与small/large配对差也保留；不能仅报告最大的或有利的条件。完整原数组可复算全部指标。
- “protocol_complete”表示两个模型、全部条件、全部步与身份/产物一致；“response_observation”分别报告电位/发放是否有差异，不以有无响应决定软件运行成功。零响应允许完整结果；不声称学会动作或优势。
- 父监督正常退出只先得到completed。只有独立轻量校验器核对registration/当前代码hash、模型/图/映射/source绑定、严格数组keys/dtype/shape/finite/time/ID、所有预定条件/步、状态/相位配对、阶段计数与桶汇总一致、原图摘要、参数不变、实际资源终态，并从数组重算汇总后，才能输出 `protocol_complete`。不信任worker自报布尔值或summary。
- 源码身份核验覆盖新增采集/协议/校验器及实际调用的brain trainable/graph/tonic/policy_groups/reference/connectome/metadata、senses spatial_drive、resource_guard；加载器和注释校验也决定完整图身份，不能漏掉。身份与来源的验证只约束保存证据的一致性，不承诺可识别任意恶意伪造。
- 预检不足、超时、RSS、异常、缺少/损坏分支均保留失败/不完整终态，不能生成完整阳性或阴性结论。轻量验证入口返回明确错误与非零退出；不触发重算或自动重试。
- 输出可读Markdown报告，明确工程映射、统一LIF、固定背景假设、输入识别绕过、有限窗口以及未验证控制/生理/拓扑优势等边界；报告不依赖尚未实现的前端。
