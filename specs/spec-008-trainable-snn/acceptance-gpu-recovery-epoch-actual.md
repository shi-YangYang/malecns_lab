## 训练期间输出：改善与仍存在的问题

这里比较旧轮和新轮在同一登记训练输入顺序下保存的 **320 帧训练期间输出**。每轮各帧使用当时不断更新的参数，神经状态轨迹也不同；新轮继承旧末档并改变损失、感觉数值、信用范围和优化器状态。因此下表只是描述性汇总，**不是固定最终模型重放、未见数据评估、受控单因素对照或闭环成绩**。

归一化动作 MSE 用 `mean(((action−teacher)/[0.3,0.2,0.5])²)`，轴顺序为 vx/vz/wz。

| 指标 | 旧轮 | 新轮 |
|---|---:|---:|
| vx 归一化 MSE | 0.844891 | 0.235662 |
| vz 归一化 MSE | 0.056784 | 0.050436 |
| wz 归一化 MSE | 0.056706 | 0.047903 |
| 三轴平均归一化 MSE | 0.319461 | 0.111334 |
| 121 帧负 vx 教师中，预测也为负 | 0 | 81 |
| 121 帧负 vx 教师中，预测仍为正 | 121 | 40 |
| vx 精确正饱和帧数 | 230 | 18 |
| vx 权重与偏置原始梯度同时精确为零的窗口 | 115 | 3 |

新轮零 vx 梯度发生于窗口 **3、4、5**，其中两帧 vx 输出与 float32 `+0.3` 教师均完全相等，vx 动作 MSE 为零；不能将它们与旧轮错误饱和无法纠错混为一谈。本轮之后没有再次出现 vx 两项梯度同时精确为零的窗口，但也不能据此声称任意状态不再饱和。

仍有明确阴性结果：

- 新轮 121 帧应后退的教师中，仍有 **40 帧输出前进**；yaw 场景的 35 帧负目标只在 16 帧给出负 vx。
- 新轮 vertical 场景的 vx 教师全为正，但 **28/80 帧输出负 vx**。四场景内 vx 输出符号变化次数分别为 **3、3、5、7**，教师分别为 **1、1、0、1**，存在振荡和方向滞后；这不是设备运动测量。
- 存在幅度超调：combined 末两帧教师 vx 约为 `[-0.0486,-0.0418]`，输出约为 `[-0.1759,-0.1800]`；yaw 末两帧教师约为 `[-0.0113,-0.0121]`，输出约为 `[-0.0532,-0.0779]`。
- aggregate 均值下降没有覆盖所有子场景：combined 场景 vz MSE **0.028666→0.095356**、wz MSE **0.045410→0.129671**，两轴均变差。不能只报告整体均值改善并隐藏这些结果。

本轮支持“原始内部梯度得到控制、错误正 vx 能产生纠错梯度且训练输出不再长期锁定正饱和”的工程结论。它不足以证明可靠控制、最终策略效果或真实连接组优于对照。
