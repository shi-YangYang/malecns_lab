## 结论

完整图的 GPU 前向与伴随运算均运行成功，采样内存保持在预算内，核级吞吐优于当前 CPU 路径。但 dense 输入存在少量元素超出运行前固定的数值容差，因此 `numeric_pass=false`、`mps_kernel_candidate=false`。**本次不迁移训练；未执行完整 SNN 训练窗口或 Adam 对照。**

这些差异整体很小，与浮点归约舍入差异相容，但本次没有证明它们对神经阈值、递推梯度或学习行为无影响；不能把结果称为 GPU 数学错误，也不能把性能通过等同训练可替换。没有修改容差、选择性删除输入或重跑挑选结果。

## CPU/GPU 数值差异

固定逐元素判据：`abs(GPU−CPU) <= 1e-5 + 1e-5*abs(CPU)`；有限性、形状和float32也必须通过。所有72次输出含预热均保存；其中36次GPU输出分别与CPU比较。

| 输入/方向 | 6次GPU输出精确相同数 | 每次超容差元素数 / 166700 | 最大绝对差 | 相对L2差 |
| --- | ---: | ---: | ---: | ---: |
| zero / W 与 WT | 各6 | 0 | 0 | 0 |
| sparse / W 与 WT | 各6 | 0 | 0 | 0 |
| dense / W | 0 | 3 | 0.00018310546875 | 1.4367093e-7 |
| dense / WT | 0 | 6 | 0.00018310546875 | 1.3497550e-7 |

dense各次比较均为相同的统计，不是偶发失败；这些比较中均无零支持或非零符号差。最大绝对差所在元素未必是超容差元素，因为容差随CPU值变化。所有CPU参考重复输出精确保持；共24个GPU输出精确相同、12个dense GPU输出未达逐元素门槛。

另一次显式固定矩阵 autograd 的前向和完整N维输入梯度也分别有3和6个超容差元素，误差统计与上述dense相同；输入、输出、梯度设备均为mps:0，未计算逐边梯度。其0.237187s耗时包含首次实际autograd路径，不用它替代正式核计时。它仍不构成SNN递推或优化器验证。
