# P1 后续 — 复用完整图稀疏伴随矩阵

状态：Done；A–D 软件已获独立 PASS，E 同协议实测也获新独立 PASS。属于已授权完整图训练路线的局部性能实施；不改变模型、任务或数据范围。完整对照见 [P1 r4](p1-run-20261019-r4.md)。

## 背景与目标

P1 的 20 ms 单序列窗口反向耗时 291.70 s，四次前向各约 16 s。当前每个神经步在反向中对 CSR 权重转置，产生 CSC，再进入 Torch 的 CSR 计算路径。已有源码审查提示重复转换可移到模型构造期；尚未测定它占全部反向时间的比例。

目标是在全部节点、全部边和全细胞梯度不变的前提下，用一次构造的转置 CSR 执行 `Wᵀ g`。软件正确性与实际提速分开验收；不为凑速度改变刺激、时间窗、精度、线程或背景工作点。

## 需求与边界

1. `base_weights` 仍为固定的 `(post, pre)` CSR；新增固定、非持久化的 `(pre, post)` CSR 伴随缓存。由原始 CSC 的 indptr/indices/data 构造转置 CSR，保持 dtype、符号、权重缩放与所有非零项；不得稠密化完整图。
2. 在构造伴随缓存前释放前向转换使用的临时 SciPy CSR。静态新增数组约 0.287 GiB（float32、int64 indices）；实际峰值由监督采样，不能声称省内存。
3. 每步反向直接使用缓存 CSR，不再进行转置或格式转换。密集输入向量的每个分量均参与反向，包括值为零的细胞；固定矩阵无梯度，不引入逐边训练或事件剪枝。
4. 正常模型路径、数值测试路径和 P2c 子类复用同一构造逻辑。数值方程、延迟、门控、参数分组、图及 checkpoint 内容不变；现有源码摘要自然更新模型身份，旧 checkpoint 不绕过严格身份检查。历史产物不覆盖或迁移。
5. 清理被本实现替代的逐步转置路径，不新增配置分叉、重复模型或兼容包装；无需调整无关模块。
