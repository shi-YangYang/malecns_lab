# 全GPU修复训练实测

本轮完成新协议的160/160窗、320帧和160次联合更新。正式训练session42726已收取exit0，`epoch_complete=true`；没有追加epoch。新增158窗的[独立保存证据审查](acceptance-gpu-recovery-epoch-actual.md)session53179 exit0、PASS；审查没有重算模型或重复首两窗验收。不能仅凭进程退出或参数变化称为学会控制。

## 这次在训练什么

目标是让完整MaleCNS连接图约束下的SNN根据指定彩色标记目标的画面，产生前后速度vx、升降速度vz和转向角速度wz，以学习目标居中与距离保持。当前使用四个合成教师场景做监督模仿学习，不是强化学习或任意物体识别。教师动作只提供训练损失目标，部署动作仍来自感觉编码→神经网络→动作读出。

训练内部11752组突触增益与动作读出，固定完整166700节点、25582938条非零有向边及124177617原始突触计数。这里“完整”指已登记参考图及其身份；不意味着每条边独立训练、所有生物动力学真实还原，或已证明真实连接组优于对照。

## 修复、继承与GPU范围

[原因报告](gpu-recovery-causes.md)和[配对诊断验收](acceptance-gradient-probe-r2-actual.md)记录了旧动作MSE在tanh精确饱和时失去纠错梯度，以及长递归反向造成theta梯度放大的证据。没有发现FLU前后轴映射接反。

本轮采用稳定logit损失；保留每窗全部1000步前向，将递归信用范围固定为100步（10ms），50步activation checkpoint负责重算节省内存。截断改变的是学习中的跨时间梯度，不删除图节点、边或前向步骤，也不证明100步是最佳超参数。

逐位继承旧第160窗theta和读出参数，因损失及反向范围改变，显式清零Adam矩和步数，新epoch重置神经与感觉状态。新float32 GPU感觉事件具有新身份。旧160窗及失败/阴性结果完整保留，不能称本轮是同协议的第161–320窗。

图像掩码、感觉事件、完整SNN、读出、损失、前反向、稳定裁剪和fused Adam主参数/矩/step均在MPS，`PYTORCH_ENABLE_MPS_FALLBACK=0`。CPU仍承担资产初始化、文件读写、Python调度和独立保存证据验算；这不属于CPU训练数值回退。

## 实测结果

独立审查验证了54份绑定源码（旧42份保持）、完整图/原始计数身份、40段各18个数组的逐位恢复、41/81/121窗的场景重置、每窗GPU驻留与损失/裁剪/Adam验算，以及最终存档链。新增158窗theta原始L2范围为0.000669046–0.083918761，均非零、有限且远低于登记停止上限；每窗5132–5370项内部theta实际改变。结合首两窗验收，新160窗全部完成真实内部参数更新。
