# Acceptance — P3e0 完整 R 生成成本探针协议

**PASS**。由未参与本协议编写或图工具实施的新 Agent 独立审查，仅确认 [P3e0 协议](p3e-generation-probe.md)可登记为一次受资源监督的完整规模 R 生成成本实验。协议当前仍标为 Draft，协调者读取本报告后可标 Ready 并提交；本审查没有执行生成、加载完整图或运行模型，不代表探针已成功或正式拓扑研究完成。

## Spec Coverage

| 要求 | 审查依据与结论 |
|---|---|
| 完整母本与来源保持 | 固定完整参考图、166,700 节点、25,582,938 内部边和 124,177,617 突触计数；记录母本文件与图身份，并要求母本前后文件摘要一致。`create_research_control` 经 `load_reference` 加载，`_clone` 保留所有节点、注释、缺失掩码、分组和原始计数。未剪图或改变正在训练的来源。 |
| 固定提案和成功上限 | seed=1901、max_attempts=100000、target_swaps=100000、with_paths=False 无歧义。现有 `_rewire` 同时受提案数与成功数约束，逐类记录拒绝、成功数、`target_reached` 和停止原因；不足成功目标不等于机械生成失败，也不允许追加提案、重试或换种子。 |
| R 机械语义与可验证边界 | `_rewire` 保持同符号源双边交换，原权重留在源列，拒绝原自环、新自环和重复边；`validate_rw` 覆盖节点、逐节点及符号入度、自环、逐源强度和全局权重多重集。协议准确指出尚未独立检查逐源权重多重集，未将算法性质冒充全部已测不变量。 |
| 独立研究角色和探针用途 | 新目录、不可覆盖或复用失败尾部；现有保存使用 `overwrite=False`，派生图保持 `research_control`。协议明确图仅作成本探针，不参与训练，不按神经活动或任务表现选图，不将本图当正式 R 对照。 |
| 全流程资源保护 | 新启动预算取 available−1 GiB 与申请 6 GiB 的较小值；`resource_guard.supervise` 实际采样进程树 RSS、系统 available 和墙钟，覆盖 worker 中加载、生成、诊断、保存及重载。固定 600 秒、0.1 秒采样，保留 Noria/Docker；当前生产段先退出，再与训练/评估共享 `workspace_lock()` 排他锁。 |
| 实际重载和独立父判断 | `load_research_control` 重新校验研究来源 ID、母本身份、图内容、元数据/角色及 `validate_rw`。协议要求比对生成与重载身份、规模和整数权重和，保存各阶段耗时。父进程不加载图，并独立结合 worker、资源监督、产物清单/摘要和母本前后摘要生成 assessment；exit0 或 NPZ 存在不足以通过。 |
| 失败与终态证据 | 保留原始监督结果、worker 结果和失败尾部，区分资源、IO、协议失败；实际进程终态必须收取，随后由新的独立实际验收者审查。本次没有引入自动恢复、重试、覆盖或把部分图计为可用对照的路径。 |
| 结论和后续研究分离 | with_paths=False 不支持通路结论；100000 提案和边重叠不支持充分混合。总成本包含加载/检查/磁盘，不直接线性外推纯交换时间；完整 W 历史成本仅作背景。正式 R 预算依本探针成本和静态复杂度另冻结，G/R 训练机会、研究策略与存档、当前输入/DN路径等仍由后续协议处理，AC6 未关闭。 |

## Regression Risks / Evidence Boundaries

- 执行脚本尚未在本次审查中提供或运行；协议已经要求在启动前将其完整文本、命令和全部调用来源摘要绑定到登记。实际验收仍需检查脚本执行了上述顺序、限额和父判断，不能用本协议 PASS 代替运行证据。
- 资源监督是采样保护而非硬内存隔离；若发生监督终止，worker 可能来不及保存终态。此时必须依原始监督结果与现有尾部如实报告失败，不能补写成 worker 成功。
- 生成器未达到成功交换目标可仍然产出机械有效的成本样本；生成/重载失败则不能这样解释。两者应分别记录。
- 本探针没有增加逐源权重多重集验证、当前 3377 输入到 1314 DN 的路径检查、混合诊断或神经策略入口；这些是正式拓扑实验的已列后续边界，不属于本次成本探针的已完成成果。
