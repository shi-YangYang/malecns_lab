## Spec Coverage

- **独立设备实现与真实图约束**：MPS 核心保留原积分、严格阈值、复位、不应期、延迟队列和固定 L1–L5 背景；原 `surrogate_spike`、配置及真实图/神经元映射 loader 被复用。固定正向及转置 COO 在构造时逐块核对完整坐标和值；伴随作用于全部节点，不筛去静默输入，不训练逐边权重。生产工厂和 run 校验拒绝数值 fixture、非 joint 模式及非固定背景。
- **实际后端及身份**：新 model/policy schema、来源闭包及 backend 均与新实现对应；未更改旧对象 class 或伪造旧 CPU ID。GPU 状态、神经及读出计算在 MPS float32，感觉事件继续采用原 CPU 编码，显式要求 fallback 为0。继承 `NeuralPolicy` 的状态验证没有调用旧 CPU 前向。
- **优化器与自身算术**：CPU 主副本保留原命名组、Adam 选项、学习率和矩；GPU raw gradient 经原稳定裁剪后由 CPU Adam 更新，再精确回拷参数。每窗保存梯度/参数/矩及输出，调用原 `validate_window_numbers` 复算有限性、裁剪、Adam、读出及损失；没有以 Decision014 绕过这些检查。
- **迁移与持久化**：从实际合法 CPU 前缀选取末档，绑定 run/checkpoint 文件摘要与前缀。首窗前调用原完整 reader；参数、矩、神经状态、全部 pending、感觉状态及时间游标在实际返拷后逐项比较。新档为严格 NPZ/JSON，字段、shape、dtype、有限性、时钟、上下文、文件摘要及运行身份均受校验。只有模型/策略身份改变，数组值不在迁移时重置。
- **有界续接与失败处理**：父进程不导入 Torch/完整图；共享锁、监督父子关系和单次 claim 位于模型构造前。1–4窗请求及160窗总预算包含 CPU 继承前缀；新输出拒绝覆盖。seal 后才加入进度，未封存尾部不计数；已记录的数值/协议失败阻断自动续接。场景内保持状态，只有进入下一场景才预处理，参数/Adam 保留。
- **资源与证据**：申请6GiB、额外系统预留1GiB、有效 RSS 上限、600s/.1s 监督保持；MPS allocator 下舍入限额与周期/阶段采样独立记录。构造/恢复、前向、反向、传输、CPU裁剪/Adam、保存及段耗时分开；GPU测量有同步。没有操作 Noria/Docker、硬件或新增依赖。
- **文档及科学边界**：`docs/MPS_TRAINING.md` 给出迁移和新进程续接命令，明确 GPU 前反向/CPU Adam 混合后端、旧数值 FAIL 保留、当前60窗为继承前缀。没有把核级提速、数值更新或数值 fixture 当成任务学习或实飞成功。
