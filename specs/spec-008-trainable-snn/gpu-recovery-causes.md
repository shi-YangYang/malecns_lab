# 训练失效原因与修复依据

本报告对应用户要求的前进饱和、方向错误、大梯度及全GPU训练。保存数据审计见[saturation-cause-audit.md](saturation-cause-audit.md)，完整图诊断见[r2协议](gradient-probe-r2.md)及 `data/mps_gradient_probe_20261019_r2`。诊断不更新权重；新训练效果另列，不用软件通过替代学习结果。

## 前进错误：没有发现轴符号接反，存在饱和后的纠错失效

教师vx为距离误差的同号函数，FLU正vx表示前进，读出第0行到vx的映射一致。旧窗口63教师已要求后退，模型仍输出+0.3；这属于预测与教师相反，并非已发现适配器把前后方向接反。

旧160窗中有115窗的vx读出权重和偏置梯度同时精确为零；从CPU窗口43起已经出现，不能归因GPU迁移。DN电位特征归一化后的向量L2约480–497，早期读出更新使logit迅速增大；初始饱和正前进标签及后续Adam动量又推动logit。到末期vx logit约9.6，float32 tanh产生精确饱和，原动作MSE的链式导数再乘 `1-tanh(z)^2`，错误饱和时也无法有效纠正。其它轴共同裁剪与旧动量是可见的额外影响，并非每项都已独立因果干预。

修复采用 `mean(softplus(2z)-(1+y)z)`，y为尺度归一化教师，部署动作仍是tanh(z)乘原尺度。该损失对logit的导数为 `(tanh(z)-y)/元素数`，不会再额外乘一个饱和导数。完整图保存特征下，全部6个logit梯度非零、有限且与解析式相符；局部0.1步logit下降使损失3.792141914→3.786087275。这里只改局部诊断变量，不是模型更新，也不证明已学会飞行。对于教师恰在±1，最优logit仍可能趋向无穷；本修复解决错误饱和无法纠错，不保证所有输出永不饱和。

## 大梯度：递归反向范围的配对因果证据

固定第159窗完整状态、原第160窗同两帧和原损失，所有分支都计算完整1000个神经步。只切断v/g/延迟队列的跨段递归梯度，保留全部DN累加的梯度。实际结果：

| 递归反向范围 | theta原始梯度稳定L2 |
|---|---:|
| 1000步（100ms） | 9.760240474×10²⁹ |
| 500步（50ms） | 3.661612147×10¹¹ |
| 250步（25ms） | 410.7343449 |
| 100步（10ms） | 0.006620554 |

动作、DN特征、神经和感觉末态以及读出梯度全部精确相等。旧1000步分支的早端伴随量级也远高于晚端。由此可把本固定窗口的极端theta梯度放大定位到长递归梯度传播；不是只有范数统计平方溢出，也不需要删除完整图的边或裁剪前向来消除这次现象。该实验不证明所有状态都稳定，亦未定位某条生物通路的唯一作用。

本轮选100步作保守稳定化。它改变学习的时间归因能力：跨越10ms段边界的递归梯度被截断，完整持续前向仍保留。theta原始稳定L2上限1000是新运行的工程停止门槛；不是生物阈值或最佳超参数结论。

## 重放末位差异与原失败

r1严格逐位比较失败保留。r2原生产路径无hook两次重放也有theta末位变化，均通过事先登记的既有数值容差、零支持和符号检查；前向等值不受影响。因此观察hook不是出现这种差异的必要条件。具体GPU归约内核的唯一归因未被证明，不能把r1重新称为逐位通过。

## 训练迁移

继承旧160窗theta和读出参数；新损失及反向范围采用新协议并显式清零Adam矩/步数，新epoch按场景重置神经和float32感觉状态。旧完整图166700节点、25582938非零有向边和原始计数保持，训练的是内部群组增益与读出，不是重新任意连接这些节点。

新数值路径将掩码/感觉事件、神经前反向、损失、稳定裁剪、Adam唯一主参数及m/v/step全部放到MPS。CPU保留资产初始化、文件读写、Python调度和独立保存证据验算；不以“全GPU训练”声称操作系统不使用CPU。基础模块与[完整集成](acceptance-gpu-recovery-software.md)已独立软件验收，实际[纠错及跨进程恢复门槛](acceptance-gpu-recovery-gates-actual.md)也已通过。

实际gate从新genesis状态处理旧第160窗的负vx输入，单次联合更新使两帧vx logit从1.4313/5.3131降至1.2880/4.7090，固定特征vx损失3.5338→3.1542，theta原始梯度L2为0.07614且5014项内部参数改变。gate参数随后丢弃；正式训练从未被gate修改的genesis开始。该证据说明错误方向仍有可用的纠错梯度，不代表一次更新已使动作反向，也不是原旧第160窗状态的精确重放。整轮训练的方向和饱和结果需独立汇总，不能从gate外推。

新160窗现已完成，见[运行报告](gpu-recovery-run-20261019.md)与[独立实际验收](acceptance-gpu-recovery-epoch-actual.md)。新158窗theta原始L2最高0.083919；训练期精确正向饱和230→18帧，负vx目标的正确方向0/121→81/121。错误方向、振荡与局部场景退化仍存在；这些描述性结果不能替代固定最终模型的闭环评估。
