# M3 首次探针的只读数值诊断

日期：2026-10-23。对象：`data/x2_behavior_probe_20261023_r1`。结论为**原 surrogate 在完整 1000 步信用链上出现反向数值爆炸，联合更新失败**。当前没有足够证据把它定性为新策略实现错误，也没有证据证明发生了 MPS 内核错误。以下建议尚未实施或运行，不改变首次探针合同和失败记录。

本次只读取已有源码、JSON 和少量归档数组；未构建脑、导入 Torch、启动 MPS、训练或仿真。唯一新增文件是本报告，不改原 run 或业务源码，不重复已通过检查。

只读数组统计另发现：迁移 theta 为 [-0.08934, 0.09421]，对应 gain 约 [0.95545, 1.04697]。NaN 梯度所在类型的 gain 也在 [0.96284, 1.04429]，并非参数已极端或 tanh 饱和。

前向数值虽有限，但不能称为全都处于生理量级或长期稳定：第二窗末最低 v 为 -720.86 mV；第二窗 DN 半窗均值最低 -318.03 mV。头输入 `(v+52)/7` 只是线性单位归一化，并不限制在 [0,1]，第二窗最大绝对值 38.00、L2 277.33。这会放大头梯度，属于需要如实保留的模型表现；它不能单独解释 theta 的 1e35 级梯度，不能据此擅自裁剪前向电压或特征。

## 具体反向路径与实现判断

归档中的 `brain/trainable.py`、`brain/mps_trainable.py`、`learning/x2_behavior_policy.py` 与诊断时工作区文件逐字节相同。检查以这些原 run 来源为准。

1. `trainable.py` 的 `_Spike.backward` 使用 `1 / (s * (1 + abs(distance/s))**2)`，当前 s=1 mV，峰值斜率为 1/mV。它是声明过的 surrogate，严格二值阈值的真实导数不是这个函数。
2. `MPSLIF.step` 传输 `W @ (gain * spikes)`；`_Matvec.backward` 用完整 `W.T @ gradient`。矩阵是带符号原始连接计数乘 0.275，没有行/列归一化；theta 由同类型神经元共享，梯度还跨细胞与时间求和。检查未见转置方向、gain 位置与 CPU 契约不一致。
3. 时间积分常数 a=0.995012、b=0.980199、耦合系数 c=0.00493794。a、b 小于 1 不等于整个递归 Jacobian 收缩，因为还有完整图放电反馈、延迟队列和类型汇聚。近阈值的非零 surrogate 也给实际没有放电的细胞传梯度，这是原模型约定，不是新误差。
4. reset/refractory 的门控由 `spikes.detach()` 决定，局部导数遵守已有 surrogate 约定；不能将其称为整个不连续物理系统的精确梯度。
5. 新策略每 50 步 checkpoint 只做重计算，没有截断；`offset`/`brain_step` 由默认参数冻结，occupancy 是各次 forward 自己的闭包。完整 v/g/pending 被跨块、跨窗传递；未看到重复累计特征、错误步号或意外 detach。旧 `gpu_recompute.py` 明确按 `credit_horizon` detach；旧短信用训练成功并不能推导新 1000 步链稳定。

**最符合现有证据的解释**：较长 surrogate 递归链不断放大伴随量，随后在 float32 稀疏汇聚、类型求和或门控乘法中溢出，并进一步产生 NaN。具体首次非有限运算尚未被记录。不能仅凭第一窗边界 v 有限，就断言第二窗所有反向量有限：该处 g/pending 梯度未归档，theta 梯度同时汇聚两个窗。因此这是机制诊断，不是已经定位到单条算子的证明。

降低学习率不能修复这次 backward；Adam 尚未执行。反向完成后再做普通梯度裁剪也无法恢复已有 NaN。即使有限部分保留下来，其平方已远超 float32 范围，直接喂给 Adam 仍有二阶矩溢出风险。不得用 `nan_to_num` 抹掉失败。

## 两个最小可证伪的后续选项

两个选项均需要协调者先另行登记。固定原先两条训练观测、初始化、相位、完整图、600 步预热和两个连续 500 步窗，不打开 locked-test。没有缩图、CPU 脑回退或信用截断。建议每个选项只运行一次、独占完整脑、仿真关闭、墙钟上限仍为 600 秒，RSS/MPS 仍为 min(6 GiB, 实测可用内存−1 GiB)。首次耗时只提示可能是分钟内成本，不保证新探针耗时；新增审计数据必须流式保存，不把全部逐步状态留在内存。

### A：缩放反传种子，定位 float32 动态范围问题

- 保留原损失值归档，只对送入 backward 的标量乘固定 `2^-64`，**0 次 optimizer 更新**。这是数值诊断，不是训练成功。保持原 surrogate 及所有前向计算。
- 每个 50 步边界记录 v/g/pending 的梯度有限性、最大绝对值和稳定计算的范数；稀疏 adjoint 前后可只记录第一次非有限出现的步号/张量类型。审计 hook 必须原样返回梯度。
- 与原 run 对比同输入的全部保存状态、DN 特征和原始头输出。仅对有限新梯度在 CPU float64 统计中乘回 `2^64`，比较旧 run 仍有限的位置；这只是归档统计，不是 CPU 脑计算或回退。
- **可证伪点**：如果前向相同且缩放后全链梯度有限，并能解释原有限梯度的比例，支持 float32 动态范围溢出；若仍出现非有限值、前向不一致或比例异常，则要按首次失败的具体算子继续查实现，不能直接采用新模型。
- 代价约一个原探针加边界统计；保留完整 1000 步信用。缺点是改变数值尺度可能让微小分量下溢；它不改善系统的条件数，也不证明 unscale 后能安全训练。不要把这个缩放自动带入正式 Adam。

### B：新的 backward 身份，固定降低 surrogate 斜率

- 明确建立新数值身份：严格二值 forward 不变，仅把 surrogate backward 乘固定 **0.1**；旧核心默认值和历史 checkpoint 身份保持原样。不是调整 `surrogate_scale_mv`，因为后者同时改变距离曲线宽度。
- 完整 1000 步仍连通，无中间 detach；只在同一固定探针上尝试最多一次联合更新。记录与 A 相同的边界审计、原始梯度及前后参数，参数头仍应为零。先检查所有梯度与 Adam 运算尺度；若仍非有限或跨窗梯度下溢为零，保留失败，不能在运行中继续调因子。
- **可证伪点**：更新前，同输入/参数的前向状态和头输出必须与原 run 配对一致；theta 与行为/阶段头梯度须有限且非零，第一窗末 v 梯度也须有限且非零；预期参数必须实际更新。任何一项失败即未解决。
- 代价约一个原探针加边界统计。它针对每次 spike 反馈的放大量，容易实施且不改变完整连接组与前向方程；但它会改变训练估计器并衰减长路径信用，不能称为原 surrogate 梯度的精确等价优化。通过后仍只证明一次更新可执行，未证明学到任务或 P3/P4 通过。

若协调者优先排查原因，先选 A；若优先验证一个明确的新训练方法，可直接登记 B。不要将两者默默组合或自动轮流重试。原计划的 readout-only 基线可以另行有界运行，但它冻结 theta，不能替代联合学习完成，也不能将脑显示或头拟合当成闭环多行为能力。
