# MaleCNS 桌面工作台

左侧显示智元 X2 官方 GPU 仿真，右侧显示同次 MaleCNS 计算的三维神经活动和群组曲线。打开窗口只加载界面与展示资产；点击“开始”才启动完整脑和仿真。

## 打开与操作

已有本地环境、展示资产和构建时，从项目根目录执行：

```bash
npm --prefix apps/desktop start
```

1. 点击顶部“开始”。应用自动加载候选脑、准备专属仿真、完成初始复位并确认画面可用；无需手动 Pause / Reset / Run。
2. 按钮可用后，选择“前进、左转、右转、挥手”。按钮提交任务，候选脑输出行为，执行层再调用官方技能。
3. 动作结束后曲线回到显示零基线，后台继续消费真实反馈并确认停稳。允许预选时可选择**一个**下一动作，显示“待执行”；准备完成后才正式提交。停止、结束互动、异常或会话变化会取消预选。
4. “结束互动”仍作为任务交给脑。“停止”独立请求停车并释放本次 GPU 资源。关闭窗口也先走清理；清理未确认时会保留窗口并显示原因。

前进 1 米、转向 90° 是当前任务目标，不是精确运动保证。官方 MC 负责平衡、步态和预设关节轨迹；单次通过不等于所有连续动作可靠。

当前工作台没有“实时/回放”切换或记录选择器。后台仍保存记录和读档接口，但不能据此认为页面提供回放操作。

## 三维脑图与曲线

| 显示内容 | 实际含义 |
| --- | --- |
| 灰蓝色主体 | 真实突触、胞体及少量官方骨架节点采样，共 674,411 个点，覆盖 166,700 个细胞 |
| 紫色神经元 | 新全脑状态按该细胞窗口平均 ΔV 的绝对值着色，固定 2 mV 半强度；采样脉冲另有短时淡出 |
| 金色连接 | 真实连接组中的 21,952 条抽样边，亮度按突触前细胞的实际 Hz 映射，固定 50 Hz 半强度 |
| 下方神经活动 | 已记录群组的平均放电率；不是每个神经元膜电位，也不是全脑静息频率 |
| 右上角果蝇 | 与脑图视角同步的形态示意，帮助辨认方向；不是 MaleCNS 解剖重建 |

完整状态以 50 个神经步为一窗，通常对应 5 ms 模拟时间，记录步后膜电位均值、相对请求初态的平均变化和实际放电率。数秒计算耗时、模拟时间、机器人发包频率与画面帧率是不同量。

待机、启动和动作结束后的 **0.0 Hz 是界面基线**，不声称模型持续在后台计算且全脑没有活动。动作后反馈仍用于脑历史、执行确认与下次请求准入，只是不继续铺到本次动作曲线里。旧记录若只有群组遥测，按旧群组方式读取，不补造全细胞状态。

节点与连接都按 body ID、运行/请求/批次身份关联。柔光、650 ms 过渡和短时脉冲淡出属于显示增强；直线仅表示连接关系，不是实测轴突走向、逐突触电流或传播动画。少量补充骨架节点也不等于已加载完整骨架。

拖动旋转，滚轮缩放，右下角复位。左上角卡片显示模型规模，左下角图例区分节点与连接。

## 独立脑图展示

```bash
npm --prefix apps/desktop run brain
```

独立窗口不加载控制后端、机器人 IPC 或新的神经推理。显示真实结构及五段历史记录中的 L1/L2 电流差异；它与工作台实时 ΔV / Hz 的含义不同。

- `1–5` 选择历史片段，`0` 只看结构，空格慢放/暂停。
- 拖动旋转，滚轮缩放，双击或 `Home` 复位；`F` 全屏，`Esc` 退出全屏/隐藏控制。
- 每段只有两个已记录的 25 ms 均值窗口；慢放不补造额外神经时间点。

## 首次准备与重新构建

需要 Node.js ≥22.12 和 npm。进入 `apps/desktop` 后：

```bash
npm ci
npm run build
npm start
```

`build` 依次准备资产、检查 TypeScript、生成 `dist/`。**准备资产只复制和校验已有导出，不自动创建缺失资产。**

| 本地依赖 | 用途 |
| --- | --- |
| `apps/atlas/public/data/catalog.json` 及其指向的图谱文件、来源说明 | 图谱身份与基础展示数据 |
| `data/brain_visualization_v1/` | 原始突触抽样、代表点、连接与历史电流片段 |
| `data/brain_activity_edges_v1/activity-edges.json` | 补充的真实活动连接 |
| `data/brain_neuron_coverage_v1/` | 为原抽样漏掉的 39,185 个细胞补齐真实坐标 |
| `.venv-train/bin/python`、完整参考图及候选模型 | 实际脑控后端 |
| `data/x2_behavior_desktop.json` | 本机候选登记；由后端读取，页面不能任意选择模型路径 |
| `data/x2_sim/gpu_probe/runtime-rebuild/`、官方软件与现有 GPU 容器 | 仿真运行环境 |

这些资产均不随源码分发。新机器应恢复匹配的完整资产与环境；当前导出脚本依赖特定历史 run、封存研究源码和原始数据，不是通用的一键安装器。需要重新导出时，先检查 `scripts/export-brain-structure.py`、`export-activity-edges.py`、`export-neuron-coverage.py` 的实际输入及拒绝覆盖规则。

仅查看已构建的网页：`npm run preview`，默认 `http://127.0.0.1:8775/` 为独立脑展示；`/#workbench` 为工作台布局预览，没有 Electron IPC，不能启动实验。

## 运行环境与记录

桌面主进程启动 `.venv-train/bin/python -m malecns_lab.runtime.x2.behavior`，固定启用 `--execute --sim-only --qualification --automatic-start --session-profile continuous`。当前执行默认是 `measured / baseline / official`；v11 / noslip1 等显式实验候选不等于桌面默认。

私有 Lighter GPU 安装使用 `malecns-x2-gpu-trial` 容器，noVNC 主机端口为 6081。Docker Desktop 中没有运行容器，并不代表这个私有运行环境没有启动。[部署说明](../../deploy/x2/README.md)是维护入口；不要为本项目重启 Docker 或停止 Noria。

每场记录位于 `data/x2_sim/agibot/data/var/desktop-*/`，包含任务、原始脑决策、官方执行、反馈、来源身份及清理摘要。`continuous` 保留单请求、单动作、心跳和停车保护；移除累计会话限额不代表无限期稳定已验证。

- 画面采样和视频仅记录本应用 noVNC。首段容量正常封存后继续实时显示；后续未保存部分不能回放。
- 视口采样上限 480 秒/960 张，2 Hz，图片总量 256 MiB；视频请求 15 fps，上限 480 秒/256 MiB。旧 240 秒档案按旧版本读取。
- 全细胞旁文件初始不可变档案上限 128 MiB，随后用 8 个实时槽；实时槽被覆盖的批次明确不可历史回放。
- 文件读取校验路径、长度、身份和哈希；缺失、过期、部分采集或失败保持可见，不伪造完整记录。

源码入口：`electron/main.mjs` 管理窗口与仿真视图，`controller.mjs` 管理任务与预选，`startup.mjs` 协调启动，`src/workbench.ts` 管理界面，`src/brain.ts` 渲染脑图，`src/neural-state.ts` 关联全细胞状态。Python 进程与 GPU 管理由项目根目录的 `src/malecns_lab/runtime/x2/` 负责。

## 常见问题与已知限制

- **内存不足**：保留完整脑预算与系统余量，不跳过检查；停止不用的实验后再试。
- **GPU 被其他会话占用**：本次不会接管。先确认实际资源所有者；不要仅凭旧状态文件结束其他会话。取得资源前被拒绝的窗口可以正常关闭。
- **画面无法采集**：启动对特定 Electron 显示层错误做一次有界恢复，必须重新取得真实画面；不能据此宣称所有原生显示问题已解决。
- **动作已结束但仍待准备**：后台还在消费真实反馈及确认停稳。允许时可预选下一动作；零曲线不等于后端已完成收尾。
- **连续动作仍失败**：保留该 run 的首因及摘要，不用重训、修改目标或清除失败记录掩盖问题。最新自动接续的物理成功仍未取得完整证据。

准确的实测结果与遗留问题见 [连续动作记录](../../history.md#x2-continuity-20261026)、[启动稳定性](../../history.md#desktop-stability-20261026)和 [实时神经活动](../../history.md#desktop-activity-20261027)。真机 X2、全部 16 对连续组合及 60 分钟/100 请求稳定性均未完成验收。
