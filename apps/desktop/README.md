# MaleCNS Lab 桌面工作台

当前默认是受保护的脑控验证：左侧为官方 X2 GPU 仿真，右侧显示实际加载的 MaleCNS 控制脑活动。按钮只提交互动任务，动作由候选脑模型选择；未加载脑时只显示静态结构。启动应用不自动启动仿真或完整脑。

## 安装与打开

需要 Node >=22.12，在本目录执行：

```sh
npm ci
npm run build
npm start
```

已有构建直接 `npm start`。构建复制本地 `apps/atlas/public/data/atlas.json` 的坐标和来源，不分发模型或实验记录。浏览器 preview 只能查看界面。

## 脑控验证

1. 点击“准备验证”。后端读取本地已登记候选配置，实际加载并校验脑模型后才启用任务输入。
2. 在左侧官方窗口 Pause → Reset，确认机器人直立且暂停后点击 Run，再点桌面“开始”。
3. 选择“打招呼”“面向左侧”“面向右侧”或“向前展示”，向脑模型提交任务；按钮不直接映射官方动作，不承诺候选模型已通过行为验收。
4. “结束互动”同样作为任务进入脑模型。“紧急停止”或关闭窗口则独立请求停车并关闭本次 GPU 资源。不用仿真时关闭以减少发热。

主进程固定启动 `malecns_lab.runtime.x2.behavior --execute --sim-only --qualification`。候选由后端读取本地 `data/x2_behavior_desktop.json`，renderer 无法选择路径或动作参数；缺配置或身份检查失败时停止，不回退手动演示或旧模型。桌面不会将启动进程视为脑已加载，`brain_controlled` 只接受后端实际就绪确认。

任务、神经活动、模型决策、官方技能执行和真实反馈分别留在本次 `data/x2_sim/agibot/data/var/desktop-*` 记录中。当前候选为冻结脑 B 的三个读出成员，权重与历史算法保持原训练版本；当前实测目标为前进 1 m、左右 90°，航向输入使用版本化真实目标。全动作仿真执行配置承接前进、左右转、挥手和待命；每请求最多 4 次运动启动、32 次决策，普通结束仍由脑输出停止意图。前进和转向使用固定官方执行档位，保留原模型强度；挥手先进行一次官方站立准备。离线完整任务仍未过门槛，代码接通不代表所有按钮或复合任务已通过；实际结论见 [当前任务](../../GOAL_STATUS.md)。

[GPU 部署说明](../../deploy/x2/README.md)为环境维护入口；私有安装为 `data/x2_sim/gpu_probe/runtime-rebuild`，容器 `malecns-x2-gpu-trial`，画面端口 6081。不退出 Docker Desktop，不停止 Noria。

普通任务在计算、执行及收尾期间禁用，只有本请求停稳且执行反馈被脑消费完毕后解锁；结束互动与独立急停仍可使用。旧 240 秒录制档案按原版本读取，不改写历史记录。

桌面使用 `continuous` 会话，累计运行时间、决策数和请求数不再触发旧实验上限；单请求120秒、32次决策和单动作/停车保护仍在。遥测与媒体各保存有界首段，达到容量后继续实时显示；档案标明 `initial_window`，没有保存的后续部分不能回放。后端命令行默认仍为旧 `qualification`，连续模式须显式指定。

## 脑活动与回放

- 脑图按 manifest 的真实 body_id 映射；点云底色按已有神经群组注释区分，亮度平滑显示群组均值；采样脉冲在真实胞体位置短暂显效，不表示实测轴突传播或膜电位，栅格显示选定 32 个神经元的真实 spike。横轴是模拟时间，每批通常 5 ms，不等于控制周期；隐藏时暂停拉取，显示跳批和采集丢批分开记录。
- 记录选择器只列固定目录中已确认资源清理的终态实验。`telemetry/manifest.json` 保存图、checkpoint、神经执行身份与来源；回放隐藏实时 noVNC，未记录部分不补造。
- `simulation_capture/` 按同机主机时间对齐采样画面、任务/状态事件与脑批次。只选不晚于游标的数据；画面超过 1 秒或有空档显示“此处未采集”，脑批次超过 2 秒显示“上一批”。noVNC 截图可能包含断线提示，截图成功不证明像素新鲜。
- `simulation_video/` 为无音频 VP8 WebM；终态记录可切换采样/视频。首帧媒体时间锚点尚未实测，`media_anchor=null`，视频模式显示“视频未对齐”并清空配对脑批次；联合查看使用采样模式。

## 采集与安全约束

| 项目 | 固定边界 |
|---|---|
| 视口采样 | 仅本应用 noVNC，2 Hz、单在途、JPEG 质量 70；最长 480 秒/960 张，最大 1280×800；单帧 512 KiB、图片总量 256 MiB |
| 原生视频 | 仅唯一可见 noVNC canvas，15 fps 请求、2.5 Mbit/s、每秒分块；最长 480 秒、单块 8 MiB、未确认数据 16 MiB、文件 256 MiB |
| 档案预算 | 图片/视频各自索引上限 8 MiB，启动至少留 512 MiB 磁盘；遥测预算 16 MiB 不变 |
| 封存 | 停车优先，图片/视频共用最多额外 2 秒；缺末块、stop 确认或完整提交保持 partial，不补造 summary，不接受跨 run 迟到数据 |

renderer 无 Node/shell 或任意文件权限；preload 只暴露固定操作。noVNC 使用独立内存 session 的 WebContentsView，只允许 `127.0.0.1:6081` 的 HTTP/WebSocket，禁止导航、弹窗、下载和权限。视频开始前校验四个 noVNC 文件 hash；不采集整屏、不申请系统录屏权限。记录读取限制固定 ID、整数帧号、符号链接、文件大小、身份与 SHA-256；视频使用固定同源 Range 地址。

隐藏、断线、重载或真实写入失败会停车；continuous 的首段正常容量封存不停止会话，封存后仍每5秒检查实时源。qualification 保留原预算超限终止。恢复须确认资源清理后新建 run。采样与录制的边界测试不能代替真实截图、编码、解码、同步、共驻留性能或动作验收。检查按变更选择 `electron/*.test.mjs` 中相关文件，不默认重跑所有测试。历史验证范围统一见 [history.md](../../history.md#spec-022)。
