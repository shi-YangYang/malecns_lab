# MaleCNS Lab 桌面工作台

左侧接入已有官方 X2 GPU 仿真，右侧显示同一次冻结 MPS 控制脑的真实遥测。启动应用时只载入真实胞体坐标，不启动仿真或完整脑，也不使用旧 CPU 诊断回放。

在本目录运行（Node >=22.12）：

```sh
npm ci
npm run build
npm start
```

构建只复制已有 `apps/atlas/public/data/atlas.json` 的坐标与来源到忽略目录。模型、实验记录、依赖均不随源码分发。已有构建可直接 `npm start`。浏览器 preview 只供界面查看，没有实验能力。

点击“准备实验”后启动本仓库固定 `.venv-train` Python 编排入口，准备一个完整脑及私有 GPU 仿真。仿真就绪时在左侧点击官方界面的 Reset、Run，再点击顶部“开始”，执行已验证路线的两轮有界纵向反馈。“停止”或关闭窗口先请求停车、等待资源清理；没有最终确认时显示失败，不能把进程退出当成停车。不会重启 Docker、切换 context、停止 Noria、训练模型或连接真机。

脑图按控制脑 manifest 的真实 body_id 映射。点云颜色是群组均值，下面的栅格只显示选定 32 个神经元的真实 spike 事件；未记录部分不会补造。横轴是神经模拟时间，单批通常 5 ms，显示频率不是控制频率。脑图按需渲染，隐藏时暂停显示拉取；显示跳批和采集丢批分别计数。

顶部记录选择器只列本应用固定运行目录中的已封存实验。回放可逐批前后查看；缺批和不完整档案会明确提示。记录没有仿真视频，因此回放时左侧不显示实时 noVNC。真实遥测来源、图、checkpoint 和执行身份保留在每次实验的 `telemetry/manifest.json` 中。

安全边界：renderer 无 Node/shell/任意文件路径；preload 仅暴露具体操作。实验参数由主进程固定。noVNC 使用独立内存 session 的 WebContentsView，无 preload，仅允许 `127.0.0.1:6081` 的 HTTP/WebSocket，拒绝导航、弹窗、下载和权限。记录读取限制目录、符号链接、单文件大小与总档案大小。

定向边界检查：`node --test electron/*.test.mjs`。真实遥测数值/性能与两轮联调的状态以 Spec022 验收报告为准，不能用界面构建通过替代。
