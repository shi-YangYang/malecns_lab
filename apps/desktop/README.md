# MaleCNS Lab 桌面工作台

左侧接入已有官方 X2 GPU 仿真，右侧显示同次候选脑的真实遥测；旧冻结脑记录继续可回放。启动应用时只载入真实胞体坐标，不启动仿真或完整脑，也不使用旧 CPU 诊断回放。

在本目录运行（Node >=22.12）：

```sh
npm ci
npm run build
npm start
```

构建只复制已有 `apps/atlas/public/data/atlas.json` 的坐标与来源到忽略目录。模型、实验记录、依赖均不随源码分发。已有构建可直接 `npm start`。浏览器 preview 只供界面查看，没有实验能力。

当前“准备验证”入口见下节。历史 Spec022 的两轮纵向运行只作为已有证据，当前入口不自动执行该脚本。“紧急停止”或关闭窗口先请求停车、等待资源清理；没有最终确认时显示失败，不能把进程退出当成停车。不会重启 Docker、切换 context、停止 Noria、训练模型或连接真机。

脑图按控制脑 manifest 的真实 body_id 映射。点云颜色是群组均值，下面的栅格只显示选定 32 个神经元的真实 spike 事件；未记录部分不会补造。横轴是神经模拟时间，单批通常 5 ms，显示频率不是控制频率。脑图按需渲染，隐藏时暂停显示拉取；显示跳批和采集丢批分别计数。

顶部记录选择器只列固定运行目录中资源清理已确认的终态实验。新采样档案按同机主机时间前后查看画面、脑批次与任务/状态事件；即使动作中没有新脑批次，也能查看后续画面。旧记录继续逐批回放，缺少画面时明确显示无画面；所有回放都隐藏实时 noVNC。真实遥测来源、图、checkpoint 和神经执行身份保留在每次实验的 `telemetry/manifest.json` 中。

安全边界：renderer 无 Node/shell/任意文件路径；preload 仅暴露具体操作。实验参数由主进程固定。noVNC 使用独立内存 session 的 WebContentsView，视频采集使用专用隔离沙箱 preload，不向网页暴露 API，仅允许 `127.0.0.1:6081` 的 HTTP/WebSocket，拒绝导航、弹窗、下载和权限。记录读取限制目录、符号链接、单文件大小与总档案大小。

定向边界检查：`node --test electron/*.test.mjs`。真实遥测数值/性能与两轮联调的状态以 Spec022 验收报告为准，不能用界面构建通过替代。

## Spec024 候选脑验证入口

当前“准备验证”使用 `malecns_lab.experiments.x2_behavior_desktop`。默认打开桌面不加载脑或仿真；缺少候选配置会明确失败，不回退旧三轴策略。历史 Spec022 记录仍可回放。

由主机操作人员在 `data/x2_behavior_desktop.json` 指定一个实际存在的新策略 checkpoint（该本地配置不入 Git）：

```json
{"mode":"qualification","checkpoint":"data/<已登记运行>/<实际候选checkpoint目录>"}
```

路径只能位于本项目 `data` 内，必须通过新 checkpoint 完整性、策略和输入身份检查。renderer 不能指定路径或发送 MC 指令。当前模式为候选验证，不表示 P3/P5 已通过；右挥手因取消资格缺失保持关闭。

准备成功后先 Pause、Reset，确认直立且暂停后 Run，再点击顶部“开始”。五个任务按钮只发送任务枚举；“结束互动”进入脑，“紧急停止”独立触发保护并关闭本次资源。仿真和脑仍使用左右布局；超过两秒没有新遥测批次显示“等待新批次”，不补造活动。

入口默认预算：总墙钟 600 秒、GPU VM 共驻留 240 秒、清理预留 35 秒、最多 50 次决策、每请求最多 8 次决策/120 秒，至少 1 GiB 系统预留。实际科学与动作资格运行须先登记预算和候选，不因构建通过而自动启动。没有实际相机或外部方向目标时保留缺失视觉，真实反馈为官方 odom/MC；不生成任务成功标签。

## 同次画面采样与回放（M5a）

只采样本应用隔离的 noVNC 视口，不采集整屏、不申请录屏权限、不注入网页脚本。当前 run 进入运行、画面可见且加载正常、登记/脑就绪/遥测身份一致后才采样。固定目标 2 Hz、单在途；JPEG 质量 70，最长 240 秒/480 张，尺寸最多 1280×800且不放大，单帧 512 KiB、图片总量 256 MiB、索引总量 4 MiB，启动至少留出 512 MiB 磁盘。到界结束本轮，不自动扩大预算。

记录位于本次目录的 `simulation_capture/`：独立 manifest、JPEG、帧索引、主机时间回放索引及 summary，不改变原遥测 16 MiB 额度。新纳秒用字符串；既有 Python Number 时间保留原值并注明精度限制。单技能 execution 与神经 execution 分开，未知关联为 null。读取仅接受固定记录 ID 和整数帧号，逐张检查目录/符号链接、预算、身份与 SHA-256，不预加载图片集合。

隐藏/最小化/加载异常会形成采样空档；只选不晚于游标的数据。画面超过 1 秒或处于空档时显示“此处未采集”；脑批次超过 2 秒显示“上一批”。这是主机时间关联的采样画面，不是连续视频、60 fps 录像或仿真物理帧同步：noVNC 断线提示也可能被截图，成功截图不能证明像素新鲜。

空图、写入失败、身份改变或预算达到上限均请求现有独立停止，不算任务成功；普通“结束互动”仍只进入脑。停车/资源清理优先，封存最多额外等 2 秒。崩溃或超时留下的半成品明确不完整，不补造 summary；迟到帧不能进入下次 run，旧记录不覆盖。恢复须先确认资源清理，再创建新记录。采样失败不能覆盖机器人安全状态。

本轮只有注入截图对象的 Node 边界检查与桌面构建，未启动 Electron/仿真，尚未实测真实截图、同机时钟关系、采样性能及断线呈现。M5b 连续视频、P5 任务表现和上海实机仍未完成；真实采样需合并到后续获准的单次 M4 运行。


## 原生视频归档与回看（M5b，工程实现待独立验收）

本次运行可同时记录 `simulation_video/` 原生 VP8 WebM。专用 simulation preload 只捕获 `#noVNC_container` 下唯一且已连接的可见 canvas：固定请求 15 fps、2.5 Mbit/s、无音频、每秒分块，不使用 JPEG 合成视频或系统整屏录制。开始前从已启动的固定 6081 服务核对四个 noVNC 文件 hash；不符则结束本轮并保留不完整原因。隐藏、断线、重载、画布变化、轨道异常、写入超时及预算超限均停止，恢复需要新 run。

最长 240 秒；单块 8 MiB、未确认数据 16 MiB、文件 256 MiB、索引 4 MiB、磁盘预留 512 MiB。独立停车先行；M5a 图片和 M5b 视频封存共用同一个最多额外 2 秒截止时刻。缺少末块、stop 确认或成功提交时保留 partial 与未完成标记，迟到 summary 无法取得完整资格。逐块保存字节偏移、hash 和事件时间，绑定同次脑/策略/官方资产/源代码身份。

终态记录左侧面板顶部可切换“采样／视频”并播放或暂停。视频通过固定同源媒体地址按 Range 有界读取；不提供任意文件、目录或外网地址。切记录、切回采样、页面隐藏均暂停视频。当前保存主进程与 preload 的 nonce 往返及录制事件原值；没有经过真实验证的首帧媒体时间锚点，`media_anchor` 明确为 null。视频模式清空配对脑批次并显示“视频未对齐”，不能把首个 dataavailable、start 事件或零偏移伪装为同步；需要联合查看时切回 M5a 主机时间采样。

本阶段只有注入编码字节/MediaRecorder 对象的定向检查和前端构建。实际 noVNC 来源、编码、解码时长/seek、帧率、首帧锚点、共驻留开销、已知断线效果均未实测。M5 同步与 P5 任务表现尚未通过；真实视频还需并入获准的短 M4 运行后离线验收。
